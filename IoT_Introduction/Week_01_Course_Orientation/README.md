## 本週目標

- 認識 18 週進度、評量方式與重要日期。
- 理解期末作品必須包含實體行為與有用途的軟體。
- 確認個人自備、課堂萬用電表、專題選配材料及準備期限。
- 建立安全、Git、協作及 AI 使用責任。

## 教材內容

1. IoT 課程定位與完整資料流。
2. 評量配分與 Week 7、8、13、15、17 的要求。
3. 可選題目：互動玩具、智慧教室、環境監測、警報或其他核准題目。
4. 期末最低要求、安全責任、文件與 AI 驗證原則。
5. 依完整 18 週實作需求定稿的材料清單、購買方式、預算與替代方案。

## 第一週確認的採購結論

- 每位學生個人必買：ESP32-S3、麵包板、三種杜邦線、電阻包、兩顆按鈕、
  KY-018、DHT11、KY-016、KY-012、SG90及4AA帶開關電池盒。
- 電子基本包依教師先前成交單價估算約NT$659／人；資料線、AA電池、
  安全轉接端子、斜口鉗與剝線鉗另計，已有合格用品就不用重買。
- 課堂只提供萬用電表，其餘器材均由學生自行準備。
- OLED、PIR、超音波、WS2812、馬達、驅動板與小車不屬於第一週必買。
- 各品項的規格、數量、使用週次與到貨檢查，以
  [學生材料採購總表](student_purchase_list.md)為準。

## 回家安裝作業

第二週不安排全班現場安裝。學生須依本週公布的
[學生材料採購總表](student_purchase_list.md)完成必要採購，
並依[Week 2 課前環境準備](preclass_setup.md)完成 Arduino IDE、Espressif ESP32
board package 與課程資料下載。安裝失敗或材料無法如期取得者，須在課前回報
錯誤畫面或缺料品項；除萬用電表外，課堂不提供借用器材。

## 當週產出

填寫作品構想卡：使用者、實體輸入、實體輸出、軟體用途及一項風險。
