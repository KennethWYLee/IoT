# Week 01：課程介紹、配分與作品

日期：2026-09-09<br>
本週定位：**課堂不操作、不攜帶硬體；課後完成開發環境安裝。**

## 本週目標

- 認識 18 週進度、評量方式與重要日期。
- 理解期末作品必須包含實體行為與有用途的軟體。
- 建立安全、Git、協作及 AI 使用責任。

## 教材內容

1. IoT 課程定位與完整資料流。
2. 評量配分與 Week 7、8、13、15、17 的要求。
3. 可選題目：互動玩具、智慧教室、環境監測、警報或其他核准題目。
4. 期末最低要求、安全責任、文件與 AI 驗證原則。

## 回家安裝作業

第二週不安排全班現場安裝。學生須依[Week 2 課前環境準備](preclass_setup.md)
完成 Arduino IDE、Espressif ESP32 board package 與課程資料下載，並攜帶筆電、
充電器及確認可傳資料的 USB 線。安裝失敗者須在課前回報錯誤畫面。

## 當週產出

填寫作品構想卡：使用者、實體輸入、實體輸出、軟體用途及一項風險。

## 完成檢核

- [ ] 能說明配分及重要週次。
- [ ] 完成作品構想卡。
- [ ] 理解本週不接線、不上電。
- [ ] 課後完成開發環境準備並保存證據。
