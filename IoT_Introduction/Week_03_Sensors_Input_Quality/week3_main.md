# Week 03：感測器與輸入品質

日期：2026-09-23

## 準備器材

ESP32-S3、KY-018 光敏電阻模組、DHT11 溫溼度模組、麵包板、杜邦線及
萬用電表。HC-SR501、HC-SR04 與 OLED 不列入共同實驗。

## 教材內容

- 類比輸入、數位感測資料與取樣間隔。
- 光線基準、有效範圍、校正、重複量測及異常值。
- DHT11 讀取失敗、斷線與不合理讀值的標記方式。

## 課堂實作

全班依相同順序測試 KY-018 與 DHT11，在正常、改變環境及故障條件下
重複量測，建立光線基準、取樣間隔與有效性規則，再把數值、單位、狀態及
異常原因輸出至 Serial Monitor。

## 完成檢核

- [ ] 兩種輸入都有接線表、實物照片及重複讀值。
- [ ] KY-018 完成亮、暗條件與遮蔽測試。
- [ ] DHT11 完成正常、失敗及恢復測試。
- [ ] 程式輸出數值、單位、有效性及異常原因。
- [ ] Lab Note 記錄一次故障、檢查、修正及復原。
