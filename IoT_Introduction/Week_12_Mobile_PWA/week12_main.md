# Week 12：手機前台與 PWA

日期：2026-11-25

## 準備環境

手機瀏覽器、Responsive Web 或 PWA、WebSocket、歷史 API、真實 ESP32
裝置與 Backend。

## 教材內容

- 手機優先介面與核心使用流程。
- loading、empty、pending、success、failure、timeout、offline 狀態。
- 即時監看、歷史查詢、命令操作及危險操作確認。

## 課堂實作

用手機顯示即時狀態及歷史資料，送出一項命令並顯示最終結果；關閉裝置或
Backend，確認離線狀態清楚且不會誤導。

## 完成檢核

- [ ] 不需縮放即可用手機完成核心流程。
- [ ] 即時、歷史與操作皆使用真實資料。
- [ ] error／offline／timeout 呈現完整。
