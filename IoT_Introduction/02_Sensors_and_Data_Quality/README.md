# 02：感測器與資料品質

## 對應週次

Week 3；後續專題的所有感測輸入都沿用這裡的測試方法。

## 可用設備

- DHT11：溫度與濕度，更新速度有限，需處理讀取失敗。
- HC-SR501 PIR：人體移動事件，有暖機時間與保持時間。
- KY-018：光線相對值，需要現場校正門檻。
- HC-SR04：距離，需要 timeout；Echo 電壓必須先確認。
- OLED：顯示數值、狀態與錯誤，並不是感測器。

## 教材內容

- 數位、類比、時序型輸入的差異。
- 取樣頻率、單位、有效範圍、校正、雜訊、去抖與濾波。
- 將「讀到數字」提升成「能說明數字是否可信」。

## 實作

每組選兩種輸入，在穩定、觸發、邊界與異常條件下重複量測，定義有效／
無效範圍與更新頻率，再將數值及狀態顯示在 Serial 或 OLED。

## 完成檢核

- [ ] 兩種輸入都有接線表及正常、邊界、異常測試。
- [ ] 程式會拒絕或標記無效值。
- [ ] 門檻與取樣頻率有量測依據。
- [ ] Lab Notebook 記錄一次誤判與修正。
