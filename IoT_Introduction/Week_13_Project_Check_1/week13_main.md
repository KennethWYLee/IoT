# Week 13：期末作品進度檢查一

日期：2026-12-02

本週不接受只有模擬資料或投影片。每組必須讓一筆真實硬體資料從 ESP32
進入 Backend 與 Database，最後在手機畫面出現。

## 必備展示

1. 實體輸入產生真實事件。
2. Backend 收到並留下 structured log。
3. Database 保存且可查詢。
4. 手機顯示即時或歷史結果。
5. API、JSON、topic 與欄位格式固定。

## 完成檢核

- [ ] 真實資料端到端路徑可重複兩次。
- [ ] 接線圖、資料流圖與介面格式已提交。
- [ ] 失敗時能從 log 找到中斷位置。
- [ ] 教師回饋已轉成負責人、期限與驗收工作。
