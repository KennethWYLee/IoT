# 10：IoT 與機器人進階路線

## 對應週次

Week 18；官方期末考週，不新增進度或評量。

## 可選方向

- **Flutter／原生 App**：重用已完成的 HTTP、WebSocket 與登入流程。
- **雲端部署**：HTTPS、環境變數、Database migration、監控與備份。
- **進階 MQTT**：QoS、retained message、Last Will、ACL 與離線佇列。
- **ROS 2**：把既有裝置事件轉成 topic、service 或 action。
- **Gazebo／Nav2**：模擬定位、路徑規劃與移動機器人導航。

## 與目前設備的關係

TT 馬達、輪胎、L298N 與萬向球可以組成簡單移動平台，但本課核心不是
「一定要做無人車」。未選移動作品的學生，可繼續用感測器、燈、聲音、
OLED 或舵機發展 IoT 專題。

## 自學原則

1. 保留可運作的期末版本，每次只新增一個變因。
2. 設定兩週內可驗收的小目標、測試方法與停止條件。
3. 新工具或 AI 產生的程式仍須本人理解、修改與驗證。
