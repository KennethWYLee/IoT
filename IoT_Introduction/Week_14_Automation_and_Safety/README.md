# Week 14：自動反應、安全與復原

日期：2026-12-09

## 教材內容

- 以狀態機、門檻、排程或事件建立一項有用途的自動反應。
- 感測異常、錯誤命令、斷線及致動器卡住時的安全狀態。
- 自動與手動命令衝突時的優先順序與復原方法。

## 課堂實作

寫出觸發、允許、動作、最大時間及停止條件；注入一項異常，確認輸出能
安全停止、手機顯示錯誤並可依步驟恢復。

## 完成檢核

- [ ] 自動反應具有清楚用途。
- [ ] 安全狀態與復原步驟完成。
- [ ] 異常不會造成無限動作或危險輸出。
- [ ] 動作原因與結果有 log。
