# 09：測試、部署與展示

## 對應週次

Week 14 安全復原、Week 16 整合與凍結、Week 17 期末展示。

## 教材內容

- 正常、邊界、異常與復原測試。
- 故障注入：斷網、裝置離線、服務停止、錯誤輸入或感測異常。
- 從乾淨環境重建 Backend、Database 與手機前台。
- 版本凍結、展示腳本、角色分工與離線備案。

## Week 16 凍結條件

- 三項故障測試、兩次完整彩排、可由另一位組員執行的重建步驟。
- 固定 commit／tag、接線圖、資料流、BOM、資料格式與啟動順序。
- 除阻止展示的重大錯誤外，不再新增功能或大幅更換架構。

## Week 17 必備展示

實體互動、手機操作、Backend、Database、即時與歷史資料、structured log、
自動反應、安全復原、原始碼、測試、限制，以及每位組員的個人問答。

## 完成檢核

- [ ] 三項異常測試皆有安全結果及證據。
- [ ] 另一位組員可依 README 重建。
- [ ] 展示版本已凍結，且有斷線備案。
- [ ] 所有組員能解釋裝置到手機的完整資料流。
