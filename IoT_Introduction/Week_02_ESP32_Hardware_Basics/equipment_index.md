# 已購設備總表

本表是教師已購庫存的辨識索引，不是學生每組固定配發清單，也不取代 Week 1
公布的正式材料清單。商品圖只供辨識，接線前必須核對實物絲印、電壓與可靠的
pinout；數量仍須以開課前實際盤點為準。
