# Week 02：必買／必帶清單

## 結論

依目前規劃的三組工作站，**本週不需要再購買電子零件**。現有設備已足夠
完成 ESP32 上傳、Serial、GPIO4 按鈕、GPIO5 測試輸出及萬用電表量測。

學生個人也不需要為 Week 2 購買 ESP32；課堂使用教師提供的三組設備。

## 三組工作站必備數量

| 品項 | 本週需要 | 目前已有 | 結果 |
|---|---:|---:|---|
| ESP32-S3 DevKitC-1 N16R8，向下 44 腳 | 3 | 3 | 足夠 |
| 400 孔麵包板 | 3 | 4 | 足夠，另有 1 塊備品 |
| 四腳輕觸按鈕 | 3 | 10 | 足夠 |
| 公對公杜邦線 | 每組至少 2 條 | 6 排 | 足夠 |
| A830L 萬用電表 | 1，輪流使用 | 1 | 足夠 |
| 可傳資料的 USB 線 | 3 條，另備 1 條 | 已有多條 | 必須先逐條測試 |
| 筆電與充電器 | 每位學生或每組 1 套 | 學生攜帶 | 課前確認 |

本週的 GPIO5 直接以萬用電表量測 HIGH／LOW，不外接 LED、蜂鳴器或馬達，
因此電阻、KY-012、KY-016、WS2812、舵機、L298N、LM2596 及電池盒都不是
Week 2 必需品。

## 只有下列情況才需要購買

### USB 資料線不足

如果現有線材無法讓電腦辨識 ESP32 的連接埠，才購買：

- 數量：補到至少 3 條可用，再加 1 條備用。
- 接頭：依實際 ESP32 板端與學生筆電端選擇。
- 商品說明必須明確標示 **data／資料傳輸**，不能只寫充電線。
- 買回後仍需實際用 ESP32 測試 Port 與 Upload，外觀無法證明可傳資料。

### 萬用電表電池失效

若 A830L 無法正常顯示或量測，先依表內原電池規格更換電池；不要在未核對
型號、極性及規格時隨意代用。

## 學生上課必帶

- [ ] 已完成 Arduino IDE 2 與 Espressif ESP32 package 安裝的筆電。
- [ ] 筆電充電器。
- [ ] Week 1 安裝證據或可直接開啟的環境。
- [ ] 可存取最新版 GitHub 課程教材。
- [ ] 若教師要求，每人攜帶一條已確認可傳資料的 USB 線。

## 教師課前檢查

1. 將三塊 ESP32 標成 A、B、C。
2. 將三條主要資料線與一條備用線逐一完成 Port、Upload、Serial 測試。
3. 檢查三塊麵包板、三顆按鈕及至少六條公對公杜邦線。
4. 確認萬用電表通斷檔及 3.3V 直流電壓量測正常。
5. 拍下並公布本批板卡實測可用的 Arduino IDE board／flash／PSRAM 設定。
6. 不把馬達、舵機、外部電池及其他本週不用的零件放在工作桌，避免誤接。

## 如果改成每人一套

只有在你決定不再分組、要求每位學生同時獨立操作時，才需要另外準備每人：

- ESP32-S3 開發板 1 塊。
- 可傳資料的 USB 線 1 條。
- 小麵包板 1 塊。
- 四腳按鈕 1 顆。
- 公對公杜邦線至少 2 條。

這不是目前 Week 2 的必買要求。
