# Week 02：器材與必帶確認表

本表說明Week 2實驗會使用的器材與最低數量，不是獨立的購買通知。除課堂
提供的萬用電表外，器材均由學生自行準備，並以Week 1公布的
[學生材料採購總表](../Week_01_Course_Orientation/student_purchase_list.md)為準。
教師現有三套設備只作驗證與示範，不提供學生借用或故障替換。

## 個人必帶

- [ ] 已安裝 Arduino IDE 2 與 Espressif `esp32` package 的筆電。
- [ ] 筆電充電器。
- [ ] 可存取最新版 GitHub 課程教材。
- [ ] Week 1 課前準備證據，或可以現場直接開啟的開發環境。
- [ ] 自備一條已確認可傳資料的USB線；可使用既有合格線材，不必重複購買。

只有充電功能的 USB 線可能讓板上電源燈亮起，卻不會讓電腦出現 Port。線材
必須實際完成 Port、Upload 與 Serial 測試，不能只依外觀判斷。

## 每個工作站的實驗依賴

| 品項 | 最低數量 | 本週用途 | 取得方式 |
|---|---:|---|---|
| ESP32-S3-DevKitC-1，模組標示 N16R8、排針向下 44 腳 | 1 | Upload、GPIO4 輸入、GPIO5 輸出 | 學生個人基本包 |
| 可傳資料的 USB 線 | 1 | 供電、Upload、Serial | 學生自備合格線材 |
| 400 孔麵包板 | 1 | 按鈕與安全測試點 | 學生個人基本包 |
| 四腳輕觸按鈕 | 1 | 數位輸入 | 學生個人基本包 |
| 公對公杜邦線 | 至少 4 條 | GPIO4、GPIO5、GND、TPG 接線 | 學生個人基本包 |
| A830L 或功能相當的萬用電表 | 可輪流共用 | 通斷、LOW／HIGH 電壓 | 教師安排共用或借用 |

每位學生須帶齊個人基本包。教師持有的三塊板與三套主要材料只作驗證及示範；
課堂只提供萬用電表輪流量測。

## 本週不使用

GPIO5 直接以 Serial 與萬用電表驗證 HIGH／LOW，不外接負載。因此本週不使用：

- LED、KY-016 RGB、KY-012 蜂鳴器或 WS2812。
- SG90、MG90S、TT 馬達或 L298N。
- LM2596、電池盒或外部電源。
- DHT11、PIR、光敏、HC-SR04 或 OLED。

未列入本週使用不代表整學期不需要；是否購買仍以完成18週設計後發布的正式
材料清單為準。

## 課前缺料處理

1. 在 Week 2 前依正式材料清單逐項盤點，不到上課當天才第一次拆封。
2. 若料件尚未到貨、數量不足或型號不同，回報品項、實物照片與規格頁。
3. 未確認相容性時不要以外觀相似的板卡、電源或模組直接替代。
4. 教師只提供萬用電表；其他缺料由學生補齊後再完成實作，不以未驗證品替代。

## 上電前最後確認

- [ ] 開發板金屬屏蔽罩與板身絲印已拍照留存。
- [ ] USB 線已確認可傳資料。
- [ ] 麵包板、按鈕與四條杜邦線無明顯損壞。
- [ ] 萬用電表表筆、電池及 DCV／電阻功能已由教師確認。
- [ ] 桌上沒有本週不使用的外部電池、馬達或其他高電流負載。
