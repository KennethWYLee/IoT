# Week 15：第二次專題報告—端到端整合、使用性與修正

日期：2026-12-16

每組先展示一筆真實硬體資料從ESP32進入Backend與Database，最後在手機出現；
再由不是該組主要開發者的人，僅看介面提示，以手機完成核心流程三次。本週
要證明作品已端到端連通、可被使用、可追蹤，且已根據測試修正。本次報告
占學期成績15%。

## 必備展示

1. 真實硬體、Backend、Database與手機的同一筆事件路徑。
2. 三次手機核心流程。
3. 每次操作的command、result／ack或timeout。
4. Database歷史與structured log。
5. 一項測試前後的修正證據。

## 完成檢核

- [ ] 真實硬體資料端到端路徑可重複兩次。
- [ ] 三次流程的成功／失敗與時間都有紀錄。
- [ ] 測試者不需 IDE 或修改程式。
- [ ] 歷史、操作 log 及錯誤狀態可展示。
- [ ] 剩餘工作可在 Week 16 完成。
