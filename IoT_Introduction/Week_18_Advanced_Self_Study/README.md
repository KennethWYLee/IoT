# Week 18：進階自學路線

日期：2027-01-06<br>
本週定位：官方期末考週，不新增進度或評量。

## 可選方向

- Flutter／原生 App：重用 HTTP、WebSocket 與登入流程。
- 雲端部署：HTTPS、環境變數、migration、監控及備份。
- 進階 MQTT：QoS、retained、Last Will、ACL 及離線佇列。
- ROS 2：把裝置事件轉成 topic、service 或 action。
- Gazebo／Nav2：模擬定位、路徑規劃及移動機器人導航。

TT 馬達、輪胎、L298N 與萬向球可組成移動平台，但本課不要求一定製作
無人車；也可用感測器、燈、聲音、OLED 或舵機繼續發展 IoT 專題。
