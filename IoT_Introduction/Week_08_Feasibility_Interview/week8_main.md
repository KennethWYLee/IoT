# Week 08：題目與技術可行性訪談

日期：2026-10-28

## 本週安排

每組參加一次 12–15 分鐘訪談。本週就是期中小組成果，不另收內容重複的
期中整合包。

## 每組必帶

1. 目標使用者、情境及核心互動。
2. 一個可運作的硬體片段。
3. 軟體要記錄什麼，或如何協助使用者操作。
4. 裝置、Backend、Database 與手機資料流。
5. BOM、供電／驅動風險及最低驗收條件。

## 完成檢核

- [ ] 硬體片段可現場重現。
- [ ] 軟體用途不只是顯示一個數字。
- [ ] 資料流、BOM、風險與驗收條件完整。
- [ ] 訪談決議已寫入 Git 專案。
