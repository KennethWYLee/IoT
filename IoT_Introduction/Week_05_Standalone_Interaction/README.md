# Week 05：單機互動作品

日期：2026-10-07

## 準備器材

ESP32-S3、前兩週選用的感測器與致動器，以及安全供電。

## 教材內容

- 輸入、狀態、決策、輸出與 reset。
- IDLE、READY、ACTIVE、RESULT、ERROR 狀態圖。
- 非阻塞時間控制、timeout 與 fail-safe。

## 課堂實作

完成一個不依賴網路的互動原型，例如反應遊戲、光控轉盤、人體警報、
距離提示、電子骰子或自動閘門；由不同組員連續操作三次。

## 完成檢核

- [ ] 無網路仍可完成核心互動。
- [ ] 狀態圖與程式行為一致。
- [ ] 三次測試都有紀錄。
- [ ] 至少修正一項測試發現的問題。
