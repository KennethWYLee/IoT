# Week 04：致動器、機構與供電

日期：2026-09-30

## 準備器材

SG90 或 MG90S、WS2812 或 KY-016、KY-012、LM2596S、電池盒／合適電源、
萬用電表及杜邦線。

## 教材內容

- PWM、舵機角度、LED 色彩／亮度及蜂鳴器。
- 外部電源、降壓、共地、啟動電流與極性。
- timeout、停止位置、斷線及異常輸入時的安全狀態。

## 課堂實作

1. 先量測供電，再以最小動作測試輸出。
2. 用按鈕或感測值觸發一個移動、指示或發聲行為。
3. 加入最大動作時間與安全停止，注入一次異常。

## 完成檢核

- [ ] 外部供電與共地接線有圖及量測。
- [ ] 致動行為可重複啟動與停止。
- [ ] timeout 與安全狀態測試通過。
