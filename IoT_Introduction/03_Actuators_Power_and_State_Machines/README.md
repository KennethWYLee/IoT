# 03：致動器、供電與狀態機

## 對應週次

Week 4 致動器與供電、Week 5 單機互動、Week 14 自動反應與安全復原。

## 可用設備

- 顯示／提示：OLED、KY-016、WS2812、KY-012。
- 動作：SG90、MG90S、TT 馬達、輪胎、萬向球。
- 驅動／供電：L298N、LM2596S、四顆 AA 電池盒、萬用電表。

## 教材內容

- PWM、舵機角度、LED 亮度／色彩、蜂鳴器及 DC 馬達方向／速度。
- ESP32 邏輯電源與負載電源分離、共地、降壓、啟動電流與極性。
- IDLE、READY、ACTIVE、RESULT、ERROR 狀態與非阻塞時間控制。
- timeout、reset、fail-safe、自動與手動命令的優先順序。

## 實作路線

1. 從低功率輸出開始，量測電源後再測舵機或馬達。
2. 用按鈕或感測器觸發一個會動、會亮或會響的行為。
3. 將輸入、狀態、決策、輸出與 reset 組成無網路單機作品。
4. 三次重複操作，再注入錯誤輸入、斷線或卡住情境。

## 完成檢核

- [ ] 電源、訊號與共地接線有圖及量測。
- [ ] 輸出可停止且有最大動作時間。
- [ ] 狀態圖與程式行為一致。
- [ ] 異常時進入安全狀態並可依步驟復原。
