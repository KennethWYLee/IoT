# Week 07：個人筆試與雙向控制

日期：2026-10-21

## 課程安排

- 前 50–60 分鐘：個人概念筆試。
- 後半段：手機命令、Backend 派送、ESP32 執行及 result／ack／timeout。
- 課末：小組題目工作坊。

## 筆試範圍

安全接線、電壓與共地、感測品質、狀態圖、JSON、資料流、HTTP、WebSocket
及 log 診斷。

## 當週產出

手機送出帶 command_id 的命令，ESP32 執行或拒絕並回傳結果；小組完成
期末題目、使用者、硬體行為與軟體用途草案。

## 完成檢核

- [ ] 完成個人筆試。
- [ ] 雙向控制有成功、失敗或 timeout 結果。
- [ ] log 可用 command_id 串起命令與結果。
- [ ] 完成小組題目草案。
