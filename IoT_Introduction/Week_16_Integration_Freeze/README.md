# Week 16：整合、故障注入與版本凍結

日期：2026-12-23

## 課堂實作

1. 注入三項故障：斷網、裝置離線、服務停止、錯誤輸入或感測異常任選。
2. 從乾淨環境依 README 重建 Backend、Database 與前台。
3. 依 Week 17 時間限制完成兩次完整彩排。
4. 準備斷線時仍可展示核心互動與既有歷史資料的備案。

## 版本凍結

固定 commit／tag、接線圖、資料流、BOM、資料格式、啟動順序、測試結果、
AI 驗證紀錄、已知限制及展示分工。除重大錯誤外不再新增功能。

## 完成檢核

- [ ] 三項異常測試有證據。
- [ ] 另一位組員可依 README 重建。
- [ ] 兩次彩排完成。
- [ ] 展示版本已凍結並有離線備案。
