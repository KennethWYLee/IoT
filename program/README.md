# 每週 Arduino 程式

各週程式由教師在指定的課堂時點開放。GitHub 的 `program/weekN` 預設由 `.gitignore` 排除；目前公開 Week2、Week3，以及 Week4 的 Q1～Q4 和 Q4 電腦工具。Week5 本次重建完成後僅公開 Q1、Q2；其他週程式仍不公開。一般 commit、push 或本機已有檔案，不表示其他程式獲准公開。

教師雲端程式位於 `IoT / IOT_Introduction / program`，可保存各週完整版本；提供學生的程式與 Ans 須符合當次開放範圍。

[Week2 程式](week2/README.md) · [Week3 程式](week3/README.md) · [Week4 Q1～Q4 程式](week4/README.md)

每支 `.ino` 保留同名資料夾，不使用 ZIP。於 GitHub 開啟 `.ino` 後選 **Download raw file**，不要另存整個網頁。Arduino IDE 以 File → Open 開啟。

開始修改前保留自己的工作副本，依 Ans 核對接腳、模組及設定。先完成編譯，不代表接線、電源或實物已經通過。
