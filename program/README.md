# 每週 Arduino 程式

各週的 `.ino` 都集中在這個 `program` 資料夾，按週次分類，不以 ZIP 提供。
目前公開 Week1、Week3；其他週在教師開放後，放進同一層的 `week2`、`week4` 等資料夾。

```text
program/
  week1/
    hello_first/
      hello_first.ino
  week3/
    light_snapshot/
      light_snapshot.ino
    ...
```

每支程式保留同名資料夾，讓 Arduino IDE 能直接開啟。例如
`light_snapshot.ino` 放在 `light_snapshot` 裡，不把不同作品合併到同一份草稿。

| 週次 | 程式與使用說明 | 題目 | 解答與接線教學 |
|---|---|---|---|
| Week1 | [Hello 程式與說明](week1/README.md) | [首次操作教學](../IOT_Introduction/Week_01_Course_Orientation/week1_main.md#week-2-preclass-setup) | 同一份教學，沒有另設答案卷 |
| Week3 | [9 支程式](week3/README.md) | [Main PDF](../IOT_Introduction/Week_03_Electrical_Measurement_and_ADC/week3_main.pdf) | [Ans PDF](../IOT_Introduction/Week_03_Electrical_Measurement_and_ADC/week3Ans.pdf) |

在 GitHub 開啟所需 `.ino`，按 **Download raw file** 下載原始程式，放進同名資料夾，
再於 Arduino IDE 選 **File → Open**。不要把 GitHub 網頁另存為 `.ino`。
開始修改前保留自己的工作副本；依當週說明核對接腳、模組規格與程式設定，再上傳到板子。

本資料夾是公開下載位置；維護來源及版本雜湊記於各週 `manifest.json`。
不要在此放密碼、金鑰、學生個資或執行紀錄。
