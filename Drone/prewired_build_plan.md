# 店家預焊、自己組裝：供貨查核與詢價單

## 現在採用的方向

使用者已同意由店家預先焊好飛控板的馬達及電源接頭，自己安裝馬達、固定主板、插接電池並撰寫手機 App。優先採用已組裝的輕量 ESP32 飛控，再請店家加工接頭；不要求使用者焊接，也不先委託重新設計 PCB。

**目前完成的是預焊需求與候選供應來源，還不是可整批下單的相容 BOM。**接受代焊解決了組裝技能限制，沒有直接解決供貨、重量、電源、推力和韌體相容性。

一般零件仍優先台灣蝦皮。下列海外飛控僅供評估及詢問代購，尚未選定海外採購、完整套件、下單或聯絡賣家。

## 可直接貼給蝦皮代焊店家的訊息

> 您好，我想組一台小型 ESP32 無人機，不會焊接，但可以自行插接與鎖螺絲。請先確認是否接受「一片客供、元件已組裝好的飛控板，加焊接頭線束」的小量加工，不是從零設計電路板。
>
> 預計需要四路馬達接頭、一組電池接頭；若馬達只有裸線，也請一起加工成能對插的版本，並標示 M1–M4、正負極、做絕緣與線根固定。若燒錄介面沒有插座，也希望一併預接，讓我之後不用焊接。
>
> 飛控、電池與馬達還在核定，確認承接後會提供板號、原理圖、實物照片、指定接頭腳序及線長。請問是否能只做一組？可否協助採購指定材料？加工及材料如何計價、交期多久、是否接受郵寄客供板？
>
> 也請分開說明能否做斷電短路／導通／極性檢查，以及拆槳、限流條件下的上電檢查。若不提供韌體設定、馬達負載測試或飛行調校，請明確列出；這些不當成一般代焊服務自動包含。

這段只用於確認服務範圍與估價，**還不是可交付加工的完整圖紙**。未核定零件前不要要求店家憑「ESP32＋8520」自行猜接線，也不要把馬達無槳轉動當成承載推力及飛行驗收。

## 完成採購前還差三個關卡

1. **取得可供貨的完整控制板方案。**確認 ESP32 確實執行穩定控制、四路動力與 1S 供電規格、可重編韌體、免焊燒錄接法，以及板價、預焊費與取得方式。
2. **把動力和機構配成同一套。**核對一款馬達＋槳的負載電流／推力、驅動與接頭容量、電池資料、機架孔位／護圈及含線全機重量。現在仍沒有核定總價，舊零件小計不適用於此方案。
3. **明確分開代焊驗收和飛行驗證。**前者是接線品質；後者包括供電壓降、單路負載／溫升、四路運轉、感測器方向、失聯停止及受控試飛。手機 App 用 Wi-Fi 下指令，ESP32 自行跑姿態控制；支援 Wi-Fi 的硬體不代表現成韌體已接受自製 App。FixedPID 可另作演算法研究，第一台不先同時更換控制器和無線協定。
