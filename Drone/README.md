# ESP Drone

本資料夾專門整理與驗證使用 ESP32 組裝無人機所需的研究、設計、程式與實作紀錄。

## 已確認的專案限制

- 飛控核心使用 ESP32；第一版優先評估具硬體浮點運算能力的 ESP32-S3。
- 一般零件以台灣蝦皮可購得為採購條件，商品仍須逐項核對型號、尺寸、接頭、電壓及庫存。
- 正常操作介面使用手機 App，不另製作雙搖桿 ESP32 遙控器。第一版以無人機建立 Wi-Fi AP、App 透過 UDP 單播送出控制封包；BLE 暫留作配對、校正與救援設定。
- 使用者目前不會焊接，希望自行選購散件，以鎖螺絲、卡扣與插頭完成組裝，可接受小型機體。2026-09-05 已同意由店家預焊飛控板的馬達與電源接頭，其餘自行組裝；不再要求每件商品出廠就完全免焊。尚未核定完整的蝦皮散件 BOM。
- 01Studio pyDrone 完整套件保留為已知免焊參考；不代表使用者已選定購買。接受預焊不等於同意海外採購、整台套件或重新設計／製造 PCB；未代為下單或聯絡店家。
- 第一版以能安全完成桌面測試、失效保護測試與短暫懸停為目標，不先加入相機、GPS 或載重功能。
- 未完成重量、單馬達推力、最大電流、供電壓降及 failsafe 驗證前，不進行自由飛行。
