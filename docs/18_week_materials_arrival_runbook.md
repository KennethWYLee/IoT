# 18 週材料到貨與課堂執行 Runbook：UCI 4WD 版

> **版本狀態：舊版教師參考資料。** 本文件尚未對齊現行 Full-stack IoT
> 課表，不得作為學生週次或評量依據。UCI 4WD 現在是教師智慧停車
> 示範，不是學生共同必修作品；現行課表以 `docs/18_week_plan.md` 為準。

本文件處理材料未同時到貨、硬體故障與教師 11/04 不在臺灣的備援。共同平台為 ESP32-S3、UCI K-4 4WD、L298N、LM2596、6AA Eneloop 電池盒與智慧停車場。

## 到貨優先順序

| 截止週次 | 必須到貨 | 沒到貨時的替代任務 |
|---:|---|---|
| Week 2 | ESP32-S3、USB data cable | 共用教師板完成 IDE / Serial 觀察，個人先畫資料流 |
| Week 3 | 麵包板、杜邦線、LED、按鈕、蜂鳴器、電阻、萬用電表 | 用接線圖與錯誤案例做安全 BIT，不上電 |
| Week 4 | 紙板、膠帶、尺、邊界開關或感測器 | 先完成 1:1 場地與紙模型驗證 |
| Week 5 | 停車場 ESP32、警示與顯示元件 | 先以 Serial event log 取代 dashboard |
| Week 6 | UCI 4WD、L298N、LM2596、6AA 電池盒、開關 | 使用教師 demo 車觀察 motor mapping；學生完成 pseudo-code |
| Week 8 | 每組可用車輛與手機錄影 | 與有車組共用測試時段，但每組仍提交自己的狀態機與分析 |

## 材料分包

### A. 智慧停車場包

- ESP32-S3 或共用控制板。
- RGB LED、蜂鳴器、微動開關 / 邊界感測器。
- SG90 閘門選配、OLED 選配。
- 紙板、膠帶、尺、標籤與手機計時備援。

### B. UCI 4WD 車輛包

- UCI K-4 4WD 固定底盤與四顆馬達。
- ESP32-S3、L298N、LM2596。
- 6AA 電池盒、總電源開關、Eneloop。
- 杜邦線 / 端子線、魔鬼氈、束線帶。
- HC-SR04 選配；沒有感測器時可先做固定起點的時間 / PWM 狀態機。

不需要木製底板、ZX2、鑽孔模具、USB 電鑽或每組工具箱。

## UCI 4WD 故障處理順序

```text
總電源
-> 電池電壓與極性
-> LM2596 輸出
-> 共地
-> L298N enable / input
-> 單顆馬達方向
-> 左右輪組 mapping
-> PWM 校正
-> 狀態機
-> 場地與起點
```

車不動時不可直接連續加大 PWM。先架空，確認 L298N 是否發熱、ESP32 是否重開、馬達是否堵轉。四輪車摩擦較大，禁止長時間原地堵轉。

教師於 2026-11-01 至 2026-11-07 出國參加研討會。11/04 是官方期中週，但不進行無教師監督的實車競賽。
