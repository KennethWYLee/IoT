# 18 週課程規劃

課程分成三段：第 1-9 週完成智慧停車場 MVP，第 10-12 週加做自動教室占用與節能異常偵測，第 13-18 週進入期末專題開發，並在第 14、16 週穿插 Raspberry Pi Pico 小車課程。

## 第 1-9 週：共同核心

| 週次 | 主題 | 產出 |
|---:|---|---|
| 1 | 課程導入：低成本 IoT、互動系統、智慧停車場案例、採購與安全 | 分組、系統架構圖、BOM 草案 |
| 2 | ESP32-S3 開發環境、GPIO、Wi-Fi | ESP32-S3 可連 Wi-Fi 並控制基本輸出 |
| 3 | MQTT / HTTP / Web 控制 | ESP32-S3 可回報狀態並接收指令 |
| 4 | 伺服馬達與閘門控制 | 手機或網頁控制閘門開關 |
| 5 | RGB LED、蜂鳴器、按鈕、OLED 選用 | 車位燈、警示音、手動操作或空位顯示 |
| 6 | 紙板停車場模型與資料模型 | 建立車位表、車輛 ID、進出事件格式 |
| 7 | 手機視覺：手機當相機、筆電讀影像 | 成功取得停車場影像 |
| 8 | OpenCV：ROI、顏色/輪廓、QR 或 ArUco | 判斷至少 3 個車位空/滿 |
| 9 | 期中 Demo | 車位辨識 + 閘門/燈號 + dashboard + 事件紀錄 |

## 期中最低標準

- 手機拍攝停車場模型。
- OpenCV 判斷至少 3 個車位空/滿。
- ESP32-S3 控制閘門或燈號。
- Dashboard 顯示車位狀態。
- 有進出紀錄或事件紀錄。

## 第 10-12 週：第二個 IoT 專案

第二專案為「自動教室占用與節能異常偵測系統」。此專案不靠按鈕或 RFID 判斷是否使用中，而是用 PIR、光敏與溫濕度資料推論教室狀態。

| 週次 | 主題 | 產出 |
|---:|---|---|
| 10 | DHT11、KY-018、HC-SR501 感測器整合 | ESP32-S3 可回傳溫濕度、亮度、近期是否有人活動 |
| 11 | 狀態推論規則與 dashboard | 自動判斷使用中、空置、疑似忘關燈、舒適度異常 |
| 12 | 第二專案 Demo / 技術診所 | 教室占用與節能異常偵測 MVP |

## 第 13-18 週：專題開發與 Pico 小車穿插

| 週次 | 主題 | 產出 |
|---:|---|---|
| 13 | 期末 proposal / 回報 0 | 延伸題目、BOM、風險、分工、最低可行版本 |
| 14 | Pico 小車工作坊 1：小車控制與 IoT 化 | 了解 Pico 小車控制、馬達、感測與遠端控制概念 |
| 15 | 專題進度回報 1 | 核心資料流跑通：視覺/感測 -> 後端 -> dashboard 或 ESP32-S3 |
| 16 | Pico 小車工作坊 2：移動平台與專題延伸 | 小車任務、避障/遙控/狀態回傳，連到自走車或 ROS 2 概念 |
| 17 | 專題進度回報 2 / 展示彩排 | 可展示原型、測試紀錄、文件、備用影片 |
| 18 | Demo Day | 作品展示與反思報告 |

第 13、15、17 週為兩週一次的專題回報節點；第 14、16 週的 Pico 小車課程作為移動平台補充，不要求所有期末專題都改做自走車。

## 期末延伸方向

- 智慧停車場完整版。
- 夾娃娃機或互動遊戲機台。
- 自走車進出停車場。
- 倉儲貨位辨識。
- 座位占用偵測。
- 置物櫃管理。
- 腳踏車或機車停放管理。
- 實驗室設備借還管理。
- 教室占用與節能稽核系統。
