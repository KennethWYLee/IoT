# 18 週課程規劃

課程分成兩段：第 1-9 週教共同核心，第 10-18 週讓學生利用上課時間開發期末專題。

## 第 1-9 週：共同核心

| 週次 | 主題 | 產出 |
|---:|---|---|
| 1 | 課程導入：低成本 IoT、互動系統、智慧停車場案例、採購與安全 | 分組、系統架構圖、BOM 草案 |
| 2 | ESP32-S3 開發環境、GPIO、Wi-Fi | ESP32-S3 可連 Wi-Fi 並控制基本輸出 |
| 3 | MQTT / HTTP / Web 控制 | ESP32-S3 可回報狀態並接收指令 |
| 4 | 伺服馬達與閘門控制 | 手機或網頁控制閘門開關 |
| 5 | RGB LED、蜂鳴器、按鈕、OLED 選用 | 車位燈、警示音、手動操作或空位顯示 |
| 6 | 紙板停車場模型與資料模型 | 建立車位表、車輛 ID、進出事件格式 |
| 7 | 手機視覺：手機當相機、筆電讀影像 | 成功取得停車場影像 |
| 8 | OpenCV：ROI、顏色/輪廓、QR 或 ArUco | 判斷至少 3 個車位空/滿 |
| 9 | 期中 Demo | 車位辨識 + 閘門/燈號 + dashboard + 事件紀錄 |

## 期中最低標準

- 手機拍攝停車場模型。
- OpenCV 判斷至少 3 個車位空/滿。
- ESP32-S3 控制閘門或燈號。
- Dashboard 顯示車位狀態。
- 有進出紀錄或事件紀錄。

## 第 10-18 週：專題開發

| 週次 | 主題 | 產出 |
|---:|---|---|
| 10 | 期末 proposal | 延伸題目、BOM、風險與分工 |
| 11 | Sprint 1：核心資料流 | 視覺/感測 -> 後端 -> ESP32-S3 跑通 |
| 12 | Sprint 1 demo / 技術診所 | 老師逐組檢查可行性 |
| 13 | Sprint 2：差異化功能 | 預約、收費、告警、機構、自走車等 |
| 14 | 資料庫、API、dashboard 強化 | 查詢、紀錄、管理介面 |
| 15 | Sprint 3：整合測試 | 完整流程跑通 |
| 16 | 異常測試與維運 | 錯誤處理、log、重啟、測試紀錄 |
| 17 | 展示彩排 | GitHub、BOM、影片、簡報 |
| 18 | Demo Day | 作品展示與反思報告 |

## 期末延伸方向

- 智慧停車場完整版。
- 夾娃娃機或互動遊戲機台。
- 自走車進出停車場。
- 倉儲貨位辨識。
- 座位占用偵測。
- 置物櫃管理。
- 腳踏車或機車停放管理。
- 實驗室設備借還管理。
