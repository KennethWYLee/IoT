# 18 週課程規劃：IoT 玩具與互動硬體設計

## 一、課程目標

學生從 ESP32-S3、安全接線、感測器與致動器開始，先做出不依賴網路的
互動硬體，再逐步加入 HTTP、WebSocket、MQTT、後端、Database、
structured log 與手機操作。期末題目由學生自行決定，但必須同時展示
實體行為與有明確用途的軟體。

軟體的用途至少包括下列一項，完整期末作品原則上應包括兩項：

1. 記錄感測值、狀態、操作、錯誤、得分或其他事件，並可查詢歷史。
2. 協助使用者即時監看、設定模式、發出命令或確認執行結果。

## 二、共同資料流

```text
感測器／按鈕／手機輸入
  -> ESP32-S3
  -> 燈、聲音、顯示、舵機或馬達
  -> Wi-Fi + HTTP 或 MQTT
  -> 學生自行撰寫的 Backend
  -> Database + structured log
  -> WebSocket
  -> 手機前台

手機命令
  -> Backend 記錄與派送
  -> ESP32-S3 判斷並執行
  -> 回傳成功、失敗或 timeout
  -> 手機更新結果
```

## 四、第 2-6 週硬體學習順序

五週不要求學生建立後端或使用WebSocket。教學依下列順序累積：

1. 全部週次的實作內容定稿後，反推共同材料需求；第 1 週公布正式材料清單，
   課後完成材料與開發環境準備。第 2 週才開始硬體操作，快速驗證環境、
   程式上傳與 Serial，再確認GND、麵包板、按鈕輸入與GPIO輸出命令。
2. 第3週以KY-018板上的`R1`與光敏電阻完成電表量程與斷電電阻比較；
   接續3V3量測、5Vin外部輸入辨識、GPIO LOW／HIGH實測及Reset後啟動命令觀察
   與ADC原始值。收尾用必買電阻包中的1kΩ、10kΩ各一顆搭分壓，斷電交換上下位置，
   比較預測與實測；只用3V3、GND與電表，不接GPIO。5kΩ只保留計算示例，不另購。
3. 第4週先辨識220 Ω與330 Ω各一顆、斷電量測並比較量程；不重做第3週分壓。
   再處理KY-018與DHT11的感測資料是否可信，而不是只看「有數字」。DHT11是
   共同必做，資料腳使用母對母線直連已驗證GPIO，供電與共同GND經麵包板保留測點；
   相容供電、邏輯準位及腳位依指定模組profile，不先猜接線規格。
4. 第5週每人分段操作RGB、蜂鳴器、SG90與4AA電源，分別觀察顏色、發聲／停止、
   受限動作及供電變化；不只選一種輸出替代共同學習，也不越過供電與安全驗證。
5. 第6週把輸入、判斷與輸出組成可重複玩的單機作品，兩顆按鈕分任START與實體STOP。

這五週的作品可以很小，例如反應遊戲、光控轉盤、環境提示器或自動閘門。
學生不必每週購買新模組，同一批材料可以重新組合。

上述新增任務是2026-09-05核准的設計調整，未增加採購、週次或評量項目。
課卡中的[材料任務對照](../course_materials/teacher_18_week_materials.md#required-hardware-activities)
記錄每項用途、證據與教材待辦。220 Ω／330 Ω任務依最新決定由設計中的Week 3移至Week 4，
已與DHT11母對母操作整合於Week 4主教材；Week 2／3檔案不改。Week 4的實機profile與新操作仍待驗，
Week 5～6保留後續重整。各層檢查見[Week 4紀錄](../lab_notes/2026-09-05-week4-material-review.md)。

## 六、期末作品最低要求

- 一個可安全運作的實體作品，以及可解釋的使用情境。
- ESP32-S3 或經教師核准的控制板。
- 至少一種實體輸入與一種實體輸出；例外須在第7週獲准。
- Wi-Fi，以及 HTTP 或 MQTT 裝置通訊。
- 學生自行撰寫、可重新啟動的 Backend。
- Database、歷史查詢與 structured log。
- 手機可用前台，至少包含即時狀態、歷史資料、操作或設定，以及錯誤／離線呈現。
- WebSocket 即時更新；有控制行為時需記錄 command、result／ack 或 timeout。
- 至少一項自動反應、狀態機或排程。
- 至少三種測試情境，其中一種是斷線、錯誤輸入、感測異常或服務停止。
- 原始碼、接線圖、資料流圖、資料格式、BOM、重建步驟、AI 使用與驗證紀錄、已知限制。

Blynk、ThingSpeak、Node-RED 或現成 Dashboard 可以作輔助，但不能取代
學生自行撰寫的裝置端、Backend、Database 與手機介面核心成果。

## 八、教師示範與進階方向

- 智慧停車與 UCI K-4 4WD：感測、馬達控制、事件紀錄與手機監看。

- ROS 2、Gazebo、Nav2：完成本課資料與控制架構後的機器人進階路線。
