## 5. 停車場事件資料格式

| 欄位 | 範例 | 說明 |
|---|---|---|
| event_type | start / collision / parked / finish | 事件類型 |
| time_ms | 15230 | 從開始到事件發生的時間 |
| zone | left_wall / slot / gate | 事件位置 |
| count | 2 | 碰撞次數或累積值 |
| result | success / fail / running | 目前結果 |

範例 JSON：

```json
{
  "event_type": "collision",
  "time_ms": 15230,
  "zone": "left_wall",
  "count": 2,
  "result": "running"
}
```
