# IoT 課堂教材包

> **版本狀態：舊版，待重寫。** 本資料夾目前仍以學生共同製作 UCI 4WD
> 自主停靠為主，不符合現行 Full-stack IoT 課表，暫時不得直接發給學生
> 或作為評量依據。現行週次以 `../18_week_plan.md` 為準。

本資料夾放「可直接上課」的教材，不取代課程規劃文件，而是把規劃轉成每週可以使用的教案、任務單、評分表與檢核表。

## 使用順序

1. 先看 `teacher_18_week_materials.md`，確認每週課堂流程、材料、任務與交付物。
2. 上課前從 `student_worksheets.md` 複製當週任務單給學生。
3. 期中與期末評分使用 `rubrics_and_checklists.md`。
4. 實作週可搭配 `starter_code_snippets.md` 的 ESP32-S3 程式骨架。
5. 若要正式發給學生，可再把對應週次轉成 PDF 或 LMS 頁面。

## 教材定位

- 課程名稱：物聯網與雲端運算。
- 對象：資管學生，程式能力可接受，硬體經驗弱。
- 主板：ESP32-S3-DevKitC-1 N16R8。
- 共同場景：考試用智慧停車場、UCI K-4 4WD 倒車入格與側向停靠挑戰。
- 期末方向：不限車或停車場，但必須是可連網、可觀測、可測試的 IoT 互動系統。
- 教學法：Type B learning loop，以 HOT question、BIT、同儕檢查、延後回饋與 learning evidence 為核心。

## 成功標準

學生修完課後應能：

1. 分辨開發板、感測器、致動器、模組、dashboard、broker、server 的角色。
2. 安全完成 ESP32-S3 基本接線，知道 GND、3.3V、5V、限流與分壓的用途。
3. 建立會回報狀態或接收指令的 IoT 裝置。
4. 做出能記錄碰撞、時間與事件的考試用智慧停車場。
5. 組裝 UCI 4WD、完成左右輪組校正，並用狀態機參加兩項自主停靠任務。
6. 用資料流圖、BOM、測試紀錄、log 與展示腳本說明自己的期末專題。
