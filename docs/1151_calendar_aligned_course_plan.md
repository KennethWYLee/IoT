## 4. 第 7-9 週

第7週每組只到場一次，進行第一次專題報告，說明作品、使用者、實體輸入
與輸出、軟體紀錄／操作、材料、風險及最低可驗收結果，並展示一個可運作
硬體片段。第8週全週只進行第一次個人筆試，檢查Week 2至6的硬體接線、
GPIO／GND、電氣量測、輸入品質、致動器供電、狀態機與安全，不考網路或後端
架構，也不安排新進度或實作。第9週不要求學生到校，也不新增評量成果。
