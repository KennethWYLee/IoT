# Lab Notes

實機實驗以 `YYYY-MM-DD-short-topic.md` 建檔。這些紀錄是兩台電腦交接的
依據；聊天內容不視為永久硬體狀態。

## Template

```text
# YYYY-MM-DD Topic

- Computer／workspace:
- Hardware IDs:
- Exact board／modules:
- Power source／measured voltage:
- GPIO and logic levels:
- Toolchain／library versions:
- Firmware commit:

## Goal

## Wiring／data flow

## Checks performed
- compile:
- upload／target:
- physical behavior:
- failure／recovery:

## Evidence

## Problems and changes

## Physical state after shutdown

## Next action
```

完成後同步更新 `../hardware_state.md`。不可提交 Wi-Fi 密碼、token、API
key、學生個資或未授權影像。
