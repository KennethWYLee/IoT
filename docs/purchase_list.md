# 採購清單

目標：每人整學期 NT$800 內。若 3-4 人一組，每組共同必買材料建議控制在約 NT$600-1,200，不含期末自願加購。

價格為 2026-05-14 依蝦皮賣場初步查詢的粗估區間，採購前仍需確認選項、庫存與運費。

## 不列必買

- Raspberry Pi。
- Jetson。
- LiDAR。
- ESP32-S3-CAM。
- Pixhawk。
- 無人機。
- 小車底盤。

視覺辨識先使用學生手機與筆電完成。

## 環島科技賣場初步選項

目前已確認可在環島科技賣場找到或相近搜尋到：

- SG90 舵機：買「全塑膠齒輪 180 度」，不要買 360 度。
- 40P 彩色杜邦線。
- 400 孔麵包板。
- RGB 全彩 LED 模組。
- HC-SR04 超音波模組。
- 有源蜂鳴器模組。
