## 作品 A：各自收到命令的兩台裝置

沿用光敏模組、START／STOP 按鈕與 RGB。兩台裝置使用不同代號 A、B，手機可各自查看光線資料、開始及停止指定裝置。

### 預期結果與驗證

| 操作 | 應看見的結果 |
|---|---|
| 兩台同時上線、各自遮光 | 能辨認讀值屬於哪一台，不互相覆蓋 |
| 只對 A 送開始命令 | A 變綠並回覆；B 維持原狀 |
| 只對 B 送停止命令 | B 變紅並回覆；A 維持原狀 |

## 重送與故障時的作品反應

沿用作品 A、B。每次只改一個條件，恢復正常後再測下一項。

| 測試 | 預期結果 |
|---|---|
| 同次開機，立即重送相同代號、相同內容的命令 | 重送原結果，不再做一次狀態轉換；最近八筆結果保存在記憶體 |
| 送出缺右大括號的訊息 | 裝置拒絕解析，RGB 不改變 |
| 送出未定義的 spin_forever 命令 | 回覆拒絕及原因，不執行 |
| 停止 broker，再按實體 STOP | 本機仍可停止，不須等待 broker 恢復 |
| 按住實體 STOP，再送 reset | 拒絕 reset，保持停止；放開後才可重新要求 reset |
| 只停止 bridge | broker 可收到新資料，手機及資料庫不因此取得新資料 |
