# Week 17：期末展示與個人問答

日期：2026-12-30　占學期成績 25%。

所有組別本週各展示一次，每位組員接受個人問答，只計一次第三次報告成績。教師依實際組數公布順序與時段；本週不新增進度、功能開發或額外實作。

所有組別使用第一組展示前、教師公布的共同截止時間已提交之 commit 或 tag。截止後只可修復啟動、網路或設備故障，不能增加評分功能；修復另記內容與重測結果。

## 要展示怎樣的作品？

安全、可重複的實體互動作品，配合手機介面、後端、資料庫，以及 WebSocket 和 HTTP 或 MQTT。作品能展示正常操作、自動反應、故障與復原，並說明已知限制。

## 預期成果與驗證

使用者實際操作後，裝置、手機、歷史資料與紀錄能互相對照。命令可查到最終結果或逾時，不用按鈕顏色代替實體成功。依文件能重新啟動系統；電源、絕緣、線材、網路與離線備案先檢查。
