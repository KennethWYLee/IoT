# Week6：兩件作品完整互動動畫

[下載離線動畫 HTML](index.html)；GitHub 檔案頁不會執行 HTML，直接觀看請開下方學生網頁。

[學生線上網頁：兩件作品的3D動畫與Ans](https://iot-week6-two-works.wy-lee9591.chatgpt.site)

同一頁提供 Q1 定時感應餵食器模型、Q2 自動遮陽板。預設從 Q1 播到 Q2，合計約90秒；也可選一件作品、暫停、拖曳時間或點選左邊步驟。

左邊始終列出完整操作與預期反應，標示目前步驟。右邊同步顯示立體紙模型、操作鈕、STOP、人工開關外接電源、RGB、原始讀值與程式的 OLED 文字，並用中文說明畫面的意思。

- Q1：空筒與光線設定 → 準備、開電、裝少量紙球 → 開始10秒一輪 → 先靠近、後到時出料 → 完成保持 → 取消／按住 → STOP與人工關電 → RST後重新設定 → 先到時、後靠近出料 → 完成與關電。
- Q2：記錄強弱光 → 準備與開電 → 強光遮陽／弱光採光 → 手動收起 → 光線改變仍保持 → 恢復自動 → 中間讀值保持 → STOP → 人工關電。

這是以實際教學程式搭配模擬輸入產生的重播，紙件轉動與紙球數量另作示意；不能代替供電、不卡料、實際行程及停止測試。動畫中的420、1100是模擬數字，不是全班共同設定。光敏確認遮光，不辨識動物；N 是開關動作完成次數，不是重量或落料顆數。舊 Q1～Q4 GIF 留存為歷史版本，現行題目以這兩件作品為準。

HTML 已包含所需資源，可下載後離線開啟；保留兩個授權檔。若要從離線動畫開 Main／Ans，保留本週目錄結構，將動畫放在 animations 子資料夾，兩份 PDF 放在上一層。學生線上網頁可直接播放動畫並開啟 Ans；該網頁不提供 Main 或 Arduino 程式。GitHub 已同步本版 Main／Ans 與動畫；舊 GIF 是歷史版本，不代表現行必做題目。
