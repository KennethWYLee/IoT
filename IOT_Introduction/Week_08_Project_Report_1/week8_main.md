# Week8：實作考材料準備

每組帶一套既有器材，組內共用。以下只公告要帶的材料；題目與驗收方式另行公布。

## 電子零件

| 品項 | 每組數量 |
|---|---:|
| ESP32-S3 開發板 | 1 片 |
| 麵包板 | 1 片 |
| USB 資料線 | 1 條 |
| 杜邦線：公對公、公對母、母對母 | 各一排 |
| 四腳按鈕 | 2 顆 |
| 四針 I2C OLED | 1 片 |
| KY-018 光敏模組 | 1 個 |
| DHT11 溫濕度模組 | 1 個 |
| RGB 模組，沿用 Week5 的 HW-479 類型 | 1 個 |
| SG90 位置型舵機，含舵盤與螺絲 | 1 個 |
| HW-508 蜂鳴器模組 | 1 個 |
| 1 kΩ 電阻，保留阻值標示 | 1 顆 |

## 舵機供電與電腦

帶四槽 AA 電池盒（含開關）、同類型及同新舊的 1.5 V AA 電池 4 顆、既有降壓模組，以及已備妥的電源連接線材。供電組沿用 Week6、7 的核對結果。

帶筆電與充電器，保留 Arduino IDE、ESP32 套件及已用過的程式庫。

## 紙材與工具

- **紙板一小片**：當模型底板，可畫車道。
- **不透光紙卡一張**：剪成小車外形，能遮住光敏的感光面。
- **A4 白紙 1～2 張**：剪輕紙條，作模型柵欄。
- **剪刀、膠帶、筆**：裁切、固定與標示。

可使用既有紙盒裁片。紙上活動部分使用輕紙，避免讓舵機帶重物。
