## 兩地環境比較器
**作品：**在 A、B 兩個位置各按一下，保存光線、溫度與濕度。OLED 顯示兩筆資料及「B 減 A」的差；RGB 表示記到哪一步。本題不用舵機。

本週從空麵包板開始。依序練習保存與比較、持續判斷與暫停、切換感測器控制指針，最後以 Q4 練習排錯。可現場或用手機展示，不另交影片網址。

| 操作／狀態 | 預期結果 |
|---|---|
| 開機，取得有效資料後 | 等待 A，藍燈；尚未保存的欄位顯示 -- |
| 在 A 等溫濕度更新，按一下 | 保存 A；綠燈表示等待 B |
| 到 B 等溫濕度更新，按一下 | 保存 B；紅燈表示兩筆齊全，交替顯示資料與 B−A |
| 不按按鈕，只改變環境 | 目前值更新，A、B 不變 |
| 再按一下 | 開始新一組 A，舊 B 不再用於比較 |

長按只保存一次；讀值失效時不保存，也不進下一步，OLED 說明未保存。RGB 顏色在本題表示保存進度，不是環境好壞。

**驗證示例：**A 是 26°C、50%，B 是 27°C、55%，差應為 +1°C、+5 個百分點；這是示例，不替代實測。光敏整數只比較同一模組的讀值，不換成照度。

**完成後回答：抄一項 A、B 實測值與 B−A；不按按鈕改變環境後，哪一組數字保持不變？**

## 可以暫停的環境提醒器
**作品：**OLED 持續顯示光線與溫濕度；RGB 用顏色提醒狀態。按鈕可暫停燈光提醒，但不停止感測與畫面更新。本題不用舵機。

### 正常運作時的優先順序
同時符合多項時，只顯示下表由上往下第一項。溫濕度門檻是教學設定，不是健康標準。

| 條件 | OLED 文字／RGB |
|---|---|
| 資料無效或光線分界未設 | CHECK INPUT／紅 |
| 溫度 > 28°C | TEMP HIGH／紅 |
| 濕度 > 65% | RH HIGH／紅 |
| 以上都沒有，且被判為遮光 | SHADE／藍 |
| 以上都沒有 | NORMAL／綠 |

等於 28°C 或 65% 不算超標。光線依本組量測設定分界與方向，等於分界歸沒遮光；原始讀數 0、4095 先視為需檢查，不據此斷定故障。

**暫停時：**OLED 顯示 PAUSED，RGB 全熄滅；目前讀值及狀態文字照樣更新。再按一下恢復，依當下狀態顯示燈色；長按只切換一次。

**驗證：**遮光、移開，觀察文字與燈色；暫停後改變光線，確認只有燈停止提醒。無法安全產生的溫濕度條件可紙上檢查，不算實測。

**完成後回答：暫停時改變光線，哪個顯示仍改變？恢復後燈色是否依當下資料更新？**

## 可切換感測器的紙指針
**作品：**同一支輕紙指針可顯示光線或溫度。按鈕切換用途，OLED 顯示 LIGHT／TEMP 與位置；藍燈表示光線模式，綠燈表示溫度模式。

| 模式 | 指針位置 |
|---|---|
| LIGHT | 沒遮光 0、遮光 6；依本組分界與大小方向，等於分界歸沒遮光 |
| TEMP | <25°C 為 0；25°C～未滿 28°C 為 3；≥28°C 為 6 |

<aside class="safety">只帶動輕紙，不加連桿或負載。先預覽；教師確認外接電源、共地、固定、STOP 與行程。外接電源關閉時啟用，看到位置 0 允許開電後才開電，再按一下開始跟隨。</aside>

**驗證：**先在 LIGHT 遮光再移開；放開再按切至 TEMP，看位置是否符合目前溫度。此時只遮光，指針不應因光線改變；再按才回 LIGHT。動作至少隔 1 秒，長按只切換一次。

兩種資料與設定都有效才能啟用；啟用後任一資料失效、OLED 失聯、按 STOP 或滿 30 秒，都保持停止，不能自行恢復。**看到停止或畫面失聯，立即切斷外接電源。**

**完成後回答：溫度模式時只改變光線，你實際看到什麼？切回光線模式後有何不同？**
