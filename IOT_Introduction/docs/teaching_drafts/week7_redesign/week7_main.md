## Q1．包裹環境看板
**作品：**把光敏與 DHT11 放在可開合的小紙箱內，OLED 放箱外，讓收件人看到箱內的光線、溫度與濕度。

**每組準備：**一個可重複開合的小紙箱、A4 白紙 1 張、剪刀、膠帶與筆，並帶既有電子零件、SG90 舵機及完整外接供電組。白紙做輕紙旗，箱蓋用手開合。從空麵包板開始，先在箱外確認電路，再固定感測器及開導線孔，不能夾住或拉扯導線。

光敏模組把光線變化轉成訊號電壓，ESP32 把電壓讀成 0～4095 的整數 **RAW**。DHT11 回報攝氏溫度 **T（°C）**與相對濕度 **RH（%）**；OLED 是顯示文字的小螢幕。ESP32 負責讀取與顯示，本題不接按鈕、RGB 或舵機。

### 預期結果
| 操作 | OLED 應有的結果 |
|---|---|
| 開機，等第一筆成功的 DHT 資料 | RAW、T、RH 有數字；等待時 T／RH 為 -- |
| 關箱，再開箱 | RAW 隨箱內光線改變，不預設變大或變小 |
| 不操作，繼續觀察 | 畫面持續更新；不保存、不計次、不警報 |

### 驗證與回答
1. 每次開、關箱停約 2 秒；確認 RAW 能看出兩種情況的差別。
2. 溫濕度有合理數字即可，不要求短時間改變，不加熱或加水。

**本組關箱 RAW：______　開箱 RAW：______**

若開箱後數字幾乎不變，你會先檢查光敏在箱內的位置、箱外光線，還是 DHT？說明一個具體檢查。

## Q2．包裹開啟紀錄器
**作品：**OLED 顯示目前判為開箱或關箱，以及這次監測的開啟次數。光敏提供判斷資料，ESP32 記次；操作鈕先設定兩種光線，再開始監測。本題不用 DHT、RGB 或舵機。

**開始方式：**關箱按一下記關箱光線；開箱按一下記開箱光線。再關箱、等約 2 秒，按一下開始。前兩次按鈕是設定，不算開箱次數；開箱中不能開始監測。

兩筆設定至少相差 100 個 RAW，否則顯示 TOO CLOSE: RETRY，要改善光敏位置或箱外光線後重做。程式依本組數字分辨方向；新狀態連續穩定 0.5 秒才成立。後續開、關箱各停約 2 秒。

### 預期結果
| 操作 | OLED／次數 |
|---|---|
| 完成設定，關箱後開始 | BOX:CLOSED、OPEN COUNT:0 |
| 開箱並保持穩定 | BOX:OPEN、次數變 1 |
| 持續開著 | 次數仍 1，不每次讀取都加 1 |
| 關箱，再開箱 | 關箱仍 1；再開變 2 |
| 按住操作鈕 | 監測中不清除次數；重新啟動才歸零 |

**驗證：**示範「關 → 開 → 保持開著 → 關 → 再開」，確認只增加兩次。OLED 中斷後須修好、關箱再按開始；中斷期間不能算已監測。

**完成後回答：**為什麼持續開著只算一次？請用「前一個狀態」與「現在的狀態」說明，不必重抄讀值。

## Q3．開箱提示旗
**作品：**不用一直看螢幕，也能看見目前是否開箱。光敏判斷箱內光線；ESP32 送位置命令；舵機只帶動箱外的輕紙旗。開箱升旗、關箱降旗，OLED 顯示目前狀態與命令。

紙箱蓋仍用手開合。旗子不能遮住光敏；本題不記次、不保留警示，也不接 DHT 或 RGB。

<aside class="safety">只帶輕紙旗，不帶動箱蓋、重物或連桿。舵機使用已核對的獨立電源，正極不接 ESP32 的 3V3／5V。另接 STOP 鈕；它停止控制訊號，不切斷電源，停止後仍須人關外接電源。</aside>

### 預期結果
| 操作 | OLED／紙旗 |
|---|---|
| 完成關箱／開箱設定；關箱等穩定 | BOX:CLOSED；尚未啟用，不動旗 |
| 外接電源關閉，按操作鈕準備 | ON OK DOWN；看到允許後才由人開電 |
| 開電後再按一下，開始監測 | 關箱，紙旗在降下位置 |
| 開箱，各停約 2 秒 | BOX:OPEN、COMMAND:UP；紙旗升起 |
| 關箱，各停約 2 秒 | BOX:CLOSED、COMMAND:DOWN；紙旗降下 |

**驗證：**連續做開、關箱；確認旗子跟隨現在狀態，不需要每次按鈕。操作鈕只用於設定、準備與開始，不能代替開箱。

位置命令至少隔 1 秒；準備起算 30 秒後鎖定停止，不因再次按鈕延長。按 STOP、OLED 失聯或程式讀值超出本題有效範圍也停止；保持外接電源關閉、放開兩鈕、RST 後才重新準備。OLED 命令不代表實物已到位。

## Q3．紙旗與停止驗證
<pre class="screen">PARCEL FLAG
RAW:420
BOX:OPEN
TARGET:UP
COMMAND:UP
SESSION:18 s</pre>
**模擬示例，不是實測。**本示例開箱 RAW420；本組可能相反。TARGET 是希望的位置，COMMAND 是最後送出的命令；實際到位要看紙旗。

1. 關箱開始監測後，開箱、關箱各停約 2 秒，確認紙旗升起、降下。
2. 開箱保持不動，不應持續來回轉。按住操作鈕也不改成手動升旗。
3. 按 STOP，立刻關外接電源；放開後再按操作鈕，不能自行恢復。

若旗子抖動、卡住、發熱或 ESP32 重啟，立即關外接電源，斷電檢查。不要用手硬扳舵盤或以取消停止條件通關。

**完成後回答：**關箱後，本題旗子會降下；這能告訴後來的人「剛才曾開箱」嗎？說明目前狀態與過去事件的差別。

## Q4．異常保留與人工確認
**作品：**讓收件人知道監測開始後是否曾開箱。沿用光敏、OLED、紙旗、操作鈕與 STOP，再加 RGB。RGB 是紅綠藍燈；本題綠燈表示尚無待確認事件，紅燈表示曾開箱、尚未確認。不接 DHT。

ESP32 保存「曾開箱」這件事；關箱只改變目前狀態，不清除事件。操作鈕在本題開始監測後，改為人工確認；只在關箱穩定後才接受確認。

### 預期結果
| 操作 | OLED／RGB／紙旗 |
|---|---|
| 設定、關箱準備、開電、開始監測 | BOX:CLOSED、ALERT:NONE；綠燈、降旗 |
| 開箱並保持穩定 | BOX:OPEN、ALERT:OPENED；紅燈、升旗 |
| 開箱時按操作鈕 | CLOSE FIRST；警示不清除 |
| 關箱，不按鈕 | BOX:CLOSED，ALERT 仍 OPENED；仍紅燈、升旗 |
| 關箱穩定後按一下確認 | ALERT:NONE、CONFIRMED；綠燈、降旗 |
| 再開箱 | 再次紅燈、升旗；舊確認不豁免新事件 |

**驗證：**開箱觸發後，先在開箱狀態嘗試確認，再關箱觀察保留，最後按鈕解除。旗子仍遵守至少 1 秒的命令間隔；立即變燈後可稍等旗子動作。

**完成後回答：**BOX:CLOSED 與 ALERT:OPENED 同時出現，分別代表什麼？這時還要做什麼才能解除警示？

## 展示與收納
**四題展示不同結果：**Q1 看目前數字；Q2 看開啟次數；Q3 看目前狀態的旗子；Q4 看曾開箱且尚未確認的警示。溫濕度只需在 Q1 成功顯示，不用刻意加熱改值。

Q4 與 Q3 使用同一套獨立供電、STOP、30 秒時限與至少 1 秒命令間隔。停止後不保證旗子回到降下位置；先由人關電，不能用確認鈕重新啟用。RST 是 ESP32 板上的重新啟動鍵；它會清掉 RAM 中的次數、設定與警示，不是正式交付確認。

### 光線與箱蓋
這個模型利用開箱進光來推測箱蓋狀態。先證明本組開、關箱光線能分辨；完全黑暗的房間開箱可能也沒有變化，漏光或移動也可能改變讀值，不能把文字或紅燈當成防竊證據。

RAW 是電壓轉出的整數。關箱較暗時可能到 0 或 4095；本週顯示並允許用兩種實測狀況設定，不因單一端點就斷定接線錯誤。兩種情況幾乎一樣時不能開始。程式也不能可靠地偵測光敏線鬆脫；展示前與發現異常時須檢查實物。

### 結束後
按 STOP，關閉並拔除舵機外接電源，再拔 USB。全部斷電後拆下旗子、感測器、模組與跳線，分類收納，留下空麵包板。剪裁紙箱時先取出電路，不用尖銳工具對著元件開孔。
