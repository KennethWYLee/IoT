## Week7．感應開蓋與開箱警示

本週做兩個完整作品。**Q1 讓紙蓋自動開關；Q2 讓收件人知道箱子曾被打開。**同一組零件換位置與程式，不必同時做兩套。

### 必要 IoT 設備
ESP32-S3 1 片、USB 資料線 1 條、麵包板 1 片、杜邦線、光敏模組 1 片、OLED 1 片、RGB 模組 1 片、四腳按鈕 2 顆、SG90 舵機 1 顆、電池盒與電池 1 組、已核對的降壓板 1 片。DHT 與蜂鳴器不用接。

### 必要文具
可開合小紙箱 1 個、A4 白紙 2 張、小片不透光紙、剪刀、膠帶、筆、少量小紙球。箱子可以重複使用。

| 元件 | Q1 免接觸垃圾桶模型 | Q2 包裹開箱警示 |
|---|---|---|
| 光敏 | 放箱外，遮光模擬靠近 | 放箱內，用進光推測開箱 |
| 舵機 | 帶輕紙蓋，不帶原本厚箱蓋 | 只帶紙旗；箱蓋由人開合 |
| OLED | 顯示自動／手動、感應與倒數 | 顯示目前箱況、次數、待確認事件 |
| RGB | 綠：待機；藍：開啟／手動；黃：倒數或待確認光線 | 綠：無待確認事件；紅：有待確認事件 |
| 操作鈕 | 設定後切換手動保持開啟／自動 | 設定後在關箱時確認事件 |
| STOP | 停止控制；人立刻關舵機外接電源 | 同左；不是確認或清除事件 |

ESP32 負責讀資料、判斷與送命令。外接電源供舵機，不由 GPIO 供馬達電力。RST 是板上重啟鍵，不是第三顆新增按鈕。

先依 Ans 從空麵包板接起，確認不裝紙件的舵機能轉出與返回，再裝紙件。換作品或改線前，先關閉並斷開全部電源。

## Q1．免接觸垃圾桶模型
**情境：**手拿著東西時，希望不用碰蓋子就能投入；更換內袋時，又需要蓋子保持開啟。

用箱外光敏感應點模擬靠近。遮住後開輕紙蓋；移開後等 3 秒再關蓋。只投小紙球。這是光線模型，不測距，也沒有真正的防夾功能；手與遮光紙留在蓋子行程外。

### 預期結果
| 操作 | 應看到 |
|---|---|
| 自動待機，沒有遮光 | 輕紙蓋關閉、綠燈、BIN AUTO |
| 遮光並保持穩定 | 開蓋、藍燈、SENSOR:COVERED |
| 移開，確認沒遮光後 | 蓋子保持開啟、黃燈；CLOSE IN 從 3 秒往下數 |
| 倒數中再次遮光 | 取消關蓋倒數，保持開啟 |
| 再次移開 | 重新完整倒數 3 秒，才關蓋回待機 |
| 按一下操作鈕 | BIN MANUAL HOLD、藍燈、保持開啟 |
| 手動時遮光或移開 | 不自動關蓋 |
| 再按一下操作鈕 | 回自動；沒遮光時重新倒數，不立刻關蓋 |

新光線狀態須穩定 0.5 秒；尚未穩定或位於中間區間顯示 WAIT，取消關蓋倒數，不把舊 CLEAR 當成現在沒遮光。這不能保證偵測鬆線或障礙物。

關閉命令已送出後再遮光，須確認遮光且滿足 1 秒命令間隔，才送重新開啟命令；不是即時防夾。整理投入口或內袋前，先 STOP 並人工關電。

**驗證：**先示範「遮光 → 移開倒數 → 再遮光取消 → 再移開完整倒數」，另做一輪手動保持與恢復自動。每輪示範前看懂步驟，不要求在同一輪趕完全部。

**完成後回答：**蓋子還開著但已移開遮光物，可能是倒數還沒結束，也可能是手動模式。你會看 OLED 哪一行分辨？

## Q2．包裹開箱警示
**情境：**收件人回來時，箱子可能已經關好。只看現在的箱蓋，無法知道監測期間有沒有被打開。

光敏改放箱內，朝箱蓋開口。**人開箱、關箱；舵機只帶箱外輕紙旗，不能拉箱蓋。**開箱時記次並保留警示；關好箱子不會自動解除。

### 預期結果
| 操作 | 次數／OLED／RGB／紙旗 |
|---|---|
| 關箱開始監測 | N:0、BOX:CLOSED、ALERT:NONE；綠燈、降旗 |
| 開箱並保持穩定 | N:1、BOX:OPEN、ALERT:OPENED；紅燈、升旗 |
| 持續開著 | N 仍是 1，不會每次讀取都增加 |
| 開箱時按操作鈕 | CLOSE FIRST，警示保留 |
| 關箱，不按鈕 | BOX:CLOSED；仍紅燈、升旗，ALERT 仍 OPENED |
| 關箱穩定後，放開再按操作鈕 | CONFIRMED、ALERT:NONE；綠燈、降旗，N 仍是 1 |
| 再開箱 | N:2，再次紅燈、升旗 |

**按住等待不算新的確認。**開箱時按住操作鈕，再關箱，警示仍保留；須放開再按。光線 WAIT 時也不能確認。設定光線時的開箱不算監測事件。

BOX 是目前已確認的光線判斷，ALERT 是尚未確認的過去事件，N 是本輪開箱次數。CMD 是最後送出的旗子命令，不是實物位置量測；RGB 可能先改變，紙旗命令仍遵守至少 1 秒間隔。

**驗證：**第一輪示範「開箱 → 關箱但保留警示 → 按鈕確認」。關電、RST、重做設定後，第二輪測試開箱時按住不能自動確認，放開重新確認後再開箱，次數應加一。

**完成後回答：**BOX:CLOSED、ALERT:OPENED、N:1 同時出現，分別代表什麼？確認後哪個數字不應歸零？

## 兩顆按鈕，四次設定操作

下表四次都按 **GPIO5 操作鈕**，每次按完放開。GPIO6 是 STOP，不用來設定。文字 CLEAR／COVER／CLOSE／OPEN 是 OLED 提示，不是四顆按鈕。

| 次序 | Q1 | Q2 |
|---|---|---|
| ①記錄第一筆 | 沒遮光，等 RAW 穩定後按 | 關箱，等 RAW 穩定後按 |
| ②記錄第二筆 | 遮住光敏，穩定後按；之後移開 | 開箱，穩定後按；之後關箱 |
| ③準備命令 | 等 SENSOR:CLEAR；電池 OFF，按準備 | 等 BOX:CLOSED；電池 OFF，按準備 |
| 人工開電 | 看 ON OK CLOSED，開電並確認紙蓋關閉 | 看 ON OK DOWN，開電並確認紙旗降下 |
| ④開始作品 | 按操作鈕進入 AUTO | 按操作鈕開始監測，N 從 0 起 |

③不是開電。**SESSION 從③準備起算 30 秒**，包含人工開電與確認時間；④之後才運作，但不重新給 30 秒。TIMEOUT 到期即停止。再做一輪須關電、放開兩鈕、按 RST，重做兩筆光線設定。

PREVIEW: POWER OFF 表示仍是保護預覽，舵機不動。須依 Ans 完成教師供電、接線、行程與設定核對，不是多按幾次就能啟動。

### 停止與限制
按 STOP 時立刻人工關外接電源，不等畫面。停止後不保證紙蓋關閉或紙旗降下；Q2 熄燈不代表事件已確認。放開 STOP 或再按操作鈕不能重啟。

RAW 是電壓讀出的整數，不是照度。兩筆至少差 100，方向可以相反；室內光線改變或感測器移位就重新設定。開箱沒有進光時可能測不到，不能當防竊證據。

最後關閉並拔除外接電源，再拔 USB，全部斷電後拆紙件、模組與線材，留下空麵包板。實作考日期與要求另行公告，不由本週題目推定。
