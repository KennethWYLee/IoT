## Q1．兩地環境比較器
**作品：**在 A、B 兩個位置各按一下，保存當時的光線、溫度與濕度。OLED 交替顯示兩筆資料與「B 減 A」；RGB 燈表示保存進度。本題不用舵機。

光敏模組輸出隨光線變化的訊號電壓，ESP32 把電壓讀成整數 RAW，本週程式範圍為 0～4095。DHT11 回報溫度 T（°C）與相對濕度 RH（%）。ESP32 執行程式、保存與計算；按鈕送保存要求，OLED 小螢幕顯示文字，RGB 紅綠藍燈只顯示進度。

本週從空麵包板開始。先比較兩地資料，再做可暫停提醒與可切換的紙指針；Q4 沿用提醒器核對最近原因。可現場或用手機展示。

| 操作／狀態 | 預期結果 |
|---|---|
| 開機，取得有效資料後 | 等待 A，藍燈；尚未保存的欄位為 -- |
| 在 A 等新溫濕度，按一下 | 保存 A，綠燈表示等待 B |
| 到 B 等新溫濕度，按一下 | 保存 B，紅燈表示兩筆齊全；交替顯示 A、B 與 B−A |
| 不按按鈕，只改變光線 | 目前值 NOW 更新，保存的 A、B 與差值不變 |
| 再按一下 | 立即保存新 A、亮綠燈；舊 B 不再顯示或比較 |

長按只保存一次；讀值失效時顯示 NOT SAVED:CHECK INPUT，不進下一步。修好後放開再按，成功保存才清除提示。紅燈表示兩筆齊全，不是警報；重啟清除 A、B。兩地溫濕度差可為 0，不代表失敗。

**示例，不是實測：**A 為 26°C、50%，B 為 27°C、55%，差為 +1°C、+5 個百分點。百分點是兩個百分比直接相減的差；RAW 只比較同一光敏模組的整數，不換成照度。

**完成後回答：**用本組一項 A、B 與 B−A，說明不再按下時，保存值與目前值有何不同。

## Q2．可以暫停的環境提醒器
**作品：**OLED 持續顯示光線與溫濕度；RGB 改為提醒目前環境，不再表示保存進度。按鈕暫停／恢復燈光，感測與畫面不停止。本題不用舵機。

### 預期狀態
同時符合多項，只顯示下表由上往下第一項。28°C／65% 是教學門檻，不是健康標準。

| 條件 | OLED／RGB |
|---|---|
| 資料無效或光線分界未設 | CHECK INPUT／紅 |
| 溫度 > 28°C | TEMP HIGH／紅 |
| 濕度 > 65% | RH HIGH／紅 |
| 以上都沒有，且判為遮光 | SHADE／藍 |
| 以上都沒有 | NORMAL／綠 |

等於溫濕度門檻不算超標。光線分界是區分兩種情況的整數；方向是遮光後 RAW 變大或變小，依本組量測設定。等於分界歸沒遮光；RAW 為 0／4095 會顯示 CHECK INPUT，不算 SHADE，也不能據此斷定故障。

### 驗證作品
1. 溫濕度未超標時，遮光、移開應是 SHADE／藍、NORMAL／綠。室內已超標，可在測試前暫調門檻高於目前讀值；註明設定，測完恢復 28°C／65%。
2. 按一下暫停：PAUSED、RGB 熄滅。改變光線，RAW 仍更新；狀態仍按優先順序判斷。
3. 放開再按，按當下狀態恢復燈色；長按不反覆切換。不能安全產生的條件只作紙上核對。

**完成後回答：**引用暫停及恢復前後的畫面，說明哪些結果仍依目前資料更新。

## Q3．可切換感測器的紙指針
**作品：**用同一支輕紙指針顯示光線或溫度。舵機接收 ESP32 的位置命令，帶動指針；固定刻度紙讓人看它停在哪一格。OLED 顯示模式與命令，RGB 表示模式。

本題有**操作鈕**與另一顆 **STOP 鈕**。前者準備控制、開始跟隨，再切換模式；STOP 要求停止控制訊號。停止後仍須由人關外接電源。

| 模式 | 預期位置與燈色 |
|---|---|
| LIGHT（光線） | 沒遮光 0、遮光 6；藍燈 |
| TEMP（溫度） | <25°C 到 0；25°C～未滿 28°C 到 3；≥28°C 到 6；綠燈 |

光線依本組分界與方向，等於分界歸沒遮光。0～6 是已核對安全範圍內的七格，不是角度量測；OLED 的 POS 是最後送出的格位命令，不能代替查看實物。

<aside class="safety">只帶輕紙，不接重物或連桿。先做畫面預覽；由教師核對舵機供電、共同 GND、固定、STOP 與行程。舵機用獨立外接電源，不用 ESP32 的 3V3／5V 供馬達。共同 GND 是相接的電壓參考，兩個電源正極仍須分開。</aside>

**預覽：**尚未由教師填好行程並重新上傳時，畫面為 PREVIEW；操作鈕只切換 MODE，不送舵機控制訊號。

**開電順序：**教師核對後，外接電源仍關閉；兩種資料有效時第一次按操作鈕初始化起點。看到 **ON OK POS:0**、手離開指針，才由人開電；第二次按跟隨 LIGHT，後面每次按切換 LIGHT／TEMP。

**停止條件：**按 STOP、啟用滿 30 秒、OLED 失聯或任一感測資料失效，都鎖定停止。30 秒從第一次初始化起算；切模式不重算。看到停止或畫面失聯，立即關外接電源。

## Q3．驗證兩種指針用途
<pre class="screen">MODE:TEMP
ON OK POS:3
TRACK 18s</pre>
**畫面示例：**正在跟隨溫度，最後送出格位 3，剩 18 秒；不保證實物已到位。

1. 依前頁開電、開始跟隨。在 LIGHT 遮光與移開，各停至少 2 秒，查看固定刻度上的 6、0。
2. 放開再按切 TEMP；看目前溫度落在哪段，核對實際格位。只遮光、溫度未跨段時，指針不應因光線改變。
3. 再按回 LIGHT，應回應當下光線。長按只切換一次；兩次移動至少隔 1 秒。
4. 按 STOP，立即關外接電源。放開 STOP、再按操作鈕，不應重新控制。停止後須保持外接電源關閉，放開兩顆按鈕、按板上的 RST 重啟，核對後重做準備。

RST 是 ESP32 板上的重新啟動鍵，不是操作鈕或 STOP。一般室內可能只有一段溫度，不需要加熱湊三段；用目前溫度驗證即可。

兩種感測資料都要有效，不只檢查正在使用的模式。若遮光使 RAW 到 0／4095，程式會保守停止，不能當成已成功到 6；先關電，再核對資料與接線。抖動、卡住、發熱或板子重啟也直接關電，不用手扳指針。

**完成後回答：**溫度未跨段時，只改變光線，你看到指針怎樣？切回 LIGHT 後有何不同？引用本組觀察。

## Q4．保存最近的提醒原因
**短實作：**回到 Q2 提醒器，OLED 的 LAST 顯示 ESP32 最近記住的有效提醒原因，不加入檔案或網路。接續 Q3 時，先關閉、拔除外接電源與 USB，拆舵機及 STOP，再換回 Q2 程式。

ESP32 自動記住 TEMP HIGH、RH HIGH 或 SHADE，OLED 只負責顯示。按鈕仍只暫停／恢復 RGB，不負責保存；原因存在工作記憶體，重新啟動會清除。

**預期結果：**目前回到 NORMAL，LAST 保留剛才原因；有效的新提醒會更新 LAST。CHECK INPUT 不算新的環境原因，不覆蓋已存原因。暫停時 RGB 熄滅，讀值、目前狀態與 LAST 照樣更新。

<pre class="screen">NORMAL
LAST:SHADE</pre>
**示例，不是實測：**目前正常，最近曾判為遮光。

### 驗證作品
1. 先用 28°C／65% 門檻；若溫濕度提醒蓋過遮光，依 Q2 在測試前暫調並註明。遮光再移開：目前由 SHADE 回 NORMAL，LAST 仍為 SHADE。
2. 暫停後重做遮光、移開，確認 RGB 不亮，兩種原因顯示仍依規則更新。再遮光時 LAST 仍是 SHADE 屬正常；自然出現不同原因時再核對更新，不要求湊齊三種。
3. 移開遮物、確認溫濕度未超標，按 RST；LAST 回 NONE，直到下一個有效提醒。不把重新上傳清掉記憶體當成新原因覆蓋。

**完成後回答：**引用一次本組「目前狀態」與 LAST 不同的畫面，說明哪個描述現在、哪個描述以前的提醒。
