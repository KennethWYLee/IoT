## Week 7：整理成能展示的作品
**作品：**沿用上週的環境顯示與紙指針，不加新元件。這週把接線固定好，確認同一個程式能完成已學過的全部功能。

**作品特色：**OLED 顯示光線與溫濕度；RGB 表示光線狀態；按鈕保存資料並推進紙指針；另一顆按鈕停止舵機控制。

<aside class="safety">改線前關閉外接電源並拔 USB。舵機仍遵守先預覽、教師確認行程、外接電源關閉時啟用、最多 30 秒及 STOP 後切斷電源的規則。</aside>

### Q1．完成一段連續展示
| 展示順序 | 預期結果 |
|---|---|
| 開機，舵機外接電源先關閉 | OLED 可讀；溫濕度尚未取得時顯示「--」 |
| 遮住光敏，再移開 | OLED 判斷及 RGB 回應一致 |
| 安全啟用舵機，再做一次按下、放開 | 保存當次資料，指針和 OLED 位置同步 |
| 不按按鈕，只改變光線 | 目前光線改變，保存資料與位置不跟著變 |
| 按停止按鈕，再關外接電源 | 顯示停止，原按鈕不會恢復舵機控制 |

可用現場操作或手機展示；不要求另交影片網址。

**完成後回答：這段展示還有哪個功能不符合預期？已全部完成，就寫出最後修好的那一個問題及修正方式。**
