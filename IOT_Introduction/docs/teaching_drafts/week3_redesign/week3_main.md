## 遮住光，電腦怎麼知道？
> Week 3：用電表看到電壓，再讓 ESP32 讀到變化。

上週按下按鈕，電腦出現「按下」或計數增加。這週不按按鈕，改用一張不透光的紙，看看電腦能不能分辨室內光與遮光。

{{diagram:overview}}

| 我們依序做 | 要看到的結果 |
|---|---|
| 用電表量 3V3 和 GPIO5 | 電源電壓，以及程式切換的高、低電壓 |
| 接光敏模組，再用紙遮住 | 電表讀值及電腦數字是否改變 |
| 用自己的數據設定規則 | 畫面出現「室內光／遮光／未判定」 |
| 交換兩顆固定電阻 | 解釋光敏模組為何能改變電壓 |

<aside class="note">今天不用馬達、舵機、Wi-Fi、OLED 或蜂鳴器。先完成「感測 → 程式判斷 → 紀錄」；它是之後軟體控制作品的基礎。</aside>

**一起做的方式：**跟著每頁的接線、動作與預期結果同步操作。做完一小段，再讀「做完再講」。尚未完成的數值留白，不抄示例當實測。

## 收起按鈕，換一個問題
> GPIO4、GPIO5 這週要換用途，不能沿用計數器接線。

1. 拔掉 ESP32 的 USB，移除電池及其他外部供電，確認 PWR 燈熄滅。
2. 電表轉 OFF，移開表筆。拍下舊作品接法後，拆除開發板所有外接線。
3. 拿空的 400 孔麵包板。板子放在乾燥、不導電桌面，不直接插進麵包板。
4. 按鈕先收起來；本週不需要按住任何按鈕來量電壓。

| 現在拿出來 | 數量 |
|---|---:|
| 圖示 ESP32-S3 開發板、USB 資料線、筆電 | 各 1 |
| 萬用電表、400 孔麵包板 | 各 1 |
| 公對母／公對公／母對母杜邦線 | 各數條 |
| KY-018 光敏模組、不透光的紙 | 各 1 |
| 電阻包中的 1 kΩ、10 kΩ | 各 1 顆 |

<aside class="safety">以後每次改線：先移開表筆 → 拔 USB 與其他電源 → 確認 PWR 熄滅 → 電表 OFF → 才移線。關閉 Serial Monitor 不等於斷電。</aside>

**本週三個用途：**3V3 給小型感測模組供電；GPIO5 暫時輸出高／低電壓；GPIO4 稍後讀光敏訊號。這些用途不是同時接上舊按鈕。

## 黑筆、紅筆、旋鈕各放哪裡？
> 這次量電壓，不是量電流，也不是聽通斷聲。

V 是電壓單位「伏特」。20 V 檔是量測範圍，不是電表會輸出 20 V。

{{photo:A830L_1.jpg|82|課堂 A830L 實物照片。照片旋鈕在 OFF；量測前仍須自己選檔。}}

| 位置 | 這次設定 |
|---|---|
| 黑表筆插孔 | COM；此表下方中間 |
| 紅表筆插孔 | VΩmA；此表下方右邊 |
| 旋鈕 | 直流電壓 20 V：找 V 與實線／虛線符號，不是 V~ |
| 10A 插孔 | 保持空著 |

**COM 是電表的共用參考端，並不會自己連到板子的 GND。**等一下要由黑表筆碰到 GND 的延長線，兩者才連起來。

<aside class="safety">本週完全不使用 A／mA 電流檔，也不量插座或市電。表型不同時看自己的符號與說明，不照照片角度猜。先設好，再將表筆放旁邊。</aside>

## 兩條線，把電源位置引出來
> 麵包板只讓表筆比較好碰，不會自己製造電源。

{{diagram:power}}

| 先後 | 起點 → 終點 | 接頭 |
|---|---|---|
| 1 | ESP32 GND → a3 | 母頭套排針，公頭插孔 |
| 2 | ESP32 3V3 → a6 | 母頭套排針，公頭插孔 |
| 3 | e3 → 一條公對公線的自由端 | 黑筆稍後碰這個自由端 |
| 4 | e6 → 另一條公對公線的自由端 | 紅筆稍後碰這個自由端 |

**同列 a～e 相通。**a3 與 e3 是同一位置的延伸；a6 與 e6 是另一組。第 3 列和第 6 列不可用線直接相連。兩個自由金屬端要分開固定。

一起核對表格及列號，確認沒有其他線或元件跨接第 3、6 列。若做通斷複查，只能在拔 USB 時做；供電與 GND 持續蜂鳴時保持斷電排查。**不蜂鳴也不是完整安全保證。**

<aside class="safety">表筆不要硬塞進麵包板。不要讓延長線金屬端互碰，也不要一邊通電一邊整理線。</aside>

## 黑筆固定，紅筆只碰一個端點
> 先猜：3V3 相對 GND，會接近 0 V 還是 3.3 V？

1. 電表確認為直流 20 V。插上板背標示 COM 接頭的 USB。
2. 黑筆碰 **e3 延長線**的自由金屬端。
3. 紅筆碰 **e6 延長線**的自由金屬端，不碰旁邊排針。
4. 接觸穩定後記錄完整畫面與單位，再移開紅筆。

{{diagram:voltage}}

| 黑筆 | 紅筆 | 檔位 | 預期 | 我的結果 |
|---|---|---|---|---|
| e3，GND | e6，3V3 | 直流 20 V | 約 +3.3 V | ____ V |

課堂舊紀錄曾回報約 3.2 V；那是另一輪操作，不是你應照填的答案，也不是本次實測。

**如果是負數：**先移開表筆，核對紅黑測點，不交換板子的供電線。**如果接近 0 V：**移開表筆、斷電，核對 USB、PWR、3V3 印字與列號。

下一頁不改線，先解釋剛才這個數字。

## 電壓是比較兩個位置
> 不是「紅筆裡面有 3.3 V」，也不是「流過了 3.3 A」。

電表在直流電壓檔顯示：**紅筆位置的電位 − 黑筆位置的電位**。本週把 GND 當共同的 0 V 參考。

| 紙上情境，不必重新接線 | 計算 | 顯示 |
|---|---|---|
| 紅筆 3V3、黑筆 GND | 3.3 − 0 | +3.3 V |
| 紅筆 GND、黑筆 3V3 | 0 − 3.3 | −3.3 V |
| 兩筆碰同一個 3V3 節點 | 3.3 − 3.3 | 0 V |

第三列不表示板子沒電，只表示兩個測點的電位相同。GND 也不是讓電流憑空消失的地方，它接回電源回路。

{{diagram:meterpath}}

**為什麼電表跨接 3V3 和 GND 不等於短路？**電壓檔內部有很大的輸入電阻，只取很小的電流。普通杜邦線的電阻很低，不能拿來代替電壓表。

<aside class="safety">上圖只是比較電路，不實作直接短接。若把電表切到電流檔，內部路徑不同，就不能照剛才的方式跨接電源。</aside>

## 換一支會切換電壓的程式
> 上週 GPIO5 是減一按鈕；現在先讓它成為輸出。

1. 移開表筆、拔 USB、電表 OFF。從開發板拔下外接線；麵包板的延長線可以留著。
2. 在 Arduino IDE 選 **File → Open**，開啟隨課程提供的 <a href="../../../examples/week03_gpio_voltage_cycle/week03_gpio_voltage_cycle.ino">GPIO 電壓程式</a>。完整程式也在本冊後方。
3. 找到 `PIN_TEST_OUTPUT = -1`。本稿示範接點是 **GPIO5**；只有課前已確認使用圖示板型與這個接點時，改為 `5`。未確認保留 `-1`，不猜其他數字。
4. 板子只插 COM 接頭 USB，依下表選設定，按左上方 **右箭頭 Upload**。

| IDE 位置 | 本課圖示板設定 |
|---|---|
| Tools → Board | ESP32S3 Dev Module |
| Tools → Port | 插入此板後新增的 COM，號碼不固定 |
| Flash Size／PSRAM | 16MB／OPI PSRAM |
| USB CDC On Boot／USB Mode | Disabled／Hardware CDC and JTAG |
| Upload Mode／Upload Speed | UART0 / Hardware CDC／115200 |
| Flash Mode／Partition Scheme | QIO／16M Flash (3MB APP/9.9MB FATFS) |

按 **Tools → Serial Monitor**，速度選 **115200**。預期看到 `startup=LOW`，之後約每 10 秒出現 LOW 或 HIGH。出現 `gpio_profile_missing` 是腳位仍未填，不是電路壞了。

<aside class="note">本稿沿用 Week 2 的 IDE 安裝與 Espressif 套件。尚未安裝者先完成 Week 2 安裝段；這一頁是重新選板、選連接埠與換程式的完整提醒。上傳後先拔 USB，再接下一頁。</aside>

## 加一條 GPIO5 線，量它的電壓
> 沒有按鈕、LED 或其他負載；GPIO5 只接電表量測。

{{diagram:gpio}}

| 起點 → 終點 | 現在的作用 |
|---|---|
| GND → a3；e3 → 黑筆延長端 | 恢復共同參考點 |
| 3V3 → a6；e6 延長端分開收妥 | 恢復電源測點，這段不量它 |
| GPIO5 → a12 | 新增程式控制的測點 |
| e12 → 新的公對公延長線 | 紅筆稍後碰這個端點 |

每條外接線照表恢復，特別確認 GPIO5 不是 5Vin。第 12 列不能直接接到第 3 列或第 6 列。

**這就是舊教材的 TPO：**只是「方便量 GPIO 輸出的地方」，不是另一個電子零件，也不是資料到電腦必經的位置。本稿直接稱它 **GPIO5／第 12 列**。

<aside class="safety">先確認舊按鈕已拆除。GPIO5 若輸出 HIGH 時仍被按鈕直接接 GND，會造成過大電流的風險。不要沿用計數器接線。</aside>

## LOW、HIGH，電表真的不同嗎？
> 先猜：哪個階段接近 0 V？哪個接近 3.3 V？

1. 確認接線後插 COM USB，開 Serial Monitor，選 115200。
2. 電表選直流 20 V。黑筆碰 e3 的延長端；紅筆碰 e12 的延長端。
3. 看 `phase=LOW` 或 `phase=HIGH`，等讀值穩定再記錄。不要把切換瞬間的跳動值當穩態。

| 次數 | phase | 預期電壓 | 實測電壓 |
|---|---|---|---|
| 1 | LOW | 約 0 V | ____ V |
| 1 | HIGH | 約 3.3 V | ____ V |
| 2 | LOW | 約 0 V | ____ V |
| 2 | HIGH | 約 3.3 V | ____ V |
| 3 | LOW | 約 0 V | ____ V |
| 3 | HIGH | 約 3.3 V | ____ V |

**再看一次啟動：**移開兩支表筆，按一下板上的 RST，保存重新出現的 `startup=LOW` 文字。這裡只看啟動紀錄，不重做整張電壓表。

<aside class="note">`expected_voltage=near_3.3V` 是程式寫出的預期，不是 ESP32 已幫你量過。電表穩態讀值也不能證明 Reset 瞬間完全沒有短脈衝。</aside>

完成後拔 USB、電表 OFF。下一頁不接新線，先看兩份證據的差別。

## 一個命令，兩種證據
> Serial 說「我要求 HIGH」；電表說「我量到幾伏特」。

{{diagram:command}}

| 程式中的動作 | 對應剛才哪件事 |
|---|---|
| `pinMode(..., OUTPUT)` | 指定 GPIO 用來輸出，不再讀按鈕 |
| `digitalWrite(..., HIGH/LOW)` | 要求輸出高／低準位 |
| `millis()` 的時間差達 10000 | 約等 10 秒才切換一次 |
| `Serial.printf(...)` | 把命令與次數送到電腦 |

**3V3 和 GPIO5 不相同。**3V3 是供電腳；GPIO5 是訊號腳，電壓由程式控制。讀到約 3.3 V，不代表 GPIO 可以當一般 3.3 V 電源帶動馬達或模組。

**自己回答：**如果 Monitor 顯示 HIGH，電表卻是 0 V，能說程式完全正確、接線也正確嗎？先斷電查腳位、列號和上傳版本，不能只相信文字。

下一段要讀光敏訊號。保持斷電，拆除 GPIO5 → a12 與 e12 延長線；3V3、GND 兩列稍後繼續使用。

> 模組先放桌上，不插麵包板，不接 USB。

## 不接電，也能先看阻值變化
> 這裡改用 Ω 檔；ESP32、USB、電池都不能接在模組上。

Ω 是電阻單位「歐姆」；k 表示一千，所以 1 kΩ = 1000 Ω。200k Ω 是量程，不是模組一定有 200 kΩ。

1. 黑筆仍插 COM，紅筆仍插 VΩmA。先選 **200k Ω**，不是直流 20 V。
2. 黑、紅筆各碰指定排針，手只握絕緣部分。固定接觸後，用紙遮住感光面，不碰動排針。
3. 同一組測點依序比較「室內光 → 遮光 → 移開紙」。換測點時也保持模組不接電源。

| 測哪兩腳 | 室內光 | 遮光 | 移開紙 |
|---|---|---|---|
| 中間 ↔ S | ____ kΩ | ____ kΩ | ____ kΩ |
| S ↔ − | ____ kΩ | ____ kΩ | ____ kΩ |
| 中間 ↔ − | ____ kΩ | ____ kΩ | ____ kΩ |

記下**檔位、完整小數點與單位**。200k 檔例如顯示 `10.0`，通常是 10.0 kΩ，仍以自己的表型說明為準。若超出量程顯示 `1`／`OL`，不要寫成 1 Ω；提高量程或保存「超量程」。

**先看變化，不求精密驗證：**本課既有接法預期中間 ↔ S 比較固定；S ↔ − 隨光線改變。沒有變化先查遮光與接觸，不交換供電腳來試。

量完電表 OFF，表筆放旁邊。下一頁把三組結果放回電路。

## 光敏模組裡有兩個電阻
> 剛才量的三組腳，是兩段電阻及它們的總路徑。

{{diagram:kycircuit}}

**上面的固定電阻：**接在中間供電腳與 S 之間。**下面的光敏電阻：**接在 S 與 − 之間。S 是兩者中間的位置，不是新的電源。

| 剛才量的路徑 | 這張圖的對應 |
|---|---|
| 中間 ↔ S | 上面一段 |
| S ↔ − | 下面一段 |
| 中間 ↔ − | 兩段串聯的總路徑 |

同樣光照與接觸下，總阻值應大致接近兩段相加。三次量測若光照變了、手碰到金屬或量程不同，不能把差異當成精密驗證通過。

**先保留一個問題：**兩段之間的 S，供電後會是多少 V？不用先背公式，下一段直接量。公式等固定電阻實作後再算。

## 遮住之後，電壓升還是降？
> 先猜一次，再用自己的讀值回答。

## 量到之後，再算一次
> 這裡只量中間電壓，不使用 ADC，也不量電流。

確認接法後插 USB。電表選直流 20 V，黑筆碰 e3 延長端，紅筆碰 e23 延長端。我的結果：______ V。保存接線照片後移開表筆。

**為什麼預期約 0.3 V？**電流先經上面 10 kΩ，再經下面 1 kΩ，最後回到 GND。兩顆串聯，流過它們的電流相同；比較大的電阻分到比較大的電壓差。

計算先定義：供電電壓 **Vs**，上方電阻 **R上**，下方電阻 **R下**，中間相對 GND 的電壓 **V中**。

```text
V中 = Vs × R下 ÷ (R上 + R下)
    = 3.3 V × 1 kΩ ÷ (10 kΩ + 1 kΩ)
    = 0.3 V
```

| 位置 | 理想電位 | 該電阻兩端差值 |
|---|---:|---:|
| 供電端 → 中間 | 3.3 V → 0.3 V | 上方電阻：3.0 V |
| 中間 → GND | 0.3 V → 0 V | 下方電阻：0.3 V |

電表量的是中間到 GND，所以對應**下方電阻的電壓差**。若實際供電不是 3.3 V，用自己量的 Vs 與阻值重算，不把差異直接當成錯接。

下一頁要交換電阻。**先拔 USB、確認 PWR 熄滅、電表 OFF。**

## 同一條路，電流不會先被用掉
> 電阻限制整條串聯路徑的電流，不是把 3.3 A 變成小一點。

{{diagram:current}}

**I 是電流，單位 A；V 是電壓差，單位 V；R 是電阻，單位 Ω。**歐姆定律在這個電阻電路中寫成 **I = V ÷ R**，不是 V × R。

```text
I = 3.3 V ÷ (10000 Ω + 1000 Ω)
  = 0.0003 A = 0.3 mA
```

這是理想計算，不是電表實測電流。交換上下位置，總阻值不變，所以理想總電流仍相同。

| 紙上比較，不實際新增接線 | 判斷 |
|---|---|
| 3V3 → 兩顆串聯電阻 → GND | 有控制電流的阻值，是本次正常電路 |
| 3V3 → 普通導線 → GND | 電源被低阻路徑直接接通，這就是短路 |
| 路徑中拔掉一端 | 斷路，這條路不再形成完整回路 |

短路**可能**造成發熱、保護動作或損壞；不代表每次一定燒壞。沒有外加電阻也不等於 R=1 Ω，導線電阻可能遠小於 1 Ω，實際電流還受電源與接觸限制。

## 看數字，也說出判斷的限制
> 對照上一頁的同一組假資料，不代替自己的實測結果。

**1. 分界 720。**(440 + 1000) ÷ 2 = 720。遮光在較高一側；本程式低側包含等號，因此 raw=720 判室內光，但它落在兩段基準之間，quality 為 suspect。

**2. 分類與原因：**

| raw | 標籤 | 紀錄該怎麼看 |
|---:|---|---|
| 430 | 室內光 | 在室內基準內；relative_only |
| 800 | 遮光 | 超過 720，但在基準之間；suspect |
| 4095 | 未判定 | 端點；suspect，不直接宣稱斷線 |

**3. 兩個問題：**raw 是 ADC 整數，不能移動小數點當成精確伏特；800 雖依規則被標成遮光，卻不在任何已觀察基準內，不能保證真實條件。

**4. 中間理想 3.0 V。**3.3 × 10 ÷ (1 + 10) = 3.0。黑筆插 COM 並碰 GND 延長端 e3；紅筆插 VΩmA 並碰中間延長端 e23；選直流 20 V。接線前 USB 拔除，核對後才供電量測。

**5. 不可用電流插孔／檔位跨接電源。**保持斷電，將紅筆插回 VΩmA、選直流 20 V，再依正確電壓接法核對。不是只改旋鈕、忘了插孔。

**回到作品：**哪一筆數據最能讓你看出「程式有標籤」不等於「已確認環境」？說明 raw=800 的原因，比只背答案更重要。

## 停在哪一步，就查那一步
> 改線前都先斷電。不一次換線、換程式、換設定。

| 現象 | 先做什麼 |
|---|---|
| 電阻檔顯示 1／OL | 模組保持斷電；檢查接觸、量程與表型說明，不記成 1 Ω |
| 電壓負號 | 移開表筆、核對紅黑測點；不反接模組供電 |
| 電源與 GND 持續蜂鳴 | 不通電；依五孔組、導線及元件逐一查路徑 |
| GPIO 文字切換，電壓不變 | 斷電查 GPIO5 → a12、黑筆 GND，以及已上傳的程式 |
| Monitor 沒文字或亂碼 | 查 COM 接頭、Port、115200；確認按的是 Upload 而非只有 Verify |
| gpio_profile_missing | 腳位仍是 −1。課前未確認時不猜；設定與圖示接法必須相符 |
| 量 S 卻總是電源電壓 | 紅筆是否量 e6 而非 e15？先移開表筆，改線要斷電 |
| raw 固定 0／4095 | 端點可能飽和或接法有誤；先量 S 對 GND，再斷電查線，不直接判斷斷線 |
| calibration_missing_or_overlap | 檢查四個範圍值、端點與重疊；先保留紀錄，不刪不利數字 |
| 遮光方向和舊資料不同 | 分開保存兩輪，查光線、接法、模組及接觸；不混合基準 |
| 異常發熱、異味、重啟 | 立即移除供電，停止使用並保存現象；不反覆通電嘗試 |

<aside class="safety">電表量電壓時須供電；Ω／通斷時不可供電。即使表筆插在同一個 VΩmA 孔，旋鈕不同，內部量測方式也不同。</aside>

## V、A、Ω，不要混在一起
> 本週用電表量 V 和 Ω；A 只在紙上計算。

| 問什麼 | 名稱與單位 | 例子 |
|---|---|---|
| 兩點電位差多少 | 電壓 V，伏特 | 3.3 V |
| 電荷流動多少 | 電流 A，安培 | 0.01 A = 10 mA |
| 對電流阻礙多少 | 電阻 Ω，歐姆 | 330 Ω；1 kΩ = 1000 Ω |

**單一電阻的紙上例子：**330 Ω 兩端相差 3.3 V，則 I = 3.3 ÷ 330 = 0.01 A，不是 0.1 A。若 R = 1 Ω，理想計算才是 3.3 A；沒外接電阻不能自行當成 1 Ω。

### A830L 常見 Ω 量程判讀示例

| 檔位 | 示意畫面 | 解讀 |
|---|---|---|
| 200 Ω | 61.0 | 約 61.0 Ω |
| 20k Ω | 1.00 | 約 1.00 kΩ = 1000 Ω |
| 200k Ω | 10.0 | 約 10.0 kΩ = 10000 Ω |
| 任一 Ω 檔 | 最左側 1，或其他表的 OL | 可能超量程或未接通，不是一般的 1 Ω |

實際顯示形式依表型而異，紀錄「61」卻不寫檔位，別人就無法確定單位。電阻檔不是把電壓讀值換成另一個單位。

**有聲音就短路嗎？**同一五孔組相通，本來就會叫；供電與 GND 原本不該直接相通，卻有低阻路徑，才是需要停止供電排查的情況。

## 上傳成功，不等於感測成功
> 三個檢查，回答三個不同問題。

| 看到什麼 | 代表什麼 | 還沒證明什麼 |
|---|---|---|
| Verify 沒錯誤 | 電腦能編譯程式 | 實際接線、電壓與模組功能 |
| Upload 完成 | 程式已寫入板子 | 光線分類必定正確 |
| Monitor 與量測符合測試條件 | 這輪觀察有對應證據 | 所有器材、環境與時間都可靠 |

### Flash 與 RAM 不要把百分比相加

```text
Sketch uses 286973 bytes (21%) ... Maximum is 1310720
Global variables use 21936 bytes (6%) ... Maximum is 327680
```

這是舊編譯摘要的判讀案例，與本次設定或結果不一定相同。

**Flash 存程式，斷電仍保留。**第一行是在看目前分割設定給程式的空間，不是整顆 16 MB 都拿來當分母。

**RAM 是執行時暫存。**第二行是編譯時計入的靜態配置，不是之後執行時永遠只用 6%，也不是板上 8 MB PSRAM 的用量。

**PSRAM 是額外的 RAM。**不是 Flash，也不能由上面兩行就判斷它用了多少。21% 和 6% 分母不同，不能加成整片板用了 27%。
