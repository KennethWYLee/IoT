## Q1　桌上光線觀測器

**用途：**讓裝置上的 OLED 小螢幕顯示目前光線讀值，遮住感測器就能看見數字的變化。本題只需光敏與 OLED，不需按鈕。

光敏模組把光線變化轉成訊號電壓；ESP32 的 ADC 把這個電壓轉成整數，稱為原始讀值 **raw**。本週用 raw 比較光線變化。

本週從**空麵包板**開始。三件作品依序練習**觀察目前值、保存一筆資料、判斷並計算遮光次數**。同堂可沿用已確認接線，分別換程式展示；Q1 不需操作按鈕。

<aside class="safety">改線前拔除 USB 與其他電源，確認燈熄滅。核對實物腳名、供電與訊號電壓，不把 5 V 接到 ESP32 輸入。發熱或異味立即斷電。</aside>

### 作品要求

- OLED 持續顯示 RAW 及其整數，光線改變時更新。
- 固定位置，比較沒遮光與遮光的讀值；不預設遮光後一定變大。
- 完成成果看 OLED，Serial Monitor 只用來排錯。

### 預期畫面與驗證

| 沒遮光 | 遮光 |
|---|---|
| RAW 430<br>LIGHT | RAW 1020<br>LIGHT |

**畫面示例，不是本組量測值。**分別維持兩種情況約兩秒，確認螢幕確實更新，而不是只顯示固定數字。

### 完成後回答

展示作品。記下本組的 RAW：沒遮光 ______；遮光 ______。

## Q2　按一下留下光線快照

**用途：**按鈕替你記住當時的光線數字；環境改變後，仍能對照剛才保存的值。本題使用光敏、OLED 與一顆按鈕。

### 作品要求

- RAW 是目前讀值，持續更新。
- 每次按下保存當時的一筆；LAST 顯示最近保存值，SAVED 顯示已保存次數。
- 按住不連續保存；放開再按才接受下一次。開機按住也需先放開。
- 重啟後 LAST 為 ---、SAVED 為 0；尚未保存不能用 0 冒充結果。

### 預期畫面與驗證

| 尚未保存 | 按一下後 | 改變光線但不再按 |
|---|---|---|
| RAW 720<br>LAST ---<br>SAVED 0 | RAW 725<br>LAST 725<br>SAVED 1 | RAW 1080<br>LAST 725<br>SAVED 1 |

**畫面示例，不是實測。**先保存，再改變光線；確認 RAW 可以變而 LAST 不變。放開後再按住約兩秒，SAVED 只再加 1。最後放開並重啟，確認保存內容清除。

### 完成後回答

展示上述反應。保存後改變光線，記下同一畫面的 RAW 與 LAST。

## Q3　可以暫停的遮光計數器

**用途：**統計感測器被遮住幾次，按鈕可暫停統計，例如休息時不把動作算進去。本題使用光敏、OLED 與一顆按鈕。

### 作品要求

- 依本組沒遮光、遮光讀值設定判斷；若兩種讀值分不開，先排查，不硬算次數。
- OLED 顯示 RAW、COUNT（次數）、RUN／PAUSE（計數中／暫停）。
- RUN 時，由沒遮光變成遮光才加 1；持續遮住不連加。
- 按鈕每按一次切換 RUN、PAUSE；按住只切換一次。暫停仍更新 RAW，但不計數。
- 在已遮住時恢復 RUN 不補算；須先移開，再遮住才加 1。
- 重啟從 RUN、COUNT 0 開始；若啟動時已遮住，也先移開再遮住才計數。

### 預期結果與驗證

| 操作（每步留約兩秒觀察） | COUNT |
|---|---|
| 啟動後先沒遮光，再遮住並保持 | 1，保持不變 |
| 移開後再遮住 | 2 |
| 切到 PAUSE，移開再遮住 | 仍為 2 |
| 保持遮住，切回 RUN | 仍為 2 |
| 移開後再次遮住 | 3 |

預期次數示例。恢復 RUN 不得把暫停期間或目前的遮光補算進去。

### 完成後回答

展示暫停與恢復。保持遮住並恢復 RUN 時，你的次數有增加嗎？接著做什麼動作才增加？

## Q4　RAW 為 0，就能說完全沒有光嗎？

OLED 顯示正常，但沒遮光及遮光時，RAW 都顯示 0。本題的 RAW 是 ESP32 對光敏訊號電壓取得的 ADC 整數讀值。

請用自己的話回答：

1. RAW 是從哪一個物理量轉成的數字？能直接把 RAW 800 寫成 800 lux（照度單位）嗎？
2. 能只靠 RAW 一直為 0，就確定完全沒有光嗎？
3. 除了照明，選一項具體接線或程式設定來檢查，說明如何安全確認。
