## Week 4：看見溫度與濕度
**作品：**把上週的光線顯示器，加上溫度與相對濕度。DHT 是本週新增的溫濕度感測器；用它回答「現在周圍有多熱、多潮濕？」。

保留按鈕、光敏與 OLED。OLED 是主要畫面，電腦只用來上傳與排錯。可以查講義、資料或使用 AI；作品要實際完成。

<aside class="safety">改線前拔除 USB。DHT 的供電、訊號、GND 依這片模組的標字與資料確認，不按線色猜。不要讓水接觸電路。</aside>

### Q1．做出環境顯示器
**預期畫面**如下；數字只是示意，請顯示本組的實測值。
<pre class="screen">NOW RAW:420
T:25.0 C RH:50.0 %</pre>

| 你怎麼驗證 | 作品應有的結果 |
|---|---|
| 開機，等待感測器第一次完成讀取 | 光線、溫度與相對濕度各有數值與可辨認的名稱 |
| 遮住光敏，再移開 | 光線數字會變；溫濕度不必跟著同時改變 |
| 溫濕度尚未讀到，或讀取失敗 | 顯示「--」或明確失敗文字，不把 0 當作量到的結果 |

**完成後回答：OLED 上實際顯示多少溫度、多少相對濕度？附單位。**

## 按一下，保留這次環境資料
### Q2．加入環境快照
**作品特色：**上半部持續顯示目前資料；按一下按鈕，下半部保存當次光線及最近一次溫濕度結果。再次按下才更新保存資料。

<pre class="screen">NOW RAW:910
T:25.0 C RH:50.0 %
SAVED:1
LAST:420 #1
LAST 25.0C 50.0%</pre>
| 你怎麼驗證 | 作品應有的結果 |
|---|---|
| 先放開，再按一下 | 保存一次，保存次數增加 1 |
| 持續按住約 3 秒 | 不連續新增保存資料 |
| 放開，改變光線，不再按 | 目前光線會變，保存資料不變 |
| 再按一次 | 保存資料換成這次結果 |

**完成後回答：第一次保存的光線是多少？改變光線後，目前值和保存值各是多少？**
