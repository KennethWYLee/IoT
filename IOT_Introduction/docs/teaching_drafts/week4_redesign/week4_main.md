## Week 4：環境顯示與警報分析
本週做四件作品：**環境顯示器 → 超標提示器 → 警報紀錄器 → 電腦分析結果顯示**。每件可選 OLED 或電腦顯示。Q1～Q3 的文字可看 Arduino IDE 的 Serial Monitor；Q4 連接電腦工具後，在工具看裝置回傳，不能同時開 Serial Monitor。

每週從空麵包板開始。本堂改線先拔除全部電源；下課保存檔案、斷電、拆線。可查資料或使用 AI，但作品與紀錄須在自己的設備上驗證。

<aside class="safety">模組供電與訊號須相容本板 3.3 V。環境變化示範由教師先核對感測器規格；液體、蒸氣及凝結水不得接觸電路，不用火或直接熱風吹感測器。</aside>

### Q1．桌上環境顯示器
**作品用途：**在一個畫面看到光線讀值、溫度與相對濕度。相對濕度表示空氣中的水蒸氣相對於當時溫度下飽和程度的比例，以 % 表示。

**預期畫面示例：**RAW 是光敏訊號電壓經 ESP32 轉成的整數；T 是攝氏溫度，RH 是相對濕度。以下不是本組實測值。
<pre class="screen">RAW:420
T:25.0 C
RH:50.0 %</pre>

| 你怎麼驗證 | 作品應有的結果 |
|---|---|
| 開機，等到有效讀值 | 三種資料有名稱，溫濕度有單位 |
| 遮住光敏，再移開 | RAW 有反應；溫濕度不必跟著光線改變 |
| 尚未讀到或讀取失敗 | 顯示 -- 或失敗提示，不用 0 冒充結果 |

**完成後回答：你實際量到的溫度與相對濕度是多少？**

## Q2．環境超標提示器
**作品用途：**不必自己一直比數字，畫面直接指出溫度或濕度哪一項超過設定。

本題先用 **28°C、65%RH** 作練習門檻，不是健康或設備安全標準。只有「大於」門檻才算超標；等於未超標。任一項超過時顯示 ALERT（警報），兩項都未超過時顯示 NORMAL（正常）。

**預期畫面示例：**溫度超過、濕度未超過。
<pre class="screen">T:30.0C RH:60.0%
LIMIT T:28.0C
LIMIT RH:65.0%
TEMP:HIGH
RH:NORMAL
ALERT</pre>

| 你怎麼驗證 | 作品應有的結果 |
|---|---|
| 比較當次讀值與門檻 | 各項 HIGH／NORMAL 和比較結果一致 |
| 展示正常及至少一項超標 | 總狀態分別為 NORMAL、ALERT |
| 沒有有效讀值 | 顯示等待或失敗，不能當作 NORMAL |

可先把門檻改到目前讀值的另一側，重新上傳，核對程式判斷。這是在測試判斷規則，**不代表環境真的改變**。

要觀察真實變化，使用教師已確認的示範方式，等感測器的新讀值。若沒有超過門檻，如實記錄，不把示例當實測。

**完成後回答：選一次提示結果，寫出讀值、門檻與哪一項超標。**

## Q3．環境警報紀錄器
**作品用途：**顯示警報次數、累計時間，以及是否已按鈕確認。

**預期畫面示例：**ACK:YES 是已確認，COUNT 是次數，TIME 是程式警報狀態的累計秒數。數字只示意畫面。
<pre class="screen">T:29.0C RH:55.0%
ALERT ACK:YES
COUNT:3
TIME:80s</pre>

| 你怎麼驗證 | 作品應有的結果 |
|---|---|
| 第一次讀到超標 | 進入警報，次數增加 1，開始累計時間 |
| 持續超標，再按一下按鈕 | 次數不連續增加；標成已確認，仍是警報 |
| 讀值恢復正常 | 警報解除，累計時間停止增加 |
| 再次超標 | 次數再加 1，新警報尚未確認 |
| 讀取失敗 | 顯示 UNKNOWN（目前無法判斷），保留紀錄；不冒充恢復正常 |

按鈕只表示「我看到了」，不清除次數、不解除警報，長按不重複確認。讀取失敗時暫停計時；之後仍超標，延續原警報。

門檻沿用 Q2，測試中不改設定。開機直接計次、計時；按 RST 或重新上電歸零。

**完成後回答：展示一次警報的開始、按鈕確認與恢復。寫出最後的警報次數與累計秒數。**

## Q4．電腦分析結果顯示
**作品用途：**保留光敏、溫濕度與按鈕，電腦保存資料、分析，再將**光線、溫度各自的警報統計**送回 ESP32 顯示。

光線 RAW 大於 **3000** 時光線警報；溫度大於 **28°C** 時溫度警報，等於未超標。兩項各有次數、累計與最長時間；濕度只顯示與紀錄。本題門檻是練習設定，光敏方向及分界須用本組讀值核對。

**操作：**先連接裝置、選擇電腦的保存資料夾，再按「開始新紀錄」。每次建立不同檔名的 CSV，不覆蓋上一份。實體按鈕仍只負責確認警報。

**預期畫面示例：**OLED 每三秒切換目前讀值與統計。L 是光線，T 是溫度；COUNT 次數、TOTAL 累計秒數、MAX 最長秒數。以下不是本組實測值。
<pre class="screen">L COUNT:2
L TOTAL:7.5s
L MAX:5.0s
T COUNT:1
T TOTAL:7.5s
T MAX:7.5s</pre>

| 你怎麼驗證 | 作品應有的結果 |
|---|---|
| 按「開始新紀錄」 | 新 CSV；光線、溫度兩組統計各自歸零 |
| 遮住再移開光敏 | 只影響光線判斷；溫度仍按實際溫度判斷 |
| 一項或兩項警報時按鈕確認 | 確認當時尚未確認的警報，不取消警報或清除統計 |
| 持續同一次警報，再恢復正常 | 該項只計一次，恢復後停止該項計時；另一項獨立運作 |
| 停止，再開始新紀錄 | 保留舊檔，新檔與統計重新開始 |
| 沒有新的電腦分析結果 | 顯示等待或逾時，不能把舊統計當最新結果 |

## Q4．CSV 與警報分析報告
**CSV 是能用試算表打開的文字資料檔**：每列是一筆紀錄，每欄是時間、讀值或狀態。Q4 將 USB 收到的紀錄存成 CSV，並由同一份資料產生報告。

目前讀值頁顯示 RAW、T、RH、兩項狀態及 PC:LIVE。沒有 OLED，就核對工具的「裝置回傳」，不能只看電腦自己算出的數字。每筆新資料才更新。

### 預期成果
1. 按「開始新紀錄」後，選定資料夾出現新 CSV；新紀錄的統計歸零。
2. 新資料逐筆寫入，電腦即時更新統計並回傳裝置。
3. 按「停止紀錄」，等保存完成，再按「下載報告」。
4. 報告分列光線、溫度兩組警報結果，並附光線、溫度及濕度圖；濕度沒有警報門檻。

| 你怎麼驗證 | 作品應有的結果 |
|---|---|
| 打開 CSV | 每筆有時間；失敗讀值留空，狀態仍保留 |
| 對照電腦、報告及裝置最後結果 | 光線、溫度各自的次數、累計與最長時間一致 |
| 查看一次警報的事件紀錄 | 能找到開始、按鈕確認與恢復；未恢復如實標示 |
| USB 斷開或裝置重啟 | 標示紀錄不完整，不把缺資料當正常 |

報告只整理收到的資料，不判斷健康風險。未解除的警報如實標示，不保證量到兩次讀取間的每一瞬間。

**完成後回答：展示兩次紀錄的 CSV 與其中一份報告。分別寫出光線、溫度的警報次數、累計及最長時間，並核對三處結果。**沒有警報就如實寫 0，不編造事件。
