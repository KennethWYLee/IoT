## 4. 建議的整堂課順序

主文沿著同一個結果前進：**按一下實體按鈕，電腦收到一筆能解釋的事件紀錄；另一路 GPIO 輸出也受程式控制。**

下列時間是課堂設計估計，不是經學生試教確認的時間。以課表 13:30–16:15 的 165 分鐘安排，含 15 分鐘休息。安裝耗時仍是需要保留彈性的風險。

| 順序 | 分鐘 | 學生要理解與完成的事 | 成功證據／接到下一段 |
|---|---:|---|---|
| 1. 先看最後會得到什麼 | 10 | 教師示範按下、放開與 Serial 紀錄；指出輸入與輸出兩條路 | 能用自己的話說出本週目的，不先背名詞 |
| 2. 先讓電腦和板子互通 | 30 | 認 USB 接口，設定 IDE 與序列埠，上傳短程式，把版本 1 改成 2 | Monitor 出現自己的版本與時間；知道訊息從哪裡來 |
| 休息 | 10 | | |
| 3. 電表先測一條線 | 15 | 拔除外部電源，確認插孔與通斷檔，做筆尖分開／接觸自測 | 能分辨連通與不連通；不把蜂鳴聲一律叫故障短路 |
| 4. 測麵包板哪些孔相通 | 15 | 先預測，再測同組、相鄰列、跨中央槽 | 用三次結果解釋孔位，不靠死背紅藍線 |
| 5. 按鈕怎麼改變路徑 | 15 | 測四腳按鈕，找出原本相通的一組，再找按下才相通的兩組 | 畫出放開／按下兩種連通情況 |
| 6. 把按鈕接到 GPIO | 25 | 先說明上拉與 HIGH/LOW，再看完整輸入／輸出接線；斷電接線並由教師檢查 | 能解釋 GPIO 讀值、GND 回路及 TPO 用途；完成安全檢查才供電 |
| 休息 | 5 | | |
| 7. 對照手的動作與原始讀值 | 10 | 放開、按下、放開，觀察原始模式 | 分清電氣讀值和程式定義的 pressed；不把定時取樣當作看見所有彈跳 |
| 8. 一次按下為何可能多筆變化 | 20 | 紙上推演既有彈跳資料，再比較診斷程式中的原始變化與接受事件 | 能解釋去抖等待時間，以及測不到彈跳不代表一定沒有彈跳 |
| 9. 完成檢核 | 10 | 對照接線、紀錄與解釋，記下尚未完成的操作 | 知道自己完成什麼，以及 Week 3 將怎麼驗證輸出電壓 |

### 一項必須由教師決定的工作量調整

現有去抖要求包含 0／10／30／100 ms 的實測比較。上表 20 分鐘不足以保證每組完成四組設定、重複操作、整理與解釋。

建議課內保留相同資料的四種等待時間推演，以及一次完整的 30 ms 實測；四種參數全部實測放延伸練習。**這會改變既有必做範圍，目前只是提案，尚未修改原要求。**若教師要保留四組全部課內必做，就必須另配時間或縮減其他活動，不能靠字體縮小解決。

## 5. 版面如何服務操作

1. 每段先放目的與成功結果，再放名詞；不先列一整頁功能清單。
2. 每個操作單元固定提供：目前條件、要做的動作、預測或觀察欄、如何判讀、下一步。
3. 接線用清楚的孔位／接點圖；照片負責認實物，不取代接線圖。錯誤照片不當作主視覺。
4. 電流路徑圖與資訊流圖分開，圖名寫明是哪一種。資訊箭頭不是杜邦線，也不是電流路徑。
5. 主文中文約 12 pt、圖中文字至少約 11 pt、短程式至少 10.5 pt。不是為追求頁數而壓縮。
6. 成對輸出、短程式、表格與對應操作不跨頁。長程式提供完整可用版本，但不要佔滿主文數頁後才說怎麼用。
7. 主文預估約 18–22 頁，另有必要參考附錄；這只是設計預算，不是刪除內容的硬性指標。
8. A4 講義不是投影片；本次改善的是閱讀與桌上操作。若要求後排能讀全頁，應另製投影版，不能宣稱 A4 PDF 已滿足。

## 12. 新增雙按鈕加減計數器

### 教師要求與這版選擇

教師要求延伸既有按鈕練習，增加一鍵加、一鍵減的計數器。第 22–30 頁新增此作品，故障排查與參考資料移至第 31–32 頁；第 9、12 頁交叉引用同步調整。第 1–20 頁的操作內容沒有改動。

- 沿用 ESP32、麵包板、原按鈕與兩條公對母線；另外使用一顆既有按鈕、一條公對母及一條公對公線。不新增 OLED、Wi-Fi 或採購要求。
- GPIO4 加一、GPIO5 減一，兩腳都是 INPUT_PULLUP。本專案 GPIO5 不可同時作 TPO 輸出。上傳前斷電並拆除開發板外接線；確認新程式啟動後再斷電接線。
- 加鍵保持 e27／f27／e29／f29，減鍵放 e21／f21／e23／f23；GPIO4 → a27、GND → a29、GPIO5 → a21、公對公 b29 → a23。新兩鍵組合未做實機測試。
- 範例規則是 0～99、長按只計一次、兩鍵都放開並穩定後才接受下一次、Reset 歸零。上下限是本次教學選擇，不是硬體限制；沒有增加評量權重或正式繳交要求。
- 兩鍵共用 40 ms 穩定等待時間。程式採樣到重疊按壓後等待兩鍵放開；早已接受的第一次不撤回，不宣稱精密同時判定。啟動時按住也不直接計數。
- 先看訊息與數字，再說明變數、指定敘述、持續按住與機械彈跳的差別。補資訊流、兩路上拉電流圖、完整接線、完整程式與操作檢核。
- 原 Arduino UNO 範例的外部 5V 接線不適用本例。官方來源：Espressif GPIO、Arduino State Change Detection、Arduino Debounce，已查核官方文件及官方 docs-content 原文並列入新增頁面。
