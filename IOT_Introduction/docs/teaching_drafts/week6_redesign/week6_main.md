## Week6：餵食器與自動遮陽板

這週讓舵機帶動輕紙，做出兩件能實際操作的作品。Q1 在指定時間且等候位置被遮光時出料；Q2 依光線遮陽，並允許使用者手動介入。依各題的預期結果核對實物。

**每組準備：**A4 白紙 2～3 張、小片不透光紙、小紙盒／紙杯作支架或接料、少量小紙球、剪刀、膠帶、筆。另帶 ESP32、OLED、RGB、光敏、兩顆按鈕、SG90 舵機、麵包板、杜邦線、USB 線與完整舵機外接供電組。DHT 本週不必接。

| 元件 | 在這週的工作 |
|---|---|
| 操作鈕 | 依畫面記錄、準備與確認；之後 Q1 開始／取消，Q2 切換自動／手動 |
| STOP 鈕 | 停止舵機控制；人仍須關外接電源 |
| OLED | 顯示倒數、光線、模式與位置命令 |
| RGB | 用顏色表示狀態；文字同時說明，不只靠顏色 |
| 舵機＋輕紙 | Q1 開關紙筒下方的出料閘板；Q2 帶動一小片遮陽板 |
| 光敏 | Q1 確認等候位置被遮光；Q2 分辨較強與較弱光線 |
| ESP32／外接電源 | ESP32 決定動作；已核對的外接電源供舵機 |

**先看完整示範：**教師提供的「Week6：兩件完整作品」互動動畫。步驟清單在電腦左側、手機下方；作品旁顯示目前動作與畫面。

從空麵包板開始。改線前先關閉並拔除外接電源，再拔 USB。舵機只帶輕紙，不拉真窗簾，也不直接接 ESP32 的 3V3／5V。

兩題先做無舵機輸出的預覽，再依 Ans 完成教師核對。ON OK 表示初始位置命令已準備，不代表已開電；看到後才由人開外接電源。SESSION 是本次剩餘秒數，從首次 ON OK 起算 30 秒；STOP 或到期後都須人工關電。

## Q1．定時感應餵食器模型

**作品用途：**模擬餵食時間到了，且貓已到等候位置，才打開出料口。用支架固定紙筒，底部的輕紙閘板擋住紙球，開啟後落入下方容器。

{{diagram:feeder-model}}

光敏固定在容器前，用紙板／玩偶遮光模擬靠近；不能辨識貓，閘板與落料不可遮到它。

**作品只接兩顆按鈕：操作鈕與 STOP。**RST 是 ESP32 板上原有的重啟鍵，不是第三顆新增按鈕。EMPTY 是「沒遮住」、PRESENT 是「有遮住」的 OLED 提示；兩次都按同一顆操作鈕：

1. 舵機外接電源保持 OFF。不遮住光敏，看到 EMPTY; PRESS，等讀值穩定，按操作鈕記錄，再放開。
2. 用紙板／玩偶遮住光敏，看到 PRESENT; PRESS，等讀值穩定，再按同一顆操作鈕記錄，再放開。

這兩次只設定，還沒倒數；PRESS 都指操作鈕。STOP 時人工立刻關電。

| 從本輪開始已滿 10 秒？ | 等候位置已確認被遮光？ | 預期結果 |
|---|---|---|
| 未滿 | 否 | 繼續倒數，保持關閉 |
| 未滿 | 是 | 繼續倒數，不提早出料 |
| 已滿 | 否／不確定 | 等待靠近，保持關閉 |
| 已滿 | 是 | 執行一次出料，再關閉 |

10 秒是模擬時間；遮光須穩定 0.5 秒。RAW 後的 EMPTY／PRESENT 是判斷結果，不必按鈕；UNKNOWN 是中間讀值或尚未穩定，不算靠近。

## Q1．完整操作與驗證

①②已在前頁記錄光線。接下來仍是同一顆操作鈕，不是新的「準備鈕」或「開始鈕」：

| 次序／按之前的 OLED | 人要做什麼 | 按完後 |
|---|---|---|
| ③ POWER OFF; PRESS | 空筒、外接電源 OFF，按操作鈕準備 | ON OK CLOSED：關閉命令已準備 |
| ④ ON OK CLOSED | 人工開電，再按操作鈕確認 | READY: PRESS：待機，還不倒數 |
| ⑤ READY: PRESS | 確認閘板關閉、裝少量紙球，按操作鈕 | COUNT:10 s：才開始本輪倒數 |

READY／DONE 是待機／完成（綠燈）；COUNT／WAIT FOR CAT 是倒數／到時等靠近（藍燈）。OPENING／FEEDING／CLOSING 是開啟／維持開口／關閉（紅燈）。

| 操作／狀態 | 作品應如何反應 |
|---|---|
| 時間到且已確認靠近 | 開口維持 2 秒，再關閉；DONE，次數加一 |
| 完成後仍一直遮住光敏 | 不再出料；須放開再按鈕，開始新的 10 秒一輪 |
| 倒數中或等待靠近時按一下 | 取消這一輪，回 READY；次數不增加 |
| 開啟、出料或關閉時按鈕 | 不追加、不排隊 |
| 按住操作鈕 | 只算一次按下，不反覆開始／取消 |

CMD 是已送命令，N 是完成開關動作次數，不是紙球顆數或食物重量；同時看實物。

**分兩次啟用展示：**第一次先靠近、後到時，完成後保持遮光確認不重複，另試取消。按 STOP、人工關電、移走紙球、放開兩鈕並按板上 RST，重做光線設定與啟用後，第二次先到時、後靠近。

**回答：**時間到了，但光線仍不確定，會不會開閘？本輪完成後一直遮住，會不會再出料？

## Q2．自動遮陽板

**作品用途：**窗邊光線太強就遮陽，光線變弱就採光；使用者也能暫時要求收起。用固定紙窗框／底座，讓舵機只帶動一小片輕紙。

{{diagram:shade-model}}

光敏避開紙板與 RGB。外接電源 OFF；BRIGHT; PRESS 時給較強光，DIM; PRESS 時給較弱光，都等讀值穩定、按操作鈕再放開。這些不是按鈕名稱；RETRY 時調整照明重做兩筆。

接著按操作鈕準備；看到 ON OK OPEN，人工開電後再按操作鈕確認，**就直接進入 AUTO**。不用像 Q1 再按「開始」；多按一下會切到 MAN。OPEN 是收起採光，SHADE 是放下遮陽。

| 模式／操作 | 遮陽板 | OLED／RGB |
|---|---|---|
| 自動，較強光 | 放下 | STRONG、SHADE；綠燈 |
| 自動，較弱光 | 收起 | WEAK、OPEN；綠燈 |
| 按一下操作鈕 | 收起，暫停自動 | MAN、OPEN；藍燈 |
| 手動中改變光線 | 保持收起 | MAN；藍燈 |
| 再按一下 | 恢復自動，依目前光線動作 | AUTO；綠燈 |

STRONG／WEAK 是目前強／弱光，穩定 0.5 秒才更新目標。BETWEEN（中間讀值）或未穩定時保持最後命令；手動優先收起。命令間隔至少 1 秒，須看實物是否到位。

**展示：**按上表順序測試；恢復自動時保持強光。最後 STOP、人工關電。

**回答：**光線仍強時切到手動，遮陽板應在哪裡？恢復自動後呢？

## 看實物確認完成

| 作品 | 驗證項目 |
|---|---|
| Q1 | 單有時間到或單有靠近，閘板都保持關閉 |
| Q1 | 兩個條件同時成立才開、關一次，完成次數加一 |
| Q1 | 完成後持續遮光不重複；倒數或等待時可取消 |
| Q2 | 較強光遮陽、較弱光採光，不需再按鈕 |
| Q2 | 手動收起期間，光線不能把遮陽板放下 |
| Q2 | 恢復自動後採用當下光線，不沿用切換前的判斷 |
| 共同 | STOP 與 30 秒停止後，操作鈕不能自行重啟；立即人工關電 |

OLED 顯示命令，沒有量測閘板、遮陽板實際位置或是否真的落料；必須同時看實物。動畫是預期操作示範，不是實機測試紀錄。

每題可分次重新啟用驗證。30 秒從首次 ON OK 起算，包含開電與確認；不是作品倒數。Q1 完整一輪約 13 秒，裝料後 SESSION 至少還有 15 秒再開始；晚靠近須多留時間。不足就關電、移走紙球，再 RST 重來。

本週每題完成一件作品，不另交重複的讀值表。重新上傳、RST 或斷電會清掉設定與次數；重新記錄該作品的兩種光線。

Q1 停止控制不保證閘板已關閉；先人工關電，再移走紙球。料筒由支架承重，舵機只帶輕紙閘板。本週只做紙球與玩偶模型。

結束先關閉並拔除舵機外接電源，再拔 USB；全部斷電後拆線收納。抖動、卡住、發熱、黑畫面或重啟時立即關外接電源，交由教師檢查。
