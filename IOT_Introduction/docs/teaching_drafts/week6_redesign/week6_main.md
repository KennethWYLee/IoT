## Q1．按鈕紙指針
**每組準備：**A4 白紙 2～3 張、小片不透光紙、剪刀、膠帶與筆。白紙做輕紙指針、翻牌與刻度；不透光紙用來遮光。另帶既有電子零件、SG90 舵機及完整外接供電組。

**作品：**按一下操作鈕，讓輕紙指針依序指向左、中、右；OLED 顯示程式指定的位置。先做出手動指針，再用時間、光線與溫濕度控制不同作品。

### 每個元件做什麼？
| 元件 | 在本題的工作 |
|---|---|
| 操作鈕 | 按下要求前進到下一個位置；按住只算一次 |
| STOP 鈕 | 要求停止送出舵機控制訊號；仍須由人關外接電源 |
| ESP32 | 讀按鈕、決定位置，送文字給 OLED、送控制訊號給舵機 |
| 舵機與輕紙指針 | 舵機是能依控制訊號轉到指定位置的馬達；轉臂帶動紙指針 |
| OLED 與固定刻度紙 | OLED 顯示命令；刻度紙用來確認指針實際到哪裡 |
| USB、外接電源 | USB 供 ESP32，OLED 用 3.3 V；獨立外接電源供舵機動作 |

左、中、右是教師在已確認安全範圍內標出的三個位置，不要求轉滿 180 度。刻度紙固定不動，不能搬動刻度配合答案。

<aside class="safety">從空麵包板接起。改線前拔 USB、關閉並拔除舵機外接電源。舵機不接 ESP32 的 3V3／5V，只帶輕紙。先做畫面預覽，再請教師確認外接供電、共同 GND、固定、安全行程與 STOP；未確認不能開舵機電源。</aside>

**四題共同規則：**上傳及準備時外接電源關閉。看到 ON OK LEFT 後才由人開電。按 STOP 或從首次 ON OK 起滿 30 秒，立即關電；操作鈕不能解除停止。關電、放開兩鈕、按開發板 RST，才能重來。運作中黑畫面、抖動、卡住或發熱，也立即關外接電源。

## Q1．驗證三個位置
先依 Ans 完成接線與安全準備。**預期結果：**每次放開再按，只前進一個位置；右邊再按回左邊。

| 驗證操作 | 應看見的結果 |
|---|---|
| 外接電源關閉，先做畫面預覽 | PREVIEW 隨操作鈕切換 LEFT／CENTER／RIGHT；舵機不動 |
| 完成教師核對與準備，再開外接電源 | 指針先到左邊；OLED 顯示 ON OK LEFT |
| 每隔至少 1 秒，放開再按操作鈕 | 左 → 中 → 右 → 左，實際指針與 OLED 命令一致 |
| 按住操作鈕約 3 秒 | 只前進一次，繼續按住不再前進 |
| 按 STOP，立即關外接電源 | STOP: POWER OFF、REASON:STOP；再按操作鈕不重啟 |

<pre class="screen">BUTTON POINTER
TARGET:CENTER
PRESS: NEXT POSITION
ON OK CENTER

SESSION:24 s</pre>

TARGET 是指定位置；ON OK 後是最後送出的命令。SESSION 是這次安全操作剩餘時間。畫面沒有量測指針位置，不能只拍 OLED 就算完成。

**回答：按住約 3 秒時，指針從哪裡到哪裡？繼續按住，有沒有再移動？**

另一次重新準備後，等滿 30 秒並立即關電，應見 REASON:TIMEOUT；兩鈕不能重啟。POWER OFF 是提醒人關電。

## Q2．倒數翻牌提醒器
**作品：**OLED 倒數 10 秒，時間到才讓舵機帶動輕紙指示牌，從「等待」轉到「完成」。時間尚未到，指示牌不變。

操作鈕開始／取消，ESP32 計時，OLED 顯示剩幾秒，舵機用位置提醒時間到。不接感測器或 RGB。

**預期結果：**左邊等待、右邊完成；結束保持完成，不自行重來。取消後回等待。

| 驗證操作 | 應看見的結果 |
|---|---|
| 完成共同準備，開外接電源 | READY LEFT:10 s，指示牌在等待位置 |
| 再按一下操作鈕 | COUNT，開始 10 秒倒數；按住不反覆開始／取消 |
| 剩 1 秒，再等到 0 秒 | 1 秒時仍等待；到 0 顯示 DONE、指示牌移到完成 |
| 完成後按一下 | READY、10 秒；回等待位置 |
| 再開始，途中按一下 | 取消，不是暫停；回 READY、10 秒與等待位置 |

<pre class="screen">COUNTDOWN FLAG
COUNT LEFT:4 s
TARGET:WAIT
ON OK LEFT
PRESS: START/CANCEL
SESSION:22 s</pre>

LEFT:4 s 是剩 4 秒；ON OK LEFT 是左邊命令。SESSION 是 30 秒安全時限，不因開始／取消重算；時限到先關電，再重來。

**回答：剩 1 秒與 0 秒時，指示牌各在哪裡？倒數中取消後，畫面與指示牌變成什麼？**

## Q3．光線自動指針
**作品：**沒遮光指向「明亮」，遮光指向「較暗」。完成設定與啟用後，不按操作鈕也會隨光線改變。

光敏模組把光線變化轉成訊號電壓；ESP32 讀成整數 raw，依本組兩筆設定判明暗。操作鈕先取設定值，再準備與開始跟隨；OLED 顯示讀值、明暗與命令；舵機把判斷變成指針位置。

**預期結果：**左邊標「明亮」、右邊標「較暗」。遮光讀值可能較大或較小，程式依本組設定判斷，不照抄別組數字。

### 驗證作品
1. 外接電源關閉。UNCOVER; PRESS 時，沒遮光、等 RAW 穩定，按一下保存明亮設定。
2. COVER; PRESS 時，用不透光紙遮住、等穩定，按一下保存較暗設定。這兩次只設定，不啟用舵機。
3. 完成教師核對與共同準備，看到 ON OK LEFT 才開外接電源。**再按一下操作鈕開始跟隨。**
4. 遮光、移開，各停至少 2 秒。較暗時右，明亮時左；不必按操作鈕。最後按 STOP、立即關電。

<pre class="screen">LIGHT POINTER
RAW:1100 DARK
TARGET:RIGHT
ON OK RIGHT
TRACKING
SESSION:18 s</pre>

BRIGHT 是明亮、DARK 是較暗；RAW 是讀值、TARGET 是指定位置。示例不是本組實測。相鄰位置命令至少隔 1 秒，TARGET 可能先變、ON OK 稍後跟上。

**回答：遮光與沒遮光時，raw 和實際指針位置各是什麼？這次移動需要再按操作鈕嗎？**

## Q4．環境警示指針
**作品：**用指針、RGB 顏色與 OLED，讓人同時看懂目前環境是「正常」「較暗」還是「警示」。這是環境提示器，不是自動小夜燈。

| 元件 | 這次增加或保留的工作 |
|---|---|
| 光敏 | 提供光線資料，判斷明亮／較暗 |
| DHT11 | 回報溫度與相對濕度；T 單位 °C，RH 單位 % |
| ESP32 | 比較讀值與門檻；超標警示優先於較暗提示 |
| RGB、OLED、舵機 | 分別用顏色、文字、指針位置呈現同一個判斷 |
| 操作鈕、STOP 鈕 | 操作鈕設定明暗，再開始跟隨；STOP 要求停止控制 |

**預期結果：**左、中、右分別標「正常」「較暗」「警示」。開始跟隨後依下表運作：

| 目前條件 | RGB | 指針 | OLED 原因 |
|---|---|---|---|
| T≤28°C、RH≤65%，且明亮 | 綠 | 左／正常 | NORMAL |
| T≤28°C、RH≤65%，但較暗 | 藍 | 中／較暗 | DARK |
| T>28°C 或 RH>65% | 紅 | 右／警示 | TEMP HIGH、RH HIGH 或 T+RH HIGH |

28°C、65% 是練習門檻，不是安全標準。即使遮光，溫度或濕度超過門檻仍優先亮紅、指向警示。

## Q4．驗證警示優先順序
從 Q1 接線加光敏、DHT 與 RGB；同堂可保留已確認接線，改線前全部斷電。使用 Q4 完整程式，不把幾題片段拼在一起。

### 驗證作品
1. 外接電源關閉，依 Q3 取沒遮光、遮光兩筆。等 T、RH 有有效數字，再完成教師核對與共同準備。
2. 看到 ON OK LEFT 才開外接電源；再按操作鈕開始跟隨。保持沒遮光，核對目前值符合哪一列，燈色、指針與原因須一致。
3. 遮住光敏，停至少 2 秒。沒有溫濕度超標時應變藍、指向中間；有超標時仍紅、指向警示。
4. 最後按 STOP，立即關外接電源。停止後 RGB 關閉，操作鈕不能重新啟用。

<pre class="screen">ENV POINTER
T:29.0C RH:62.0%
RAW:1100 TEMP HIGH
ON OK RIGHT
RGB:RED
SESSION:16 s</pre>

**畫面是教學示例，不是實測。**RAW 仍顯示光線讀值，TEMP HIGH 說明為什麼使用紅燈與警示位置。

**室內沒有三種狀態：**依 Ans 改練習門檻，註明「改門檻測試」。上傳後重新設定與準備，不假稱環境變熱／變濕，不用火、熱水或熱風吹電路。

**回答：較暗與超標各測一次，填讀值與本次門檻、原因、燈色、實際位置。遮光又超標時，哪個優先？**

結束先斷開舵機外接電源，再拔 USB；全部斷電後拆線收好。
