## Week6：餵食器與自動遮陽板

這週讓舵機帶動輕紙，做出兩件能實際操作的作品。Q1 在指定時間且等候位置被遮光時出料；Q2 依光線遮陽，並允許使用者手動介入。依各題的預期結果核對實物。

**每組準備：**A4 白紙 2～3 張、小片不透光紙、小紙盒／紙杯作支架或接料、少量小紙球、剪刀、膠帶、筆。另帶 ESP32、OLED、RGB、光敏、兩顆按鈕、SG90 舵機、麵包板、杜邦線、USB 線與完整舵機外接供電組。DHT 本週不必接。

| 元件 | 在這週的工作 |
|---|---|
| 操作鈕 | Q1 開始／取消一輪；Q2 切換自動與手動收起 |
| STOP 鈕 | 停止舵機控制；人仍須關外接電源 |
| OLED | 顯示倒數、光線、模式與位置命令 |
| RGB | 用顏色表示狀態；文字同時說明，不只靠顏色 |
| 舵機＋輕紙 | Q1 開關紙筒下方的出料閘板；Q2 帶動一小片遮陽板 |
| 光敏 | Q1 確認等候位置被遮光；Q2 分辨較強與較弱光線 |
| ESP32／外接電源 | ESP32 決定動作；已核對的外接電源供舵機 |

**先看完整示範：**教師提供的「Week6：兩件完整作品」互動動畫。左邊是完整步驟，右邊是目前作品；可暫停、選步驟或拖曳時間。

從空麵包板開始。改線前拔 USB、關閉並拔除外接電源。舵機只帶輕紙，不拉真窗簾，也不直接接 ESP32 的 3V3／5V。

兩題均先做無舵機輸出的預覽，再依 Ans 完成教師核對與啟用。Q1 預覽只能設定光線，不能開始倒數。看到 ON OK 後才由人開舵機外接電源；STOP 或啟用後 30 秒會停止控制，人仍須關電。按 STOP 立刻人工關電，不等 OLED 更新。

## Q1．定時感應餵食器模型

**作品用途：**模擬餵食時間到了，且貓已到等候位置，才打開出料口。紙筒固定在支架，裡面放少量紙球；底部用輕紙閘板擋住，舵機只移動閘板。下方有接料容器。

{{diagram:feeder-model}}

光敏固定在接料容器前的等候位置，用紙板／玩偶模擬貓靠近並遮住感光面。它量到的是遮光，不能辨識貓；閘板和落料本身不可遮到它。先記錄「空位置」「遮住」各一次。

| 從本輪開始已滿 10 秒？ | 等候位置已確認被遮光？ | 預期結果 |
|---|---|---|
| 未滿 | 否 | 繼續倒數，保持關閉 |
| 未滿 | 是 | 繼續倒數，不提早出料 |
| 已滿 | 否／不確定 | 等待靠近，保持關閉 |
| 已滿 | 是 | 執行一次出料，再關閉 |

10 秒從操作鈕開始本輪時起算，是課堂模擬時間，不是每天固定鐘點。遮光須連續確認至少 0.5 秒；分界附近或剛變動時不算已靠近。

## Q1．完整操作與驗證

| 操作／狀態 | 作品應如何反應 |
|---|---|
| 完成啟用，再按一下操作鈕 | 開始一輪 10 秒倒數；藍燈，閘板仍關閉 |
| 時間到且已確認靠近 | 紅燈，送開啟命令、稍候後開口維持 2 秒，再關閉 |
| 關閉流程完成 | DONE；綠燈，完成次數加一，保持關閉 |
| 完成後仍一直遮住光敏 | 不再出料；須放開再按鈕，開始新的 10 秒一輪 |
| 倒數中或等待靠近時按一下 | 取消這一輪，回 READY；次數不增加 |
| 正在開啟、出料或關閉時按鈕 | 不追加、不排隊；目前流程完成後保持關閉 |
| 按住操作鈕 | 只算一次按下，不反覆開始／取消 |

READY 是待機，COUNT 是倒數，WAIT FOR CAT 是等待遮光，FEEDING 是出料中，DONE 是本輪已完成。RGB 綠燈表示待機／完成，藍燈表示等待，紅燈表示出料流程。

一次出料是開、關閘板的動作；不要求固定幾顆紙球，也不以它推定食物重量。OLED 的 CMD 是已送出的命令，N 是本次開機完成的出料動作次數，必須同時看實物。

**展示兩種順序：**先靠近、後到時；先到時、後靠近。另展示完成後持續遮光不重複、取消，以及 STOP 後人工關電。每次啟用最多 30 秒，可關電、RST 分次示範。

**回答：**時間到了，但光線仍不確定，會不會開閘？本輪完成後一直遮住，會不會再出料？

## Q2．自動遮陽板

**作品用途：**窗邊光線太強就遮陽，光線變弱就採光；使用者也能暫時要求收起。用固定紙窗框／底座，讓舵機只帶動一小片輕紙。

{{diagram:shade-model}}

光敏固定在遮陽板外側，收起或放下都不會被自己的紙板遮住。先記錄本組較強、較弱光線各一次；沒有足夠差異時重新調整照明，不照抄別組讀值。

| 模式／操作 | 遮陽板應如何動作 | OLED／RGB |
|---|---|---|
| 自動，光線較強 | 放下遮陽板 | AUTO、STRONG、SHADE；綠燈 |
| 自動，光線較弱 | 收起遮陽板 | AUTO、WEAK、OPEN；綠燈 |
| 按一下操作鈕 | 收起，暫停自動 | MAN、OPEN；藍燈 |
| 手動時改變光線 | 仍保持收起 | MAN；藍燈 |
| 再按一下 | 恢復自動，依目前光線動作 | AUTO；綠燈 |

光線須穩定至少 0.5 秒才改變目標；中間讀值或尚未穩定時，取消尚未送出的自動目標，保持最後已送命令的位置。手動仍優先收起。命令至少間隔 1 秒，不保證紙板已到位。

**展示：**自動遮陽 → 變弱收起 → 變強遮陽 → 手動收起 → 改變光線仍保持 → 恢復自動。最後按 STOP 並關電。

**回答：**光線仍強時切到手動，遮陽板應在哪裡？恢復自動後呢？

## 看實物確認完成

| 作品 | 驗證項目 |
|---|---|
| Q1 | 單有時間到或單有靠近，閘板都保持關閉 |
| Q1 | 兩個條件同時成立才開、關一次，完成次數加一 |
| Q1 | 完成後持續遮光不重複；倒數或等待時可取消 |
| Q2 | 較強光遮陽、較弱光採光，不需再按鈕 |
| Q2 | 手動收起期間，光線不能把遮陽板放下 |
| Q2 | 恢復自動後採用當下光線，不沿用切換前的判斷 |
| 共同 | STOP 與 30 秒停止後，操作鈕不能自行重啟；立即人工關電 |

OLED 顯示命令，沒有量測閘板、遮陽板實際位置或是否真的落料；必須同時看實物。動畫是預期操作示範，不是實機測試紀錄。

每題可分次重新啟用驗證。30 秒從首次 ON OK 起算，包含開電與確認；不是作品倒數。Q1 完整一輪約 13 秒，裝料後 SESSION 至少還有 15 秒再開始；晚靠近須多留時間。不足就關電、RST 重來。

本週每題完成一件作品，不另交重複的讀值表。重新上傳、RST 或斷電會清掉設定與次數；重新記錄該作品的兩種光線。

Q1 停止控制不保證閘板已關閉；先人工關電，再移走紙球。料筒由支架承重，舵機只帶輕紙閘板。本週只做紙球與玩偶模型。

結束先關閉並拔除舵機外接電源，再拔 USB；全部斷電後拆線收納。抖動、卡住、發熱、黑畫面或重啟時立即關外接電源，交由教師檢查。
