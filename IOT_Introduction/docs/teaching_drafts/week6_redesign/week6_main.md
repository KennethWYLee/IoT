## 按鈕七格紙指針
**作品：**做一支能用按鈕選位置的輕紙指針。紙面標 0～6，OLED 顯示目前位置，舵機帶動指針指向相同數字。這題不需要感測器或 RGB。

本週從空麵包板開始，不保留上週接線。先用按鈕指定位置，再改由光線、溫度決定位置，最後以 Q4 說明訊號與供電的差別。

<aside class="safety">三件作品都只帶動輕紙，不加負載或連桿。先做不輸出舵機訊號的畫面預覽；由教師確認外接電源、共地、固定、行程與停止按鈕後，才實物驗證。預覽不算完成作品。</aside>

| 操作 | 預期結果 |
|---|---|
| 外接電源關閉時啟用，看到允許開電的提示後才開電 | 指針到安全行程起點 0 |
| 每隔至少 1 秒，放開再按一次 | 指針與 OLED 一起走 0、1…6、0 |
| 按住約 3 秒 | 只前進一格，不連續跳動 |
| 按停止鈕，或啟用滿 30 秒 | 顯示停止；由人關外接電源，原按鈕不能解除停止 |

<pre class="screen">BUTTON POINTER
ON OK POS:2
LEFT 24s</pre>
畫面為示例；0～6 是七個位置編號，不是角度。

**完成後回答：你實際按住按鈕約 3 秒，指針從哪格到哪格？**

## 光線狀態紙指針
**作品：**做一個不必盯著數字的光線提示器。沒遮光時指向紙面「沒遮光」的 0；遮光時指向「遮光」的 6。OLED 顯示讀數及位置。

以本組沒遮光、遮光各幾筆讀數，選能分開兩種情況的分界與大小方向；兩段重疊先排錯，不能假設遮光一定較大。等於分界歸沒遮光。

### 驗證作品
1. 舵機不輸出時，先確認畫面能分辨兩種光線；讀數 0、4095 或未設定分界時，不准啟用舵機。
2. 依 Q1 安全流程啟用，看到位置 0 後開外接電源，再按一下開始跟隨光線。
3. 遮光、移開，各停留至少 2 秒。指針在 0 與 6 之間變換，相鄰動作至少相隔 1 秒。
4. 按停止鈕後關外接電源。恢復光線、再按原按鈕，都不能解除停止；30 秒時限同樣適用。

<pre class="screen">LIGHT POINTER
RAW:1100
TARGET:6
ON OK POS:6</pre>
這是遮光讀數較大的示例，不是實測。TARGET 是希望到達的位置；移動間隔內可能暫時與目前位置不同。

**完成後回答：寫出本組分界及遮光時讀數增減方向；實際指針位置是否符合兩種光線狀態？**

## 溫度狀態紙指針
**作品：**用指針表示三段溫度，不使用光敏判斷。OLED 顯示 DHT 溫度與位置；紙面分別標示下表三種情況。

| DHT 回報的溫度 | 位置 |
|---|---|
| 小於 25°C | 0 |
| 大於或等於 25°C，且小於 28°C | 3 |
| 大於或等於 28°C | 6 |

25°C、28°C 是本題教學分界，不表示健康、安全或舒適標準。

**預期結果：**啟用前沒有有效 DHT 資料，不能轉動。安全啟用、開外接電源、按一下開始跟隨後，指針依最新溫度移動；兩次動作至少隔 1 秒。啟用後讀取失敗就保持停止，恢復資料不會自動再動。

**驗證：**在普通室內量測，等畫面更新再核對位置。不要用火、熱水或吹風機加熱。STOP 與 30 秒時限也須有效；看到停止立即關外接電源。

<pre class="screen">TEMP POINTER
T:26.0C RH:50.0%
TARGET:3
ON OK POS:3</pre>

**完成後回答：你量到幾度、指針到哪格？未跨三段時，另填 24°C、25°C、28°C 應到的位置，並標註這三筆是紙上推演。**

## 訊號線與電源線做不同的事
舵機有訊號、正電源、GND 三個功能端。正常作品由 ESP32 送訊號指定位置；舵機另由符合規格的外接電源供電，兩者的 GND 相連。

**Q4．分別回答兩種改法會缺少什麼，以及理由。只在紙上思考，不通電改接。**

1. 保留 GPIO 訊號線與共同 GND，但拿掉舵機的外接正電源線：GPIO 訊號能代替馬達需要的供電嗎？

2. 舵機外接正、負電源仍接好，但拿掉 ESP32 GND 與舵機 GND 間的共同連線：兩邊比較訊號電壓會受到什麼影響？

### 結束後
先關閉並拔除舵機外接電源，再拔 USB。全部斷電後拆下紙指針、元件與杜邦線，分類收好。三件作品可在同堂課內沿用已確認部分；換線、換程式前仍先斷電。
