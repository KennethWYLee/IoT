## Week 6：數字與紙指針
> 可查資料或使用 AI；作品可現場操作或用手機展示。

**作品：**先做只計算、不轉動的數字預覽器，再以已確認安全的舵機帶動輕量紙指針。定位型舵機接收位置命令，轉動軸到指定方向。

**預覽特色：**輸入 0～6，電腦顯示對應的示例角度。第 0 格為 60 度，第 6 格為 120 度，各格等距；超出範圍要拒絕。

<aside class="safety">示例角度不是實物安全範圍。舵機供電、接頭、行程、上電順序與停止條件未確認時，只做數字預覽與紙上題，不接舵機通電。不要只把保護設定改為允許。</aside>

**預期結果：**輸入端點 0、6，分別顯示示例 60、120；輸入 9 被拒絕，不輸出控制訊號。

**驗證方法：**舵機保持未接，測試兩端、範圍內一格及超出範圍。確認預覽不讓任何機構移動。

## A．數字、OLED 與紙指針一致
**作品：**輕量紙指針顯示器，接受 0～6 的格數，OLED 與電腦顯示同一命令值，實際指針指向已確認的刻度。

**特色：**具停止按鈕；每次命令至少相隔一秒，太快的命令拒絕且不排隊。每次啟用最多 30 秒，後續命令不能延長期限。不能推門、吊重物或擴大既有行程。

### 預期結果
| 操作或條件 | 應有的反應 |
|---|---|
| 啟動，尚未準備控制 | 不輸出舵機控制脈波 |
| 完成安全準備後指定格數 | 畫面更新；實物位置須另外目視核對 |
| 按住停止鍵 | 中止並鎖住，不接受重新啟用 |
| 放開停止鍵、排除原因 | 不自動恢復，明確重新準備才開始 |
| 啟用滿 30 秒或軟體模擬故障 | 停控制訊號、中止並保留原因 |

**驗證方法：**只使用已驗證的行程，逐格前進再回退；展示命令、OLED 與實物是否一致。STOP、逾時及故障各測不同目的，不以卡住舵機或拔帶電線製造故障。

## B．加減兩格的計數指針
**作品：**由電腦輸入 +／− 改變格數，OLED 與紙指針呈現結果。既有實體按鈕仍只作 STOP。

**特色：**先驗證每次加減一格的基本版，再把每次改為兩格；範圍仍是 0～6。不得改變角度端點、供電、STOP、一秒命令間隔或三十秒啟用上限。

### 預期結果
| 條件與操作 | 應有的計數結果 |
|---|---|
| 基本版從 0，+、+、− | 1、2、1 |
| 兩格版從 0，+、+、+、+ | 2、4、6、6；最後一次拒絕 |
| 兩格版從 6，−、−、−、− | 4、2、0、0；最後一次拒絕 |
| 兩格版指定 3，再 +、+、− | 5、6、4 |
| 中止後輸入 + | 不改數字，不重新啟用控制訊號 |

**驗證方法：**各列重新建立起始狀態，每次命令至少隔一秒。先紙上或主機測試；完整行程確認後才展示實物，並分開核對命令值與指針位置。
