## Q1．按鈕七格紙指針
**作品：**用一顆操作鈕選擇 0～6 格，讓舵機帶動輕紙指針，OLED 顯示 ESP32 送出的格位。0～6 是位置編號，不是角度；刻度紙固定不動，不能隨指針移動。

### 各部分負責什麼？
| 部分 | 在這件作品中的工作 |
|---|---|
| 操作鈕、STOP 鈕 | 兩顆按鈕都是輸入。操作鈕要求開始或前進；STOP 鈕要求停止控制 |
| ESP32 | 執行程式，決定格位，送控制訊號給舵機、送文字給 OLED |
| 舵機、紙指針 | 舵機是依控制訊號轉到指定位置的馬達；轉臂帶動輕紙指針 |
| OLED、刻度紙 | OLED 顯示命令，不量指針位置；實際指向哪格，要看固定的刻度紙 |
| USB、外接電源 | USB 供 ESP32；OLED 由板子的 3.3 V 供電。獨立外接電源供舵機 |

本週從空麵包板開始；接線、程式與設定見本週 Ans、program。同堂換作品可保留已確認部分；改線前關閉並拔除外接電源、拔 USB。上傳時只接 USB，舵機外接電源保持關閉。

<aside class="safety">只帶輕紙，不加重物或連桿。舵機不接 ESP32 的 3V3／5V；外接電源負極與 ESP32 GND 相接，讓訊號有共同電壓基準，稱為共地。先做畫面預覽，再請教師核對電源、接線、固定、指針活動範圍與 STOP。未確認前不開舵機電源；不要拔線、短接、用手擋住指針或取消時限測故障。</aside>

**STOP 不會切斷電源。**看到 STOP: POWER OFF 是提醒你立即關舵機外接電源，不是告訴你電源已關。

**停止後重來：**保持外接電源關閉，放開兩顆按鈕，再按開發板上的 **RST** 重啟程式；依下一頁重新準備。RST 是板上重啟按鈕，不是操作鈕或 STOP 鈕。

## Q1．驗證七個位置
**預期結果：**每次放開再按操作鈕，指針只前進一格；到 6 後再按回到 0。按住不會連續前進。

| 驗證操作 | 應看見的結果 |
|---|---|
| 外接電源關閉，先做畫面預覽 | OLED 的 PREVIEW POS 隨操作鈕在 0～6 循環；舵機不轉。這不是實物完成 |
| 教師核對後，外接電源仍關閉；放開再按操作鈕一次 | OLED 顯示 ON OK POS:0，才可由人開外接電源；紙指針到 0 |
| 開電後，每隔至少 1 秒放開再按操作鈕 | 紙指針與 OLED 命令格位一致，依序 0、1…6、0 |
| 在一格按住操作鈕約 3 秒 | 只前進一格；繼續按住不再前進 |
| 按 STOP 鈕，或從首次 ON OK 起滿 30 秒 | 顯示停止。立即關外接電源；操作鈕不能解除停止 |

<pre class="screen">BUTTON POINTER
TARGET:2
ON OK POS:2
LEFT 24s</pre>
**畫面示例：**TARGET 是程式指定的格位；ON OK 表示已開始送控制訊號，POS 是最後送出的格位。LEFT 24s 表示這次還可操作 24 秒。這些文字都不能證明指針實際到位。

**完成後回答：按住操作鈕約 3 秒時，實際指針從哪格到哪格？繼續按住有沒有再前進？**

## Q2．光線狀態紙指針
**作品：**做一個用指針表示光線狀態的提示器：沒遮光指向 0，遮光指向 6；OLED 同時顯示光敏讀數與命令格位。

光敏模組把光線變化轉成訊號電壓；ESP32 把該電壓讀成整數，畫面稱為 RAW。用本組沒遮光、遮光的讀數選分界，ESP32 才能分辨兩種情況。遮光時數字可能變大，也可能變小，須依本組量測決定。

### 驗證作品
1. 外接電源關閉，先看沒遮光、遮光兩種讀數。設定能分開本組兩種情況的分界與方向，預覽的 TARGET 應分別為 0、6；等於分界歸沒遮光。
2. 依 Q1 核對及準備；看到 ON OK POS:0 才開外接電源。**Q2 再按操作鈕一次，才開始自動跟隨光線**，不是前進一格。
3. 遮光、移開，各停至少 2 秒。紙指針應在 6、0 之間變換；程式限制相鄰位置命令至少隔 1 秒。
4. 按 STOP 鈕後立即關外接電源。停止、30 秒時限及 RST 重來方式同 Q1。

<pre class="screen">RAW:1100
TARGET:6
ON OK POS:6
TRACK 20s</pre>
**畫面節錄示例，不是實測：**TRACK 表示已自動跟隨。TARGET 可能先變，POS 等移動間隔後才跟上。

**無法分辨時：**先關外接電源，核對光敏供電與訊號接線、遮光是否確實；不勉強選分界。RAW 為 0、4095 或未設定分界時，本程式阻止啟用；啟用後讀值失效會保持停止，須關電。這個處理不能單憑數字證明接線故障。

**完成後回答：本組分界是多少？遮光時 RAW 變大還是變小？遮光與沒遮光時，實際指針各在哪格？**

## Q3．溫度狀態紙指針
**作品：**用指針表示三段溫度。DHT11 是溫濕度感測模組，提供攝氏溫度與相對濕度；本題 ESP32 只用溫度選格位，OLED 顯示資料與命令。

保留 Q1 的元件；斷電後拆光敏、加 DHT11。畫面 T 單位為 °C，RH 單位為 %。

| DHT11 回報的溫度 | 應指向的格位 |
|---|---|
| 小於 25°C | 0 |
| 大於或等於 25°C，且小於 28°C | 3 |
| 大於或等於 28°C | 6 |

25°C、28°C 是本題練習分界，不是健康、安全或舒適標準。

### 驗證作品
1. 在普通室內量測。程式每 2.5 秒讀一次 DHT11；先等 OLED 出現溫度數字，再核對表格。
2. 依 Q1 準備，看到 ON OK POS:0 才開外接電源；再按操作鈕一次，開始跟隨溫度。核對實際指針和表格是否一致。
3. 按 STOP 鈕後立即關外接電源。30 秒時限及重來方式同 Q1。

<pre class="screen">T:26.0C RH:50.0%
TARGET:3
ON OK POS:3</pre>
**畫面節錄示例，不是實測。**讀取失敗顯示 T:-- C RH:-- %；啟用前不能開始，啟用後會停止，立即關電。不要拔線測故障，也不用火、熱水或吹風機湊三段溫度。

**完成後回答：實測幾度，指針到哪格？若未看到三種位置，另寫 24°C、25°C、28°C 各應到哪格，註明「紙上推演」。**

## Q4．停止原因驗證
**任務：**用 Q1 同一件按鈕紙指針，驗證 OLED 是否保留第一個停止原因。不加新元件，改回 Q1 的程式；改線前全部斷電，DHT11 可拆除。

**預期結果：**按 STOP 鈕顯示 REASON:STOP；啟用滿 30 秒顯示 REASON:TIMEOUT。停止後，兩顆按鈕都不能重新開始，也不能改掉原因。POWER OFF 仍是提醒人關外接電源。

### 驗證作品
1. 依 Q1 準備與開電，在 30 秒前按 STOP 鈕。立即關外接電源，再讀停止原因。
2. 外接電源保持關閉，依 Q1 的 RST 重來方式重新準備，再開電。
3. 這次不按 STOP，等 30 秒時限。立即關外接電源，再讀停止原因；不必讓指針持續來回動。
4. 外接電源仍關閉，按下再放開 STOP 鈕，再按操作鈕，觀察原因是否被改掉、程式是否重新開始。

**完成後回答：兩次停止各顯示什麼原因？第二次停止後再按兩顆按鈕，畫面及控制狀態有沒有改變？**
