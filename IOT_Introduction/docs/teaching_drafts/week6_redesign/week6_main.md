## Week 6：讓數字變成紙指針位置
**作品：**保留環境顯示器，再加舵機帶動的輕紙指針。舵機能依控制訊號轉到指定位置；我們先看螢幕上的位置，再讓它真的轉動。

不加重物、不裝機械連桿、不用它推拉物品。OLED、光敏、DHT、RGB 與原按鈕繼續使用。

### Q1．先完成不通舵機電源的預覽
**預期結果：**OLED 顯示位置 0～6；每按一下前進一格，6 之後回到 0。長按不連續前進。此時舵機不接電、不動。

<pre class="screen">NOW RAW:420
T:25.0 C RH:50.0 %
INDOOR:GREEN
PREVIEW POS:2
LAST:420 #2
LAST 25.0C 50.0%</pre>

**驗證方法：**先放開按鈕，從位置 0 按到 6，再按回 0。按住一次約 3 秒，確認只前進一格。

**完成後回答：從位置 5 連續做兩次「按下、放開」，畫面依序顯示什麼？**

## 讓紙指針跟著畫面走
### Q2．完成七格紙指針
**作品特色：**紙面標上 0～6。畫面中的位置和指針方向相符；每次放開再按才接受下一次操作，相隔至少 1 秒。一次啟用最多 30 秒。

<aside class="safety">舵機使用經確認的外接電源，不能由 ESP32 的 3V3 接腳供電。手離開轉動範圍；異常抖動、卡住、發熱或板子重啟，立即切斷舵機外接電源。</aside>

| 你怎麼驗證 | 作品應有的結果 |
|---|---|
| 外接電源關閉時完成啟用，再開外接電源 | 指針到教師確認的起始位置 0 |
| 每次間隔至少 1 秒，放開再按 | 指針與 OLED 同步走一格；6 之後回 0 |
| 按住約 3 秒 | 不持續跳格 |
| 操作時遮住光敏 | OLED 光線與 RGB 仍回應；環境功能未被移除 |

**完成後回答：實際驗證了哪些位置？是否有到不了、抖動或碰到物體的位置？如有，先停止，再說明問題。**

## 有停止方法，才完成作品
### Q3．加入停止按鈕
**作品特色：**第二顆按鈕專門停止舵機控制。停止後不能只靠按原按鈕、恢復 OLED 接線或等待，就自行再動。

**預期結果：**按停止按鈕或達到 30 秒時限，OLED 顯示停止。程式停止送出舵機控制脈衝，接著由人關掉外接電源。這不是已切斷供電的意思。

<pre class="screen">NOW RAW:420
T:25.0 C RH:50.0 %
INDOOR:GREEN
STOP: POWER OFF
LAST:420 #2
LAST 25.0C 50.0%</pre>

**驗證方法：**在教師確認的安全位置測試停止；關閉外接電源後，再按原按鈕，畫面不可解除停止。要重做時保持外接電源關閉，再按板子 RST，重新走啟用流程。

**完成後回答：你實際用哪個操作停止？看到什麼畫面？為什麼看到 STOP 後仍要關掉外接電源？**
