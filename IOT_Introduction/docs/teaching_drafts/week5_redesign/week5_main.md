## Week 5：桌上狀態燈
前三題依序練習按鈕選狀態、光線分類、溫濕度提醒；Q4 使用 Q2 作品比較燈光方向。

<aside class="safety">本週從空麵包板開始。改線前拔 USB，只用教師確認極性、限流電阻與電流適用的 RGB 模組；不可短接電阻。下課拔除所有電源後拆線收好。</aside>

### Q1．桌上狀態燈
**作品：**用按鈕選擇「有空」「忙碌」「暫離」，讓同學遠看 RGB 燈就知道狀態；OLED 同時顯示文字。RGB 是把紅、綠、藍三種發光元件放在一起的燈，本題一次只亮一色。

**預期結果：**啟動時是有空；每次按下並放開，依序變為忙碌、暫離、有空。長按只換一次，不自動輪流變色。

| 狀態 | 實物燈色 | OLED 文字 |
|---|---|---|
| 有空 | 綠色 | AVAILABLE |
| 忙碌 | 紅色 | BUSY |
| 暫離 | 藍色 | AWAY |

<pre class="screen">DESK STATUS
BUSY
LED:RED</pre>
這是忙碌狀態的成品畫面。

**驗證：**展示完整循環，再長按約 3 秒，確認只換一次且燈色與文字始終一致。按住按鈕重新啟動時，仍從有空開始；放開後再按才換狀態。

**完成後回答：長按前是什麼狀態？長按後停在哪個狀態？**

## 光線狀態燈
### Q2．光線狀態燈
**作品：**用 RGB 顯示光敏模組判斷的結果，OLED 顯示讀值與文字。這件作品不需要按鈕或 DHT。

ESP32 把光敏訊號的電壓轉成整數，叫原始讀值 **raw**。本題使用 0～4095 的讀值範圍；請用本次「沒遮光」與「遮光」的量測決定兩類分界，不能假定遮光數字一定變大。

| 情況 | 預期燈色 | OLED 必須顯示 |
|---|---|---|
| 沒遮光 | 綠色 | 目前 raw、INDOOR |
| 遮光 | 藍色 | 目前 raw、SHADE |
| 尚未設定分界 | 關燈 | 目前 raw、SET LIGHT LIMIT |
| raw 是 0 或 4095 | 關燈 | 目前 raw、LIGHT:CHECK |

<pre class="screen">RAW:910
SHADE
LED:BLUE</pre>
910 只是畫面示例，不是你這組的標準值。等於你設定的分界時，歸為沒遮光。

**驗證：**在同一位置，沒遮光、遮住、移開，畫面文字和實物燈色都應正確切換。RGB 不要直接照到光敏。

**完成後回答：你量到的沒遮光／遮光讀值各是多少？最後採用哪個分界？**

## 溫濕度提醒燈
### Q3．溫濕度提醒燈
**作品：**用 DHT 量溫濕度，OLED 顯示數字，RGB 顯示需要注意哪一項。這件作品不需要光敏或按鈕。

**預期結果：**畫面的 T 是溫度（°C），RH 是相對濕度（%）。本題門檻為 28 °C、65%；它們只是課堂練習設定，不是健康或設備安全標準。

| 量到的情況 | 預期燈色／文字 |
|---|---|
| 溫度 > 28 °C | 紅燈／TEMP HIGH，即使濕度也超標 |
| 溫度 ≤ 28 °C，濕度 > 65% | 藍燈／RH HIGH |
| 溫度 ≤ 28 °C，濕度 ≤ 65% | 綠燈／NORMAL |
| 任一溫濕度讀取失敗 | 關燈／CHECK DHT，兩個數字均為 -- |

<pre class="screen">T:29.0 C RH:70.0 %
TEMP HIGH
LED:RED</pre>
這是示例，不是實測資料。兩項同時超過門檻，先提醒溫度。

**驗證：**展示數字、文字與燈色一致。若室溫無法出現某個狀態，可暫時調整比較門檻進行驗證，最後恢復 28 °C／65%。不要用火、加熱器或水改變感測器狀態。

**完成後回答：展示一個實際測出的狀態，寫下溫度、濕度、當時門檻與燈色。若改過門檻，請註明。**

## Q4．RGB 與光敏比較
**作品：**使用 Q2 光線狀態燈，比較自己的 RGB 是否影響光敏。沿用同一份程式與接線，不增加元件或功能。

**預期結果：**OLED 持續顯示 raw，RGB 依同一分界選色。轉向光敏後，raw 可能改變或燈色來回切換；也可能沒有明顯差異。隔板擋住 RGB 直射光後，可再比較讀值是否接近原來狀況。

### 驗證作品
固定外部照明、光敏位置、程式、分界及判斷方向。不要用手或紙遮住光敏；只改 RGB 朝向，或在 RGB 與光敏之間放不透光隔板。隔板不能遮住原本照向光敏的外部光線，也不能碰觸接腳。

| 比較條件 | OLED raw 範圍 | 燈色是否來回切換 |
|---|---|---|
| RGB 背向光敏 | ______ | ______ |
| RGB 朝向光敏，距離不變 | ______ | ______ |
| 維持朝向，加隔板擋住 RGB 直射光 | ______ | ______ |

每種條件觀察約 5 秒。若調整會拉扯接線，先拔 USB，擺妥再上電；不用拆線或短接做比較。

**完成後回答：哪兩種條件的讀值或燈色不同？隔板有沒有減少差異？若三種都接近，照實寫觀察，不必做出來回跳色。**
