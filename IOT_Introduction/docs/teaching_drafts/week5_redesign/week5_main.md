## Q1．桌上狀態燈
本週依序做狀態燈、倒數燈、小夜燈、環境巡檢。Main 列作品需求；接線、程式與上傳步驟查 Week5 Ans，Q1 從空麵包板開始。
**作品：**讓同學遠看燈色就知道你有空、忙碌或暫離，靠近時可讀 OLED 的文字。

| 元件 | 它是什麼，在這件作品做什麼 |
|---|---|
| 按鈕 | 按下會接通接點的開關，把「換到下一個狀態」的操作送給 ESP32 |
| ESP32 | 執行程式的開發板，記住目前狀態，決定文字與燈色 |
| OLED | 顯示文字的小螢幕，把 ESP32 的狀態顯示給人看 |
| RGB | 內含紅、綠、藍三種發光元件的燈；本題一次亮一色，讓人遠看辨認狀態 |

<aside class="safety">RGB 接地接回 ESP32 GND；只用教師核對過、有保護發光元件用電阻的模組。CHECK RGB WIRING 表示確認設定未完成，先請教師核對，不自行解除保護。改線先拔全部電源；下課斷電拆線。</aside>

**預期結果：**啟動是 AVAILABLE（有空）／綠。每按一下依序變成 BUSY（忙碌）／紅、AWAY（暫離）／藍，再回 AVAILABLE／綠。按住不放只前進一次。

<pre class="screen">DESK STATUS
BUSY
LED:RED
PRESS TO CHANGE
</pre>

**驗證：**展示完整循環，回到 AVAILABLE 後按住約 3 秒，確認只變 BUSY／紅一次。

**完成後回答：朋友只看燈能知道什麼？按住約 3 秒時，你的作品實際停在哪個狀態？**

## Q2．倒數提醒燈
**作品：**做一個 30 秒倒數器，讓人看燈就知道還有時間、快到時間或已到時間。

**各元件用途：**按鈕送出開始或取消的操作；ESP32 計算剩餘秒數；OLED 顯示秒數與操作提示；RGB 用燈色提醒進度。本題不用感測器，時間由程式計算。FOCUS TIMER 是畫面上的倒數器名稱。

| 操作或目前狀態 | 預期畫面與燈色 |
|---|---|
| 開機等待；READY 表示準備開始 | LEFT:30 s，關燈；PRESS TO START 表示按下開始 |
| 按一下開始，剩 30～11 秒 | COUNTDOWN，顯示剩餘整數秒，綠燈 |
| 剩 10～1 秒 | 倒數繼續，藍燈 |
| 倒數滿 30 秒，剩 0 秒 | TIME UP，紅燈持續 |
| 倒數中或結束後再按一下 | 取消本次，回 READY／30 秒／關燈，不直接重開 |

<pre class="screen">FOCUS TIMER
COUNTDOWN
LEFT:10 s
LED:BLUE
PRESS TO CANCEL</pre>

**驗證：**第一次讓它倒數完，觀察綠、藍、紅；取消回 READY 後重新開始，倒數途中取消。按住約 3 秒只算一次操作。

顯示秒數向上取整：剩 0.2 秒仍顯示 1，滿 30 秒才到 0。不要求手量毫秒。

**完成後回答：寫下你看到變藍的剩餘秒數，以及途中取消後的畫面與燈色。**

## Q3．自動小夜燈
**作品：**沒遮光時關燈，遮住感測器後自動亮藍燈，不用每次手動開燈。

**各元件用途：**光敏模組把光線變化轉成訊號電壓；ESP32 的 ADC 把接腳電壓轉成整數，叫原始讀值 raw，本題範圍 0～4095。ESP32 依本次兩種光線的資料判斷；RGB 提供燈光；OLED 顯示讀值與判斷；按鈕只用來保存設定。本題不用 DHT。

### 預期結果
沒遮光、遮光各按一下，保存 BRIGHT、SHADE 設定值。LIMIT 是兩值中點的整數部分。SHADE 比 BRIGHT 大，讀值 > LIMIT 判遮光；SHADE 比 BRIGHT 小，讀值 < LIMIT 判遮光。等於 LIMIT 歸沒遮光。兩值相同顯示 SAME VALUE: RETRY，重做兩次設定。

| 階段或操作 | OLED 與 RGB |
|---|---|
| 等第一筆／第二筆設定 | 顯示即時 raw、UNCOVER SENSOR／COVER SENSOR；關燈 |
| 設定後，沒遮光 | 即時 raw、BRIGHT；關燈 |
| 設定後，遮住感測器 | 即時 raw、SHADE；藍燈 |
| 設定後再按按鈕 | 不改設定、不開關燈；BUTTON:NONE 表示此時不操作 |
| 按板上的 RST（重新啟動） | 清除設定，回到第一筆，重新設定 |

## Q3．成品與驗證
設定完成後，OLED 顯示本次兩個設定值與分界；RGB 在遮光時亮藍、沒遮光時關閉。

<pre class="screen">NIGHT LIGHT
RAW:1100 SHADE
BRIGHT:420
SHADE:1020 LIMIT:720
LED:BLUE BUTTON:NONE</pre>

RAW 後的 SHADE 是目前判斷；SHADE:1020 是保存的遮光設定值，兩者意思不同。

**驗證：**設定後遮住、移開，確認自動亮、滅。RGB 背向光敏，不照回感測器。圖中數字為示例，不是本組實測。

## Q4．環境巡檢與比較
**作品：**在不同位置或光線下保存環境資料，比較自己選擇記錄的樣本；同時用燈提醒目前環境。

**各元件用途：**光敏提供光線訊號；DHT11 是溫濕度感測模組，提供溫度 T（°C）與相對濕度 RH（%）。ESP32 判斷目前狀態並保存你選的資料；OLED 顯示即時值、保存結果與統計；RGB 提醒目前狀態；按鈕先設定光線，設定完成後改為要求保存一筆。

### 預期結果
先依 Q3 順序保存沒遮光與遮光設定。設定畫面的兩次按下不算環境紀錄。設定完成後，每按一次保存**一筆新取得的 raw、明暗、溫度、濕度**。

- SAVING 表示等新溫濕度資料，最長約 2.5 秒；保持位置和遮光狀態，直到 SAVED。
- SAVED 顯示剛保存的資料約 2 秒；當場記下或拍照，之後只顯示統計。按住只存一筆；等待中重按不另排一筆。
- 即時讀值會更新，但**沒有按下保存，統計就不增加或改變**。
- OLED 約每 3 秒輪換目前值與保存統計；保存成功時先顯示那一筆約 2 秒。
- 比較已保存筆數、遮光筆數、溫度／濕度最小與最大值。遮光筆數依光線判斷，不依燈色。

<pre class="screen">SAVED #2
RAW:1100 SHADE
T:27.4C RH:61.0%
COUNT:2 SHADE:1
PRESS TO SAVE</pre>

這是保存第二筆的示例。COUNT 是已保存筆數；SHADE 後的數字是其中被判為遮光的筆數。

資料只存於 ESP32 暫存記憶體 RAM，未寫入檔案。SAVE FAILED 表示讀取失敗、不存；FULL:20 RECORDS 表示已滿 20 筆、不覆蓋。拔 USB、按 RST、重新上傳都清除紀錄與光線設定。只在 USB 線能安全到達的範圍移動。

## Q4．驗證紀錄與提示燈
RGB 表示**目前**環境，不表示剛才保存的資料。依序判斷下表：

| 目前條件，依序判斷 | 預期文字／燈色 |
|---|---|
| 尚未完成光線設定 | LIGHT SETUP／關燈 |
| 設定完成，溫濕度讀取失敗或尚未取得 | WAIT/CHECK DHT、T:--C RH:--%／關燈 |
| 兩種資料有效，溫度 > 28°C 或相對濕度 > 65% | TEMP HIGH、RH HIGH 或 T+RH HIGH／紅 |
| 沒超標，光線判為遮光 | 狀態 NORMAL，RAW 行為 SHADE／藍 |
| 沒超標，光線判為沒遮光 | 狀態 NORMAL，RAW 行為 BRIGHT／綠 |

28°C／65% 是練習門檻，不是安全標準。等於不超標；兩項都超過為 T+RH HIGH。紅色優先，超標時遮光也不變藍；RAW 行的光線判斷仍更新。

### 驗證作品
1. T、RH 已顯示數字後，沒遮光與遮光各保存一筆，應有 COUNT:2、SHADE:1。各筆數字用自己的實測值。
2. 不再按保存，只改光線。RAW 與光線判斷更新，保存統計不變；超標時燈仍紅，沒超標時才隨光線變綠／藍。
3. 對照兩筆保存畫面，確認統計範圍正確。數字相同照實寫，不要求兩地必有溫濕度差。
4. 展示紅、藍、綠判斷。數字無法跨門檻，可按 Ans 調整門檻、重新上傳測試；這會清除紀錄，須重新設定光線與取樣。註明設定，不當成環境真的改變。
5. 按 RST，確認紀錄歸零並重新要求光線設定。

**作答：填保存筆數、遮光筆數與溫濕度範圍；如何確認沒有自動保存？**

## Q4．即時值與保存統計
下列為示例，數字不是本組實測。ENV CHECK LIVE 顯示目前資料；SAVED DATA 只整理按下後成功保存的資料。

<pre class="screen">ENV CHECK LIVE
RAW:1100 SHADE
T:27.4C RH:61.0%
NORMAL
LED:BLUE
PRESS TO SAVE</pre>

<pre class="screen">SAVED DATA
COUNT:2 SHADE:1
T:27.2..27.4 C
RH:61.0..62.0 %
PRESS TO SAVE</pre>

COUNT 是已保存筆數，SHADE 是其中遮光筆數。範圍左邊最小、右邊最大；例中保存的溫度為 27.2～27.4°C、相對濕度為 61～62%。
目前數字可以繼續變，保存範圍只在成功保存新資料後改變。沒有保存資料時，範圍顯示 --，不表示量到零。
