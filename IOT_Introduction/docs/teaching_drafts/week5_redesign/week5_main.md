## Week 5：用燈色看懂狀態
**作品：**保留 OLED 的光線、溫濕度與按鈕保存功能，再加一顆 RGB 燈。RGB 模組含紅、綠、藍三種發光元件，本週用單色提醒，不要求混色。

**為什麼加燈？**不用走近看數字，也能從燈色知道光線判斷的結果。

<aside class="safety">改線前拔除 USB。只使用已確認極性、限流電阻與電流符合接腳能力的模組；不能把裸 LED 直接接上，也不能移除限流電阻。</aside>

### Q1．先讓三種顏色對得上
**預期結果：**紅、綠、藍依序亮起，每次約 1 秒，一次只亮一色，循環重複。這一步只驗證新增的 RGB；原有接線保留。

**驗證方法：**展示實際燈色，不以電腦文字代替燈真的亮起。

**完成後回答：三色是否符合順序？若曾亮錯色，你最後修正哪一條連線或哪個腳位設定？未遇到問題可寫「順序正確」。**

## 光線改變，畫面與燈一起回應
### Q2．完成光線狀態提示器
**作品特色：**用本組「沒遮光」與「遮光」的實測資料建立判斷。沒遮光亮綠燈，遮光亮藍燈；OLED 同時顯示判斷文字、目前光線與溫濕度。

<pre class="screen">NOW RAW:910
T:25.0 C RH:50.0 %
SHADE:BLUE
LAST:420 #1
LAST 25.0C 50.0%</pre>
示例數字不是標準答案。保留上週「按一下保存、長按不重複」的行為。

| 你怎麼驗證 | 作品應有的結果 |
|---|---|
| 沒遮光、遮住、移開 | OLED 判斷和燈色一致，能回到沒遮光狀態 |
| 按一下保存，再改變光線 | 目前狀態和燈會變，保存資料保持不變 |
| 讀值為 0 或 4095（本例設定的兩個端點） | 顯示待確認，RGB 關閉，不假裝已辨認環境 |

**完成後回答：你的判斷分界是多少？遮光時讀值變大還是變小？**
