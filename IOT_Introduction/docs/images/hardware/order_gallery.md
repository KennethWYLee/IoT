# 購物圖片外觀參考

以下是教師過去的購物畫面，只供辨識，不是領料或學生必買數量清單。
截圖中額外的車輛器材是教師為自製無人車等個人實作準備的，學生不必跟著買。
畫面中的價格不是即時報價；**不可把商品圖當成接線圖或腳位文件**。

正式規格、每人數量與使用週次只查[Week 1中文採購表](../../../Week_01_Course_Orientation/week1_main.md#purchase-table)。
教師庫存歷史另見[已購紀錄](../../hardware/purchased_inventory.md)，不在本圖鑑重複維護。

## 訂單圖 1：基礎原型、馬達與電源

可辨認按鈕、公對母杜邦線及萬用電表。OLED支架、TT馬達、車輪與降壓模組不列共同必買；
支架不是OLED螢幕。

![環島科技購物與訂單參考圖1：基礎原型、馬達與電源](orders/shopee-aroundtw-01-prototyping-motors-power.png)

## 訂單圖 2：驅動、舵機、距離與顯示

共同需要母對母杜邦線與符合Week 1規格的OLED；收納容器可沿用。
L298N、MG90S、HC-SR04與萬向球不是共同必買。

![環島科技訂單圖2：驅動、舵機、距離與顯示](orders/shopee-aroundtw-02-drivers-servos-sensors-displays.png)

## 訂單圖 3：ESP32、感測與燈光

共同材料可辨認RGB、蜂鳴器、公對公杜邦線、DHT11、ESP32-S3及4AA電池盒。
PIR與八顆WS2812B燈條是另一類元件；不能用燈條代替本課單顆四針RGB。
ESP32-S3模組名稱也不等於整片開發板版型。

![環島科技訂單圖3：ESP32、感測與燈光](orders/shopee-aroundtw-03-esp32-sensors-lighting-power.png)

## 訂單圖 4：光敏、舵機與麵包板

KY-018、SG90位置型舵機與400孔麵包板是共同材料。
商品寫180度不代表收到的舵機已驗證可安全走完整行程。

![環島科技訂單圖4：光敏、舵機與麵包板](orders/shopee-aroundtw-04-photoresistor-servo-breadboard.png)

## 訂單圖 5：電阻與收納

電阻可單買或合買分裝，確保每人取得Week 1指定的四種阻值與數量；不要求整包全買。
收納容器不限定圖片款式。

![樂意創客訂單圖5：電阻與收納](orders/shopee-loyi-maker-05-resistors-storage.png)
