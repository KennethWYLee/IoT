# Week5 重寫與各週元件說明

教師要求先與 Claude 確認學生的困難：不只是按鈕用途不明，而是每個元件的定義、作品中的功能、輸入與可觀察結果都要清楚。本輪先對齊這項原則，再重寫 Week5；不增加其他週的零件、作業、評分或改動考試、報告及出國安排。

## 修改內容

- Week5 四件作品：Q1 桌面狀態、Q2 倒數提醒、Q3 自動夜燈、Q4 環境巡檢。Main 七頁、Ans 十二頁；完整程式另放 Arduino 同名資料夾。Ans 先說接線、開檔、設定、結果與排錯，原理在後。
- Q3 依本組兩次讀值決定光線分界與方向，明定相同讀值、等於分界、重新啟動及後續按鈕行為。Q4 前兩次按下用於光線設定，完成設定後才保存新取得的環境資料；明定等待、失敗、保存成功、二十筆上限、目前值與已保存統計。
- 新接線圖以實際腳位名稱標示電源、GND 和訊號；電源使用同一段麵包板正負排。RGB 與感測器分工清楚，OLED 顯示資料，ESP32 執行判斷與保存，不把顯示器寫成保存裝置。
- Week1～4、Week6／7、Week11／12／14／15 在現行內容補齊元件或軟體分工，修正不清楚的用語；不是全面重設後段課程或全面縮短 Ans。Week4 只改 `_withClaude` 比較版，保留原版與個人 GPIO1 工作檔。
- Week8／9 只修正現有活動用語和已教內容引用；Week10／16 只隨現行生成器刷新 PDF。其他報告、空白與保留週不套入固定題數。
- 舊 Week5 完整來源保存在本機 `archives/week5_before_20261007`，舊雲端程式另移至歷史資料夾，不混在現行四件作品入口。

## Claude 與驗證

- 使用指定 Claude Opus 5.5／xhigh，先討論所有元件的功能與學生閱讀方式，沒有永久授權或硬體操作。
- Claude 逐檔讀取 Week5 Main、Ans、生成器與圖檔，提出學生第一次操作的疑問；修正後再以實際片段核對邊界規則。其他週由 Codex 閱讀現行來源、提供實際片段給 Claude 檢查，不宣稱 Claude 獨立逐頁讀完所有週次。
- Week5 十二組主機程式設定測試共 172 項斷言通過；四支程式在 ESP32-S3 N16R8 設定編譯通過。涵蓋長按、倒數邊界、光線方向／等值、等待新資料、失敗不保存、二十筆上限、統計及 OLED 中斷後重連。
- 受影響二十五份 PDF 共 277 頁，以 Poppler 全頁渲染並目視檢查所有頁面的縮圖總覽；Week5 新接線頁另檢查大圖。來源雜湊、頁界、缺字、本機連結與公開範圍核對通過。未修改的後段 Ans 仍有歷史內容與較疏頁面，不把本輪檢查描述成全面排版重建。
- Week4 比較版十八頁再次核對來源、引用、頁界及舊檔保留；Q3／Q4 程式邏輯沒有因這輪文字修正而更動。
- 尚未操作真實硬體，沒有上傳韌體、使用 COM、移動舵機或驗證所有學生能完成。編譯和假的 I/O 測試不能取代實際接線測試。
