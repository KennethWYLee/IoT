# Week4 修訂版與程式檢查

## 範圍

依教師要求，以第一次實作學生的閱讀順序整理 Week4；舊版保留，修訂版使用 `_withClaude` 檔名。四件作品、零件、週次、評分及 OLED／Serial 選擇不變。每週從空麵包板接線；同堂換題可保留接線，改線前斷電。

- [修訂版 Main／Ans](../../Week_04_Sensors_and_Data_Quality/README_withClaude.md)：Main 6 頁，Ans 12 頁。
- [Q1、Q2 公開程式](../../../program/week4/README.md)：四支 `.ino` 已在先前版本公開，本次維持程式邏輯，只補程式入口的操作說明。
- Q3、Q4 程式、電腦工具、答案維護來源和教師工作檔不公開。

## 主要修正

Main 依作品、完成畫面、驗證、回答排列；刪除重複展示，異常行為不要求學生帶電拆線製造。Q3 只要求一次警報開始、按鈕確認及正常恢復，不額外要求第二次環境循環。Q4 保留教師實測截圖；光線預設分界 3000 無法跨過時，開始前依本組讀值選分界並標示設定。

Ans 從 Q1 直接開始，加入課堂實物腳位標示、完整供電與訊號接線示意。光敏中腳供電僅限已核對的課堂同款，不把 R1 當供電標字；本片 OLED 的 SCK 接 GPIO9，程式稱 SCL。Q1 不先接按鈕，Q3 才接。

Q1 提供程式庫安裝、檔案入口、Ctrl+F 設定、等待畫面及就近排錯。每次換程式重新核對 DATA 接腳、確認旗標與 OLED 控制器。Q3 分清按鈕測試與真實恢復；重刷、RST 不冒充恢復。Q4 寫出就緒、資料夾權限、開始、首筆、裝置回傳及保存的成功狀態；開始前網頁 -- 是正常的。原理與完整 IDE 設定放在後面。

## Claude 與獨立核對

教材與程式各由一次獨立 Claude Opus 5.5、xhigh 工作檢查。程式工作曾因排隊逾時未啟動；取得教師「允許重新啟動」後另開新工作，保留原逾時紀錄。每次讀取、搜尋個別審核，未增加永久權限，未切換模型。

Claude 教材檢查讀維護來源、設定與程式，沒有看到 PDF 版面；最終 PDF 由 Codex 渲染與視覺檢查。Claude 程式檢查是讀碼推演，沒有編譯、沒有讀程式庫原始碼或操作實物。它未發現必改 bug；I2C 初始化速度與命名只列可選建議，未據此更動程式。這不是全班實作通過的證據。

Codex 核對實際程式與維護紀錄，另完成以下檢查：

- 兩份 PDF 共 18 頁：Poppler 渲染、逐頁檢查、界線、圖片、缺字、頁碼、交叉引用與 Main 不含程式解答。
- 維護來源、建置輸入及 PDF SHA-256 核對；正式目錄 PDF 與草稿建置逐位元相同。
- 原 Main／Ans 維護來源及四份 PDF、兩個指定工作檔、既有 Windows 紀錄均與修改前雜湊相同，共九項。
- Q1／Q2 共 12 個假 I/O 配置、270 項斷言通過，含未確認、有效讀值、NaN、恢復、門檻邊界、計時回繞、OLED 回應與 GPIO1 配置。測試沿用既有獨立 C++ 測試程式及假的硬體介面，共享這些假設，不等於實物證據。
- 四支公開程式在 ESP32 core 3.3.12、DHT 1.4.7、Unified Sensor 1.1.15、U8g2 2.36.19 的課堂 N16R8 配置編譯通過。Flash／RAM：Q1 OLED 351856／25800、Q1 Serial 293791／22940、Q2 OLED 340248／25536、Q2 Serial 280635／22636 bytes。
- 公開程式匯出核對：僅統一換行與行尾空白，四支與來源一致。教師 GPIO1 工作複本不覆蓋。

## 發布與限制

依教師授權提交並推送修訂版 PDF、Main 維護來源、比較入口、檢查規則與本紀錄。Q1／Q2 程式保留現行版本；公開 `program/week4` 仍只有四支程式與 README／manifest。私有答案來源、檢查、Q3／Q4 及未相關改動不提交。

沒有韌體上傳、COM 操作、實物改線、帶電測試或新手試讀；未操作現場分析網頁。Q3 可重複的環境恢復、Q4 OLED PC:LIVE、CSV／報告／裝置一致及第二份檔案不覆蓋，仍須實物確認。
