# Week 2：基本原理與延伸練習分開

日期：2026-09-22。依五則 PDF 批註及教師再次確認的原則修正，不增加教學功能。

## 教學界線

- 基本範例只做兩鍵讀取、count 加減及 Serial.println(count)。不使用事件格式、上下限、去抖、單次按壓鎖定、雙鍵衝突或長按計時。delay(200) 僅讓輸出容易閱讀，不冒稱一次按壓只計一次。
- 主教材第 24–28 頁操作、第 29 頁一頁完整程式、第 30–31 頁資訊流與電流，專注 GPIO → ESP32 計算 → UART／CH343／USB → 電腦，以及上拉電阻、按鈕、GND 的電流支路。
- 第 32–33 頁才談負數、長按、重啟、雙鍵、loop 與計時，作為觀察和判讀練習。
- 第 34–36 頁是「活動入場人數登記」，沿用雙按鈕完成 0～20、指定長按間隔、雙鍵暫停及事件紀錄。此名稱是情境的普通描述，不另立課程專有名詞。程式識別字 room_counter 維持不變。
- 刪除原第 38 頁「停在哪一步，就處理那一步」及其頁碼引用；必要的 Port／接頭檢查短句留在操作位置。參考資料改為第 37 頁。
- 補充第 23 頁為觀察題解答，第 24–30 頁為入場登記實作解答。主教材不嵌入進階解答程式。補充及所有解答繼續只留本機。
