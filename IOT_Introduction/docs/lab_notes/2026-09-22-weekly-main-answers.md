## 反例的設計與界線

每個實作週兩張對照圖；正常情境和修改情境保留相同條件，只改一個地方。
Main 提供具體問題與短提示，Ans 補完整推理。危險接法、取消權限或未知負載僅圖上推演。
一般連接示意不當成實物排針圖；資訊箭頭不當成電流。圖內斷路也不表示讀值一定為零。

| 週 | 反例一 | 反例二 |
|---|---|---|
| 2 | 取消內部上拉，不是換成導線 | 不印 Serial，RAM 仍可能改變 |
| 3 | 拆掉分壓下方電阻 | 模組有電但 S 沒接 ADC |
| 4 | DHT 有電但 DATA 不通 | 改時間戳不能讓舊資料變新 |
| 5 | 唯一限流電阻換成線的風險 | 畫在 RAM 但不 sendBuffer |
| 6 | 舵機失去唯一共地 | 只印 angle 不證明實際到位 |
| 7 | x 中止不是 USB 斷電 | 略過有效性把端點當動作 |
| 11 | WebSocket 斷線不等於未入庫 | 結果遺失不證明實物未動 |
| 12 | broker 收到不等於 bridge 入庫 | 沒有 device_id 篩選會混入其他裝置 |
| 14 | 快取頁面不等於可送新命令 | 隱藏按鈕不能代替後端授權 |
| 15 | 同門檻且保留三筆確認的假想比較 | 只改 ERROR 變數不等於更新安全輸出 |

分壓 3.3×1/(10+1)=0.3 V 為理想模型；電表高阻抗但不是無限大。
讀取年齡示例為 4800−3000=1800 ms，不是實機時間。
INPUT 未上拉的狀態、DHT 快取與 U8g2 全畫面暫存行為核對：
[Espressif GPIO](https://docs.espressif.com/projects/arduino-esp32/en/latest/api/gpio.html)、
[ADC](https://docs.espressif.com/projects/arduino-esp32/en/latest/api/adc.html)、
[Adafruit DHT](https://github.com/adafruit/DHT-sensor-library/blob/master/DHT.cpp)、
[U8g2 sendBuffer](https://github.com/olikraus/u8g2/wiki/u8g2reference#sendbuffer)。
網路結果及安全狀態以本 repository 的 app、bridge 與實際範例程式對照，不宣稱通用產品保證。

## 保留限制

- 沒有上傳韌體、掃描序列埠、傳送硬體控制命令、動舵機或改實體接線。
- 沒有驗證真實手機、LAN／HTTPS 安裝或整堂課學生獨立完成。

- 不宣稱「保證做完」；實物有異常仍應停止，不能拿反例當帶電試錯步驟。
