# 18 週材料與課堂執行 Runbook

本文件處理學生材料尚未到齊、學生器材故障與第9週教師出國時的課堂安排。
教師三套器材只作驗證及示範，不提供硬體借用。學生每組1～3人並自行準備一台
萬用電表；1人組可向其他組共用。教師電表只作示範、核對與故障參考備品。

## 1. 教師三套器材的用途

| 用途 | 原則 |
|---|---|
| 課前驗證 | 教師先驗證當週接線、library、程式、供電及預期錯誤 |
| 課堂示範 | 使用一套完成共同示範，避免同時拆動三套已知可用配置 |
| 教師作品 | 可供智慧停車、互動玩具或移動平台案例，不影響學生選題 |

## 2. 使用與缺料處理

2026-09-30 Week1～7 重排目標見[課程規劃](18_week_plan.md)。以下同步本輪安排，
沿用已更新的採購規格，不另加零件、數量或指定學生購買新套件；三件作品不代表同時組裝三套硬體。
Week1 無元件，Week2 才開始實機操作。OLED 改在 Week3 使用，發布前須同步原採購頁的首次使用提醒。
每週硬體實作都從空麵包板重新搭建；沿用已學知識與同一批零件，不保留上週實體電路。
各週操作講義提供當週完整接線圖、表與步驟。同堂課分段時可保留已確認接線，標明保留、新增、移除，改線先斷電。
每週仍聚焦本週新增部分，以三件不同用途作品練習已學操作；每件只接需要的元件，重新搭建時核對空間、供電及腳位，不增採購或額外交件。
Week7 之後原有活動若需硬體，也依本週需要從空板接線；不因此要求接回全部舊元件或增設新活動。

僅 Week4 可等效選用 OLED 或 Serial Monitor 顯示，Ans／program 須提供兩種版本，學生擇一即可。
Week4 的三件作品是環境顯示器、環境超標提示器、兩個位置的環境比較器；每件均提供 OLED／Serial Monitor 兩版，學生擇一，功能要求相同。Q1 用光敏與 DHT，Q2 只用 DHT，Q3 用 DHT 與按鈕；無效溫濕度顯示 `--`，不冒充正常值。其他週顯示安排、採購與配分不變。

此表不另訂採購數量。依Week 1已公布規格選購，按首次使用週次自行安排到貨；
無法確認相容性的商品先詢問。採購確認不等於已可上電，不以模擬替代學生實體證據。

## 3. 每組基本材料摘要

確切規格、數量與使用週次以Week 1的
[學生材料採購總表](../../Week_01_Course_Orientation/week1_main.md#一學生材料採購總表)
為唯一依據，不在此複製另一份清單。每組1～3人共用一套基本零件、供電組與電表；輪流操作，各自保存學習紀錄。OLED採購規格與電池種類已明列，
連接材料不限定某一款轉接板；學生自行安排準備，教師仍須在各週上電前確認實物profile。
HW-508蜂鳴器的腳位及驅動尚未確認，不把採購清單當成全班可直接接線的答案。

題目確認前不要求購買感測器大全包、相機板、Raspberry Pi、車體、LiDAR
或高價 AI 板。特殊材料在第10週第一次專題報告確認用途、安全與預算後再買。

## 4. 教師課前驗證

逐週任務與證據依[教師課卡](../course_materials/teacher_18_week_materials.md)；
新增模組先完成profile、單元與整合測試，再公布可上電程序。
Week3 確認光敏與 OLED；Week4 確認 DHT；Week5 確認 RGB；Week6 確認外部供電與紙指針。
蜂鳴器移為進階，未確認不得上電；不能把教師已有的局部測試當成全班器材都已通過。
Week7 確認輸入、OLED、RGB與指針的對應、必要的色光隔離、持續中止及故障恢復；不另加計時遊戲。
Week 17預先核對全班場次容量、同一提交截止、電源／網路與每位成員問答安排。

## 5. 故障交換順序

不要一看到失敗就換 ESP32。依序留下證據：

1. 檢查電源、GND、極性與電壓。
2. 檢查 GPIO、接線與插接牢固度。
3. 使用最小程式測單一輸入或輸出。
4. 更換一條已知良好線材。
5. 更換同類模組並重測。
6. 最後才更換開發板，並在 `IOT_Introduction/docs/hardware/hardware_state.md` 記錄原板現象。

## 6. 跨組與跨電腦紀錄

- 每個實體元件貼唯一標籤，例如 `BOARD-T01`、`SERVO-T02`。
- 借用、接線、供電、library、測試與已知問題記在 `IOT_Introduction/docs/hardware/hardware_state.md`。
- 每次完整實驗在 `IOT_Introduction/docs/lab_notes/` 新增日期檔，附 commit 與下一步。
- 開始前 `git pull --ff-only`；完成後只提交教材、程式與去敏紀錄。
- 不提交 Wi-Fi 密碼、API key、Database secrets、學生個資或未授權影像。

## 8. 完成標準

- 材料不足不讓學生整堂等待，另有等價的判斷、設計或 log 除錯任務。
- 不把 teacher-tested、student target-tested 與 physical project-tested 混為一談。
- 每週下課前先停止操作，關閉並斷開 USB、外接供電等所有電源，確認斷電後才拆下跳線與模組、收納零件，留下空麵包板；原有標籤、版本與 Lab Notebook 要求不增加。
- 題目可自由，但供電、邏輯準位、驅動與安全停止沒有例外。
