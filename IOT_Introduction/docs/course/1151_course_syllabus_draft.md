# 115-1 物聯網與雲端運算課程教學大綱

## 基本資料

- 班級：四技資二乙；教師：李文毅。
- 課名：物聯網與雲端運算（Internet of Things and Cloud Computing）。
- 時間：星期三第5–7節，13:30–16:15，每週3小時。
- 語言：中文為主，搭配英文術語；具基本程式能力即可。
- 科目代碼、學分、必選修及正式授課語言／EMI登記待確認。

## 教學目標

運用ESP32-S3製作自選互動硬體，結合手機操作、後端、資料庫與紀錄分析，完成可安全運作及重建的IoT作品。重視理解、測試與協作，不以價格、機構複雜度或速度評分。

## 學習成果

1. CLO1：說明硬體、網路與軟體的分工。
2. CLO2：安全接線、量測及控制輸出入。
3. CLO3：整合感測與致動，並實作安全停止。
4. CLO4：串接裝置、後端、資料庫與手機。
5. CLO5：利用歷史資料與log除錯並驗證修正。
6. CLO6：完成作品、文件及展示問答。

## 教學內容

第2–7週練習硬體與單機互動；第11週起加入Wi-Fi、HTTP、WebSocket、JSON、MQTT、資料庫及手機前台。穿插三次專題報告與兩次個人筆試，第17週展示完整作品。

## 作品要求

- 第8週：每組12–15分鐘說明題目、可行性、材料及風險，展示硬體片段，不要求完整成品。
- 第13週：報告實作進度、問題與修正計畫。
- 第17週：展示自選硬體、學生自製前後台、資料庫、歷史查詢、log及WebSocket更新，包含操作結果、自動反應與異常處理。
- 繳交原始碼、接線與資料流、測試、重建及AI驗證紀錄；現成平台不得取代核心實作。完整規格見[18週計畫](18_week_plan.md#六期末作品最低要求)。

## 教學方法

短講、QA、實作、除錯與展示。每組1–3人共用基本零件及供電組、輪替分工並維護Lab Notebook；個人自備筆電及學習紀錄。每組備電表，1人組可跨組共用但須分別留存量測證據；材料依Week 1清單準備。

## 教材與參考

教師自編教材，以及Espressif、HTTP、MQTT、WebSocket、JSON與PWA相關文件。ROS 2、Gazebo及Nav2為進階選讀。不指定單一教科書或付費雲端服務；尊重智慧財產權，不得非法影印。

## AI與安全

AI產出須經人工理解、修改及驗證並留存紀錄。上電前檢查接線與供電；GPIO採3.3V邏輯，5V訊號須保護，馬達及舵機不得由GPIO供電，且須可停止或斷電。不得未經同意蒐集個資。
