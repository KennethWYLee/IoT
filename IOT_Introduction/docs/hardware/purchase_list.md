# 採購原則與材料清單

發給學生的正式品項、數量與使用週次，以Week 1的
[學生材料採購總表](../../Week_01_Course_Orientation/week1_main.md#一學生材料採購總表)
為唯一依據。本文件保留課程採購原則、分組萬用電表、專題選配及教師示範政策。

本課不要求學生製作車輛，也不以買更多模組換取更高成績。共同材料先支援
Week 2–7 的安全接線、量測、感測、致動與單機互動，以及 Week 11 之後的 ESP32
連網。作品特殊材料在第8週第一次專題報告確認用途、相容性、風險與預算後才購買。

學生必買或必須自備的每一項品項與數量，都須在共同教材中有明確操作、量測
或安全用途。教師已購庫存不構成學生採購理由；沒有共同必要用途的品項應延後、
改列專題選配或自清單移除。

每組1～3人共同備妥一套基本零件、舵機供電組與電表，教師不替學生購買。已有合格用品只補缺項，
不是要求購買某一整套商品。零件小計（含OLED）、電表分攤與未計價自備用品，
統一見Week 1的[參考預算](../../Week_01_Course_Orientation/week1_main.md#purchase-budget)，
本文件不另外維護金額。歷史成交價只供估算，不是再次採購的即時報價。
特殊專題材料仍須等第8週第一次專題報告後才決定。

## 1. 每組基本材料

每組必備零件須對應Week 2～7共同操作，不能只用「未來專題可能會用」作為理由。
一個零件不必每週都用，也不要求全部進入Week 7遊戲；例如DHT11在Week 4有
單獨讀取、雙感測器整合與失敗恢復任務，已構成共同用途。

指定電阻可以沿用、單買或跨組合買分裝，每組仍須取得正式清單的四種阻值與數量。
整包其餘阻值不屬共同必備；整包歷史價格也不是分裝後每組的固定費用。

共用器材不取消個人學習要求：組員輪流接線、量測、上傳與操作，各自保存程式、觀察與推理紀錄。
筆電仍每人自備，USB資料線與收納用品按組準備；規格與數量以Week 1為準。
OLED的可選購規格已在Week 1公布；符合規格可先準備，不必等到Week 5。
購買規格與上電驗證分開：實物腳序、位址、邏輯相容性與顯示仍須檢查。
蜂鳴器HW-508的中間腳與驅動尚未確認，不能僅憑型號標示宣稱可直接GPIO。

各品項的確切規格、數量與週次不得在本文件另建一份副本，應直接查閱
[學生材料採購總表](../../Week_01_Course_Orientation/week1_main.md#一學生材料採購總表)，
避免兩份清單失去同步。

電池種類與降壓模組依Week 1供電組表，取代原四顆1.2 V鎳氫方案；不再要求鎳氫充電器。
四顆1.5 V AA經降壓模組供舵機，供電組可由1～3人共買並輪流操作，一次只供一顆舵機；
換接前關電池並拔USB，每人仍須完成自己的操作與紀錄。
標稱電壓不等於實測值；舵機接線前仍須完成實際電壓、極性、固定、絕緣與共地檢查。
不限定購買2P端子轉12P排針板；既有合適連接材料可用，不接受裸線碰觸或鬆散纏繞。
斜口鉗與剝線鉗不列每人必買，依確實採用的安全連接方法準備工具。
各項依首次使用週次安排到貨，可一次購齊，不另設OLED的延後購買期限。

教師已購三套主要材料只作課前驗證與示範，不提供學生借用或故障替換。
學生以1～3人為一組，每組自行準備一台萬用電表；1人組可以向其他組共用，
但各組仍須分別完成並保存自己的量測證據。

## 2. 分組量測工具與教師參考設備

| 工具 | 正式配置 | 備註 |
|---|---|---|
| 數位萬用電表 | 每組1台；1人組可與其他組共用 | 須具通斷蜂鳴、電阻及低壓直流電壓量測功能 |
| 教師A830L萬用電表 | 1台參考備品 | 只作示範、讀值核對及故障參考，不計入各組正常使用量 |

電源、資料線、電池、轉接端子、文具及機構材料由學生依正式清單自行準備。
只有已核准活動確實需要的工具才另行通知學生自備；工具未列入共同必買，
不因課堂不提供就要求全班預先購買。

焊接、鋰電池、高電流電源與快速旋轉機構不作為入門共同要求。若專題需要，
須有教師在場、適當工具、絕緣固定與專門安全程序。

## 3. 第8週後按題目加購

| 作品方向 | 可能加購 | 先確認 |
|---|---|---|
| 互動燈／遊戲 | WS2812、按鈕、旋鈕、OLED | 電流、限流、亮度與操作流程 |
| 閘門／指針／夾取 | SG90、MG90S、支架、外部 5V 電源 | 扭力、行程、夾手、共地與 stop |
| 環境／占用 | DHT11 或較佳溫濕度、PIR、光敏、OLED | 精度、位置、誤判與隱私 |
| 距離互動 | 3.3V 相容 ToF，或 HC-SR04 加保護 | Echo 邏輯準位、盲區與安裝角度 |
| 聲音／輸入裝置 | 麥克風模組、旋鈕、搖桿、觸控 | 輸出範圍、ADC 與雜訊 |
| 移動平台 | 底盤、馬達、驅動板、電池、降壓、急停 | 堵轉電流、驅動容量、重心、雜訊與固定 |
| 手機視覺 | 優先使用學生手機與筆電 | 延遲、光線、影像傳輸、隱私與網路 |

特殊材料應先用資料表或官方文件回答：工作電壓、訊號邏輯、峰值電流、
控制介面、library、安裝方式、失敗時的安全狀態，以及是否真的支援作品
的使用情境。

## 4. 不列共同必買

- UCI K-4 或其他小車底盤。
- L298N、馬達、輪胎、6AA 電池盒及其他移動平台專用電源；Week 1列出的舵機降壓模組除外。
- Raspberry Pi、Jetson、LiDAR、ESP32-S3-CAM、Pixhawk 或無人機。
- 37 件感測器包。
- RFID、相機板、3D 列印件或壓克力機構。
- 付費雲端、付費 MQTT broker 或 Flutter 套件。

這些都可以因專題需要選用，但不屬於全班共同前置成本。

## 5. 教師可選補強

若預算允許，優先順序如下：

1. 先保留並驗證教師用ESP32-S3、USB資料線、麵包板與三種杜邦線，只作
   教師驗證及示範，不替學生代購、借用或故障替換。
2. 保留一台已知良好的教師參考萬用電表，並在課前確認其表筆、通斷、電阻及
   低壓直流電壓功能正常。
3. 各備數顆按鈕、RGB／LED、蜂鳴器、SG90 及不同類型感測器。
4. 再考慮一包感測器套件作教師示範庫，不提供學生借用。
5. 最後才為已確認題目的高負載致動器、移動平台或影像運算加購。
