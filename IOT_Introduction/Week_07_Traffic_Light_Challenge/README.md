# Week7：紙杯垃圾桶＋App

手遮住杯外光敏，舵機掀開輕紙蓋；預設開啟5秒，而且感應點清空後才關蓋。手機可操作開關、秒數、保持開啟、恢復自動與今天指定時刻，OLED 顯示目前狀態。

**最新版教材與動畫：Arduino 與手機 App 已在教師本機整合並完成電腦檢查，但程式尚未公開，由教師另行提供。動畫是操作預期，不是實機錄影；Android Chrome、實際 Wi-Fi 與紙杯帶載仍須試作。**

## 1. 先完成純舵機＋App

先不裝紙杯或紙蓋，只看舵盤轉出、返回。App「開蓋／關蓋」此時對應舵盤動作。Ans 依序說明接線、獨立舵機測試、教師設定、連線校正、App 操作，最後才裝紙蓋。

![手機加入 ESP32 Wi-Fi，讀取 App、送操作要求與查詢狀態；ESP32 判斷後控制舵機及 OLED](animations/system_architecture.png)

App 網頁由 ESP32 提供，介面在手機瀏覽器執行；不經雲端，電腦也不是操作中繼。收件不等於已執行，舵機命令不等於實物已到位。圖中箭頭是資訊，不是電源接法。

重新開始：電池 OFF → USB保持供電按 RST → 重連 Wi-Fi → 刷新原單一分頁 → 重新校正。若顯示教師設定未確認，維持 OFF，由教師核對並更新程式；App不能解鎖。

## 本版操作重點

- 不接外接按鈕；由 App 完成光線校正、準備、開始與停止。
- 開蓋命令起預設 5 秒，感應點還要連續清空 0.5 秒才關蓋；光敏不是實際防夾設備。
- 手機可調 1～60 秒，或設定今天、本輪剩餘期限內的一次關蓋時間；準備起最多 3 分鐘，不會因重連而延長。
- 同組使用一支手機、一個控制分頁；對照 Serial 與 App 的本組 Wi-Fi 名稱。原頁離線後重連不補送；刷新成為只讀，要重新接手須先關舵機電源，再依 Ans 重設與校正。
- App 停止與 TIMEOUT 都不等於切電；異常時直接人工關閉舵機外接電源。
- 保持開蓋會轉出並保持，不是凍結當前角度；手動／定時完成後須恢復自動，才會重新接受遮光觸發。

## 必要材料

**IoT 設備：** ESP32-S3、COM 資料線、麵包板、跳線、光敏模組、OLED、SG90、電池盒、降壓板、可連 Wi-Fi 的手機。

**文具：** 紙杯、輕紙片、紙板底座與短支架、小紙球、剪刀、膠帶、筆。不接外接按鈕、RGB、DHT 或蜂鳴器。

## 操作限制

先空載測舵機，再由教師核對供電、紙蓋負載與兩端行程。光敏放在杯外，不讓紙蓋遮住它；這不是正式防夾設備。App 停止只停止控制，不會切電；異音、卡住、發熱或失聯時人工關外接電源。完整關機還要拔 USB。
