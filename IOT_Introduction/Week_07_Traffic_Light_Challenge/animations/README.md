## Q1．免接觸垃圾桶模型

遮住箱外感應點，輕紙蓋開啟；移開後 OLED 倒數 3 秒才關蓋。倒數中再次遮光會取消，下一次移開重新計滿。操作鈕可切換手動保持開啟與自動模式。

## Q2．包裹開箱警示

監測後開箱，次數加一、紅燈、升旗。關箱仍保留待確認事件；關箱穩定後重新按操作鈕才確認，累計次數不清除。開箱時按住鈕等關箱不算確認。

動畫左邊列出完整步驟，右邊顯示目前作品、燈號與 OLED 預期畫面。可暫停、選步驟、拖時間、切換立體／俯視／側面；手機先顯示作品，再列完整步驟。

兩題只接操作鈕與 STOP；RST 是板上原有的重啟鍵。STOP 不切斷電源，人仍須立即關舵機外接電源。舵機只帶輕紙，光敏只作遮光推測，不測距、不防夾，也不能辨識誰開箱。

每題分兩輪示範，中間人工關電、RST、重做光線設定。單輪從準備起算 30 秒，不以動畫總長延長硬體操作時間。
